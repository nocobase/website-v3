description: Create a NocoBase Core application and find documentation for development, extensions, deployment and maintenance.

NocoBase Core is an open-source application foundation for developing and running business systems with AI. Common capabilities such as permissions, workflows and files are ready to use, so agents can focus on your business-specific functionality within a consistent architecture.

Creating a project from the [default application template](https://github.com/nocobase/nocobase/tree/v3-develop/packages/templates/app-template-default) gives you an application you can run, modify and deploy. It includes foundational capabilities and development guidance for agents. Add your own business pages, data and rules with an agent, or write the code directly.

## Getting started

1. [Create an app](getting-started/create-app.md): prepare your environment, create a project with an agent or the command line, start it and sign in.
2. [Build your first app](tutorials/build-your-first-app.md): add task management with an agent, try the result and explore the key code.

Read [Project structure](getting-started/project-structure.md) when you need to locate pages, APIs, database resources and tests.
