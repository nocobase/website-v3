---
title: "Do I need Studio to use Core?"
---

No. You can use Core on its own, develop business features with coding tools such as Claude Code or Codex in your application directory, and organize testing, reviews, and deployment within your team. Start with [Build your first app with Core](../getting-started/develop-your-first-app.md).

Core provides the foundation and development conventions for your application. Studio coordinates collaboration between people and agents. In practice, many teams build the MVP locally with Core first and connect the same repository to Studio with zero migration once frontline feedback and parallel iteration pick up; see [Best way to get started](../getting-started/from-core-to-studio.md). Applications built either way run on Core.

When you are ready to bring in Studio, start with [Install and use Studio](../getting-started/collaborate-with-studio.md) to try the free Community Edition on your own computer and walk through a request. For team deployment and edition selection, see the [Installation overview](../studio/setup/index.md).
