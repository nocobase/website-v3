---
title: "Where can I find help with installation, development, or tasks?"
---

First identify whether the problem occurs in your business application or in Studio’s development workflow, then open the relevant troubleshooting guide.

- **Core development and runtime issues**: for missing plugin features, configuration that does not take effect, migration errors, dependency upgrades, or deployment problems, start with the [Core FAQ](../core/reference/faq.md).
- **Studio setup and collaboration issues**: for login failures, Git connection errors, offline runtimes, tasks that do not start, or missing checks and previews, see [Studio troubleshooting](../studio/reference/faq.md).
- **Tutorials or commands that differ from your environment**: confirm that you are reading NocoBase 3 documentation. See [NocoBase 2 and NocoBase 3](from-v2.md) for version differences, and use the [CLI reference](../core/reference/cli.md) and your installed version’s help for application commands.

If you still cannot identify the cause, ask a coding agent to investigate with reproduction steps, actual and expected results, relevant versions, and sanitized error messages. State whether the issue occurs during installation, source development, building, or deployment. For Studio tasks, include the relevant task and runtime status. Do not include passwords, keys, or session tokens.
