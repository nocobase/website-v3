<p class="course-intro">Learn how to use NocoBase 3 through practical examples.</p>

The lessons build on the same CRM app. If you are new to NocoBase 3, start with Quick start and work through app creation, customer management, and testing and delivery in order. If you already have development experience, choose a topic from Hands-on practice and check its prerequisites before you begin. Adapt the requirements to your own business, and verify the results with tests and by using the app.
