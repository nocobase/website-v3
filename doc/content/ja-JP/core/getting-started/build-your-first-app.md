[アプリを作成する](create-app.md) で作成したアプリで、エージェントに最初の機能である顧客管理を構築させます。アプリのルートでエージェントを開きます。

## 要件を伝える

エージェントに次を送ります。

```prompt
顧客管理を作ってください。項目は名前、連絡先、メモ、営業担当者、次回フォロー日です。顧客のステータスは Lead、Following up、Won です。
顧客の作成、閲覧、編集、削除と、名前での検索、ステータスでの絞り込みができるようにしてください。
営業マネージャーはすべての顧客を管理できます。営業担当者は自分の顧客だけを閲覧でき、そのステータスを更新できます。閲覧専用ユーザーはすべての顧客を閲覧できますが、変更はできません。
```

伝えるのは業務の内容だけです。何を記録するか、どんな操作があるか、だれが実行できるか。ユーザーと権限の管理、翻訳、テスト、完了報告は、エージェントがプロジェクトのスキルに従って扱います。

## 設計を確認する

実装の前に、エージェントはページの構成、主な操作、あなたに決めてほしいことを含む設計を示し、確認を求めます。質問に答えて設計を確認すると、開発が始まります。

## 結果を試す

開発が終わると、エージェントはテストを実行し、ブラウザーでアプリを確認してスクリーンショットを撮ります。続いて、行ったことと検証できなかったことを報告します。検証にサインインが必要な場合は、自分でサインインするよう求めます。

エージェントが伝えた URL を開きます。サイドバーに **Customers** が表示されます。顧客を作成し、営業担当者と次回フォロー日を割り当て、ステータスを更新し、検索と絞り込みができます。

![ステータス、営業担当者、次回フォロー日、ページネーションのある顧客一覧。](/assets/core/tutorials/crm/customer-list-en.png)

スクリーンショットはサンプルアプリのものです。同じ依頼でも、毎回異なるレイアウトになる場合があります。

エージェントはユーザーと権限の管理も有効にします。営業担当者ができることを試してみましょう。

1. **System settings → Users** でユーザーを追加し、**Permission sets** で営業のロールを割り当てます。サンプルアプリでは `Sales rep` という名前です。
2. 顧客を作成し、営業担当者にこのユーザーを選びます。
3. そのアカウントでサインインします。一覧にはこのユーザーが担当する顧客だけが表示されるはずです。ステータスは更新できますが、詳細の編集や削除はできません。

## 改善を続ける

結果が間違っている場合や別のものにしたい場合は、何をして、何が起き、何を期待していたかをエージェントに伝えます。

```prompt
営業担当者のロールだけを割り当てたアカウントでサインインしましたが、ほかの人が担当する顧客も見えてしまいます。
営業担当者には自分の顧客だけが見えるようにしてください。
```

名前をクリックすると顧客の詳細が開き、そこで編集するかどうかを決められるようにするなど、操作の変更を依頼することもできます。

## コードの変更を確認する

サンプルアプリで主に変更された場所は次のとおりです。ファイル名は異なる場合がありますが、場所は似ているはずです。

```tree
my-app/
├── database/main/
│   ├── migrations/      # Create the customers table
│   └── seeds/           # Initialize three customer roles
├── server/
│   ├── customers/       # Input validation, business services and permissions
│   ├── providers/       # Register customer services and permissions
│   └── routes/          # Customer HTTP APIs
├── client/
│   ├── routes.ts        # Customer pages, sidebar entry and system settings
│   ├── pages/customers/ # List, details, forms and action menus
│   └── locales/         # Interface text
└── tests/               # Migration, API, page and browser tests
```

[CRM の完全なサンプル](https://github.com/nocobase/docs-examples-v3/tree/8ad953049469ab6b1e703be2a1b07f80f28ed592/apps/crm) を参照するか、[ZIP をダウンロード](/assets/core/downloads/crm-source-8ad9530.zip) してください。セットアップと実行の手順は [README](https://github.com/nocobase/docs-examples-v3/blob/8ad953049469ab6b1e703be2a1b07f80f28ed592/apps/crm/README.MD) を参照してください。
