**AI 時代の業務アプリ開発のための基盤。**

NocoBase Core は、業務システムを開発・運用するためのオープンソースのフレームワークです。統一されたアプリケーションアーキテクチャ、基盤サービス、プラグインの仕組みを提供します。付属のプラグインが認証、認可、ワークフロー、ファイル管理などの共通機能を提供するため、開発者とエージェントは業務機能に集中できます。

アプリテンプレートからプロジェクトを作成すると、実行、変更、デプロイできるアプリが手に入ります。エージェントと一緒に、または自分でコードを書いて、業務に合わせたページ、データモデル、API、ルールを構築します。

## NocoBase Core を選ぶ理由

### 共通機能を再利用する

Core と付属のプラグインは再利用できる基盤機能を提供し、プロジェクトごとに繰り返される基盤づくりの作業を減らします。必要に応じてこれらの機能を選び、組み込み、拡張して、自社固有の業務要件に集中できます。

これらの機能はアプリを構築するための基盤であり、決まった設計の完成された業務システムではありません。ページ、操作、業務プロセスは、開発者とエージェントが必要に応じて実装します。

### エージェントに明確な開発ガイダンスを与える

一貫したプロジェクト構成、開発規約、スキル、サンプルが、エージェントが既存の機能を理解し、関連するコードを見つけ、プロジェクトの規約に従うのを助けます。

開発中、エージェントは基盤モジュールを改めて生成するのではなく、既存の機能を優先して使えます。開発者は業務ルールを確認し、重要な実装上の判断をレビューし、結果を検収します。

### 業務機能をカスタマイズし、継続的に改善する

業務機能はコードで実装します。ページ、API、データモデル、業務ロジックは必要に応じて整理・変更できます。機能はアプリ内で直接開発するか、独立した保守や複数のアプリでの再利用が必要な場合はプラグインにまとめます。

業務コード、フレームワーク、プラグインの責任が明確に分かれているため、開発の継続、問題の調査、アップグレードの影響の評価がしやすくなります。

## NocoBase Core でアプリを開発する

**Core とプラグインが共通の基盤機能を提供し、開発者とエージェントが業務アプリを構築します。**

一般的な開発の流れは次のとおりです。

1. **アプリを作成する**：アプリテンプレートからプロジェクトを作成し、設定を準備してアプリを起動します。
2. **業務機能を開発する**：要件と業務ルールを明確にし、既存の機能を使ってページ、データモデル、API、業務ロジックを構築します。
3. **結果を検証する**：アプリを試し、テストを実行し、実装をレビューして、問題に対処します。
4. **デプロイして改善を続ける**：自社の環境にデプロイし、業務の更新を届け、必要に応じて Core とプラグインをアップグレードします。

始める前にフレームワークの細部をすべて学ぶ必要はありません。具体的な業務機能から始め、開発しながらドキュメントを参照してください。
