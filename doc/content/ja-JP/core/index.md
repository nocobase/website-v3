## 概要

NocoBase Core は、AI 開発のために設計されたオープンソースのアプリケーション基盤です——**エージェントは業務の開発に専念、基盤はもう整っています**。

普段お使いの Claude Code、Codex、Cursor などのコーディングツールと組み合わせて単体で始められるだけでなく、NocoBase Studio のエンジニアリング基盤としても機能します。新しいアプリを初期化するだけで、ユーザーと組織・権限、ログイン認証、ワークフロー管理、データベース、ファイルストレージ、通知、AI 連携など 30 以上の共通機能がすぐに使え、統一されたプロジェクト構成と開発規約も整います。

権限、承認、ワークフローエンジンといった複雑で高い信頼性が求められる基盤部分を AI にゼロから書かせるのではなく、アプリケーション基盤として標準提供し、NocoBase が継続的に保守・アップデートします。エージェントは自社固有の業務コードだけを書けばよいため、開発はより速く安定し、人が行うテストやセキュリティレビューの範囲も大幅に絞れます。業務のソースコードは自社の Git リポジトリに保管され、リリース後は独立して稼働します。

## 主な特長

### 30 以上のすぐに使える共通機能

新しいアプリを作成した時点で、企業の業務システムに共通して求められる基盤機能がそろっているため、プロジェクトごとに AI へゼロから車輪の再発明と検証をさせる必要はありません。

| 機能領域 | 主な標準機能 |
| --- | --- |
| **ユーザー・組織・権限** | ユーザー管理、部門・組織構造、ロールベースのページ／操作／データ範囲権限、既定のデータ範囲、共有ルール、制限ルール |
| **ログインと認証** | パスワードログイン、ソーシャルログイン、OIDC、API キー（プロフェッショナル版では SAML 2.0、LDAP、WeCom・Feishu・DingTalk の SSO にも対応） |
| **データとファイル** | SQLite、PostgreSQL、MySQL、SQL Server、Oracle（プロフェッショナル版では Dameng、KingbaseES、OceanBase にも対応）、外部データソース、データベースブラウザー、ローカルおよび S3 互換ファイルストレージ |
| **ワークフローと協働** | ワークフローとレコードのライフサイクル、定期タスク、タスクセンター、基本承認（プロフェッショナル版では多段階の条件分岐や全員承認・いずれか承認などの高度な承認にも対応） |
| **通知・メール・UI** | アプリ内通知、メール送受信、Feishu／DingTalk／ブラウザーのプッシュ通知、多言語対応、テーマ、業務向け UI コンポーネント、DOCX／PDF テンプレート印刷 |
| **AI と業務エージェント** | クラウドおよびローカルモデル接続、業務エージェントの実行・制御、権限管理とバージョン管理を備えた AI ナレッジベース |

機能一覧と具体的な組み込み方は[組み込み機能とプラグイン](using-plugins/overview.md)を参照してください。

### 統一されたプロジェクト構成と開発規約

AI にゼロからコードを書かせると、担当者やモデル、あるいはセッションが変わるたびにディレクトリ構成や書き方がばらつき、やがてシステム全体が保守しにくくなります。

Core は標準のアプリテンプレート、ルール定義ファイル `AGENTS.md`、および基盤パッケージとともに配布される開発スキルを提供します。ページ、API、データモデル、マイグレーション、テストの配置が明確に決まっているため、どのモデルやコーディングツールを使っても、同じ構造の標準的な TypeScript・React・Node.js コードが生成されます。統一されたアーキテクチャのもとで長期的に改善を続けられ、開発チームが直接引き継いで保守することも容易です。詳しくは[アプリ開発の概要](developing-apps/overview.md)と[プロジェクト構成](developing-apps/project-structure.md)を参照してください。

### 業務システムに標準内蔵された AI 機能

Core はコーディングエージェントが開発に使うための基盤にとどまらず、モデル接続、業務エージェントの実行基盤、AI ナレッジベースを標準で内蔵しています。

システムの本番稼働後は、業務エージェントをアプリ内に配置し、担当者の権限の範囲内で 24 時間日常業務（リード調査、台帳の照合、メール整理、チケットの振り分けなど）を自律的に進めることができます。意思決定が必要な場面では根拠を添えて人に判断を委ねます。詳しくは[エージェント](using-plugins/agents-and-knowledge/agents.md)と[ナレッジベース](using-plugins/agents-and-knowledge/knowledge.md)を参照してください。

### オープンソース・単体スタート・独立稼働

- **オープンソース・無料で継続保守**：Core は無料のオープンソースとして公開されており、ソースコードを自由に監査できます。基盤機能の不具合修正や機能強化は NocoBase が継続的に保守し、バージョンアップを通じて各業務アプリへ届けます。
- **ワークスペースやツールに縛られない**：Core を使うために Studio を先に導入する必要はありません。普段お使いの Claude Code、Codex、Cursor などのコーディングツールと組み合わせてそのまま開発を始められます。
- **セルフホストと独立稼働**：アプリのソースコードとデータはすべて自社が所有し、自社サーバーにデプロイできます。Docker、PM2、マルチインスタンス、Kubernetes などの運用形態に対応しており、リリース後は Studio を経由せず独立して稼働します。

## はじめよう

初めて使う場合は[最初のアプリを開発する](../getting-started/develop-your-first-app.md)から進めてください。数分で新しいアプリを初期化し、コーディングツールで最初の業務機能を開発できます。台帳、承認、権限、デプロイまでをひとつの案件として実践したい場合は、[NocoBase 3 で信頼できるエンタープライズアプリを構築する](../guides/build-reliable-enterprise-apps.md)を参照してください。
