---
title: "Core を使うには Studio のインストールが必要ですか？"
---

必要ありません。Core 単体でも、アプリのディレクトリで Claude Code や Codex などのコーディングツールを使って業務機能を開発し、チームでテスト、レビュー、デプロイを進められます。[最初のアプリを開発する](../getting-started/develop-your-first-app.md)から始めてください。

Core はアプリの基盤機能と開発規約を提供し、Studio は人とエージェントの共同作業を管理します。複数のプロジェクトやタスクを並行して進め、進捗、チェック、受け入れ確認をまとめて管理したいチームには Studio が役立ちます。どちらの方法でも、開発するアプリは Core 上で動作します。

Studio を検討する場合は[Studio で共同開発する](../getting-started/collaborate-with-studio.md)をご覧ください。インストールとチームの設定は[セットアップの概要](../studio/setup/index.md)で説明しています。
