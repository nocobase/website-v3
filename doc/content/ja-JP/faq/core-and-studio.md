---
title: "Core を使うには Studio のインストールが必要ですか？"
---

必要ありません。Core 単体でも、アプリのディレクトリで Claude Code や Codex などのコーディングツールを使って業務機能を開発し、チームでテスト、レビュー、デプロイを進められます。[Core で最初のアプリを開発する](../getting-started/develop-your-first-app.md)から始めてください。

Core はアプリの基盤機能と開発規約を提供し、Studio は人とエージェントの共同作業を管理します。実際のプロジェクトでは、探索期にローカルの Coding Agent と Core で素早く MVP を作り、試用フィードバックが集まり始めたタイミングで同じリポジトリを移行コストゼロで Studio に接続する進め方がおすすめです。詳しくは[おすすめの始め方](../getting-started/from-core-to-studio.md)を参照してください。どちらの方法でも、開発するアプリは Core 上で動作します。

Studio の導入を検討する場合は、[Studio をインストールして使う](../getting-started/collaborate-with-studio.md)に沿って自分のコンピューターで無料のコミュニティ版を試し、最初の要件を一通り進めてみてください。チーム向けのデプロイとエディションの選び方は[インストールの概要](../studio/setup/index.md)で説明しています。
