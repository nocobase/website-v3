---
title: "既存の Java・Spring Boot などの業務システムと連携できますか？"
---

既存システムを維持し、Core アプリから API を呼び出して業務ページや新機能を追加できます。たとえば品質・設備サービスは引き続き Spring Boot で管理し、NocoBase アプリでデータ表示、業務操作の送信、画面操作の組み合わせを実装します。実装場所は[サーバー側サービス](../core/developing-apps/server-business-services.md)を参照してください。

既存サービスが管理するデータの更新は、原則としてその API を使い、検証・トランザクション・業務フローを維持します。システム間のアカウント対応、権限、リトライ、重複送信の処理を定義してください。NocoBase のローカルデータベーストランザクションに、外部サービスの呼び出しが自動で含まれることはありません。

既存データベースに直接アクセスする場合は、`schemaManagement: 'external'` の接続を設定し、テーブル構造は元のシステムが管理します。`external` は読み取り専用という意味ではなく、実際のアクセス範囲はデータベースアカウントとアプリの権限で決まります。[既存データベースへの接続](../core/developing-apps/existing-databases.md)を参照してください。

既存の統合認証基盤は、[認証](../core/using-plugins/authentication/sign-in.md)の拡張機構で連携し、利用するプロトコルに応じてログインとアカウント対応を実装できます。認証の共有だけでは業務権限は同期されないため、双方の認可範囲を定義します。
