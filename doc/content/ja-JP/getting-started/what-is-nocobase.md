NocoBase 3 は業務アプリを開発し、実行するためのプラットフォームです。ページ、データ構造、業務ルールは自分たちのリポジトリにコードとして保存され、人とエージェントが開発します。Core が基盤を提供し、Studio がチームの開発、チェック、交付を管理します。

- **[Core](../core/index.md)** は、AI で業務システムを開発・運用するためのオープンソースのアプリケーション基盤です。権限、ワークフロー、ファイルなどの共通機能がそろっているため、エージェントは統一されたアーキテクチャの上で、自社の業務固有の部分だけを開発します。
- **[Studio](../studio/index.md)** は、人とエージェントが協働開発するためのガバナンスプラットフォームです。Claude Code、Codex、OpenCode をひとつのエージェントチームにまとめ、タスクを自律的に進めます。進捗はひと目でわかり、重要な判断は人が下します。
- **Solution** は、Core 上に構築された、エージェントが動かす業務アプリのシリーズです。NocoCRM や NocoITAM などがあります。実務の大部分はエージェントが担い、人は重要な判断だけを行います。そのままインストールして使うことも、エージェントに自社の業務に合わせてカスタマイズさせることもできます。

Studio は商用版で提供されます。

## 開発エージェントと業務エージェント

開発エージェントは Claude Code や Codex などのツールを使い、アプリのリポジトリで要件を実装、検証します。ローカルで一緒に作業することも、Studio のコーディネーターエージェントが実行エージェントへ分担することもできます。開発後、業務ユーザーは公開されたアプリを使います。

業務エージェントは稼働中のアプリ内で、顧客調査、メールの下書き、資産台帳の確認などを行います。Core の Agents プラグインを通じて業務機能に接続し、ユーザーの役割と権限に従い、判断が必要なら担当者に引き継ぎます。開発エージェントはアプリを変更し、業務エージェントはアプリの業務機能を使います。

## アプリの実行とデプロイ

Core、Solution、Studio はすべて自社サーバーで稼働し、コードとデータは自社のものです。モデルとエージェントは自由に選べ、特定ベンダーに縛られません。Claude Code、Codex などのコーディングツールと、さまざまなモデルに対応しています。業務アプリはリリース後、独立して稼働し、日常の業務リクエストが Studio を経由することはありません。

[最初のアプリを開発する](develop-your-first-app.md)で業務機能の作成と改善を体験するか、[Studio で協働開発する](collaborate-with-studio.md)でチームの交付プロセスを進めます。NocoBase 2 を使っていた場合は、[NocoBase 2 と NocoBase 3](../faq/from-v2.md)を参照してください。
