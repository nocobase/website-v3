NocoBase は、企業が AI で業務システムを開発・運用するためのオープンソースプラットフォームです。人が要件を定義して意思決定を行い、エージェントがコードを書いて実行し、NocoBase がシステムの信頼性とプロセスの統制を支えます。

NocoBase は、アプリケーション基盤（Core）とワークスペース（Studio）の 2 つで構成されます。フェーズに応じてアプリケーション基盤から単体で始めることも、ワークスペースでチーム協働を行うこともできます。両者を組み合わせることで、AI の力を、信頼できる業務システムを継続的に開発・運用する組織の力へと変えていきます。

## なぜ NocoBase なのか

AI を使えばコードは素早く書けますが、信頼できる業務システムを作り上げるのは簡単ではありません。これから AI でのシステム構築を始める企業でも、すでに Claude Code や Codex などのコーディングツールを活用しているチームでも、業務システムを本番投入して長期的に改善していく段階になると、次の 4 つの課題に直面します。

### 基盤機能をゼロから作らなくていい

AI に任せたとしても、権限、ログイン認証、ワークフローエンジン、承認といった基盤モジュールをゼロから設計・開発するのは難易度が高く、例外ケースも多いため、検証と保守に大きなコストがかかります。

Core には 30 以上のすぐに使える共通機能が標準で備わっており、NocoBase が継続的に保守・アップデートします。エージェントは自社固有の業務部分だけを開発すればよいため、実装・テスト・セキュリティレビューが必要なコード量が大幅に減ります。

### 統一されたアーキテクチャで、長期にわたって安定進化

担当者やモデル、さらには会話が変わるたびに、AI はその場しのぎの実装をしがちです。その結果、ひとつのシステムの中に異なる書き方が混在し、アーキテクチャが崩れて保守が困難になっていきます。

Core は統一されたプロジェクト構成、開発規約、そして基盤とともに配布される開発スキルを提供します。誰がどのモデルやセッションで書いても同じアーキテクチャにそろうため、長期にわたって安定して改修を続けられ、必要に応じて開発者が直接引き継いで保守することもできます。

### プロセスを統制し、ツールで品質を守る

チームで複数のプロジェクトと多数のタスクを並行して進めると、メンバーそれぞれがターミナルや会話を行き来することになり、エージェントから届く変更も膨らみ続けます。すべてを目視で確認しきれず、かといって任せきりで本番に出すこともできません。

Studio は定義されたワークフローに沿って各タスクを進め、常駐スキルを毎回の実行で自動的に読み込みます。変更は自動チェックと別モデルによるクロスレビューを通過したうえで、納品レポート、スクリーンショット、操作可能なテスト環境を添えて人の検収に回ります。さらにエンタープライズ版では、実績ある外部ツールを用いて機能・スモークチェック・権限・セキュリティ・パフォーマンス・コード品質・UX を多角的に実測し、見つかった課題をフォローアップタスクとして自動起票して修正・再テストまで完結させられます。

### 協働を一元化し、ノウハウをチームに蓄積

各自の PC で個別に AI を使っていると、要件の背景、業務資料、プロジェクトの進捗、過去に踏んだ落とし穴が別々の会話に散らばってしまい、他メンバーから見えず、担当者やモデルが変わると引き継げなくなります。

Studio はすべてのプロジェクトの要件、議論、進捗、コストを 1 か所に集約します。仕事の進め方はスキルに、業務資料はナレッジベースに、開発で得た教訓や合意済みのルールはプロジェクトメモリーに蓄積されるため、担当者やエージェントが変わってもスムーズに引き継げます。

### NocoBase Core（アプリケーション基盤）

**[NocoBase Core](../core/index.md)** は、AI 開発のために設計されたオープンソースのアプリケーション基盤です。オープンソース・無料で提供され、単体で始めて独立して稼働できます。

新しいアプリを初期化するだけで、ユーザーと権限、ログイン認証、ワークフロー管理、データベース、ファイルストレージ、通知、AI 連携など 30 以上の共通機能がすぐに使える状態でそろい、統一されたプロジェクト構成と開発規約も備わります。個人でもチームでも、Studio を先にインストールすることなく、普段お使いの Claude Code、Codex、Cursor などのコーディングツールと組み合わせて Core から業務システム開発を始められます。

### NocoBase Studio（ワークスペース）

**[NocoBase Studio](../studio/index.md)** は、チームでの協働開発とガバナンスのためのワークスペースです。

個人の PC やチームサーバー上にある Claude Code、Codex、OpenCode などのコーディングツールを 24 時間稼働するエージェントチームにまとめます。コーディネーターエージェントが各エージェントの得意分野に応じて設計、開発、テスト、レビューを割り振り、複数のプロジェクトを並行して推進します。人は PC やスマートフォンから要件を伝え、質問に答え、検収レポートやテスト環境を確認して判断を下し、全プロジェクトの進捗とコストをいつでも把握できます。

Studio コミュニティ版は無料で利用でき、2 種類の組み込みワークフロー（シンプルフローと標準フロー）および主要な協働機能を備えています。複数ロールのワークフローやカスタムワークフロー、デプロイ承認、品質管理などの高度な機能が必要になった場合は、プロフェッショナル版またはエンタープライズ版へアップグレードできます。詳しくは[エディションを選ぶ](../studio/setup/index.md#エディションを選ぶ)を参照してください。

## 開発から運用までの進め方

### 開発とデリバリー

人が目的、業務ルール、検収基準を定め、コーディングエージェントが Core の基盤上で画面、API、データ構造、業務ルールを実装します。ソースコードは自社の Git リポジトリに保管されます。自動チェック、クロスレビュー、検収を経てリリースし、業務要件の変化に合わせて既存アプリを継続的に改善していきます。

### 業務エージェントによる日常業務の遂行

システムの稼働後も、業務エージェントがアプリの中で日々の業務処理を継続的に担えます。業務エージェントは Core の Agents 機能を通じて組み込まれ、担当する責任者の権限を引き継いで社内ルールに沿って 24 時間自律的に実務をこなし、重要な操作の前には根拠を添えて人に確認を求めます。

## セルフホストと完全な自社管理

- **コードとデータは自社が所有**：Core も Studio も自社サーバーにデプロイでき、閉域網環境にも対応しています。
- **アプリは独立して稼働**：業務アプリはリリース後に独立して稼働し、日常の業務リクエストが Studio を経由することはありません。
- **モデルとツールを自由に選択**：特定ベンダーに縛られず、Claude Code、Codex、Cursor などのコーディングツールや、各種クラウドモデル・ローカルモデルを自由に選べます。
