## コーディングツールを選ぶ

コーディングツールには、Codex、Claude Code、OpenCode などの一般的なコーディングエージェントを使います。どれでもプロンプトは同じように使えます。各ツールの公式の手順に従ってインストールし、サインインしてください。

## モデルを選ぶ

2026 年後半の時点でおすすめのモデルは、Claude と GPT の各ファミリーの最上位モデルと、オープンソースモデルでは DeepSeek です。

| モデル | 強み |
| --- | --- |
| Claude Opus | 見栄えのよいページを作り、総合的な能力が高い |
| GPT Astra/Sol | かなり完全なシステム設計書があれば、システム全体を構築できる |
| DeepSeek | 高速で低コスト。OpenCode で使うか、DeepSeek のドキュメントに従って Claude Code に接続します |

設計書や新機能には、推論の強さを高めた強力なモデルを使います。文言やスタイルなどの小さな変更には、より速くて安価なモデルに切り替えます。

コードレビューでは、別ベンダーのモデルのほうが問題を見つけやすくなります。たとえば Codex が GPT で機能を構築したら、Claude Code のセッションを開いて Opus にレビューさせます。

```prompt
コミットされていない変更をレビューしてください。AGENTS.md の規約に照らして問題を探し、重要度順に一覧にしてください。コードは変更しないでください。
```
