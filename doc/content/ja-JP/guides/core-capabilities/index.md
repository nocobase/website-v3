NocoBase Core の各機能を実際の業務要件に組み込みたい開発者・チーム向けのシリーズです。基本テーマはすべて **CRM 営業管理サンプル** を主軸に Core の各機能・プラグインを 1 つずつ解説しています。グループ順に進めることも、必要な機能から直接選んで Studio の Agent チームまたはローカルの Coding Agent で実践することもできます。

## サンプルプロジェクトについて

各テーマは独立して学べるため、必要な機能から直接選び、サンプルプロジェクトまたは自分のアプリで実践できます。

- **完成版 CRM サンプルプロジェクト**：最初の 6 グループのテーマは [nocobase/doc-demo-crm](https://github.com/nocobase/doc-demo-crm)（英語 UI・英語サンプルデータ）を主軸の参照実装として扱います。デフォルトの `main` ブランチに構築済みの全機能が含まれているため、`main` を動かして該当機能の実装を確認したり、業務ルールやプロンプトを自分のアプリへ直接応用したりできます。
- **インストールと起動**：サンプルプロジェクトの [README](https://github.com/nocobase/doc-demo-crm/blob/main/README.MD) に従って、アプリをセットアップして起動します。
- **商用機能と外部サービス**：承認、To-do センター、メール接続など商用ライセンスや外部サービスが必要な条件は該当テーマのみに適用され、他のテーマには影響しません。
- **高度な応用シナリオ**：部門横断の権限設定、複数分岐の承認、複数フローの連携などの高度な使い方と、より自由なアプリの構築方法を学びます。
