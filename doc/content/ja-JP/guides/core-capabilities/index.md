NocoBase Core の各機能を実際の業務要件に組み込みたい開発者・チーム向けのシリーズです。各ガイドは単一の機能テーマに絞って解説しており、必要なテーマから直接選んで Studio の Agent チームまたはローカルの Coding Agent で実践できます。

## サンプルプロジェクトについて

このシリーズは機能テーマ別に構成しており、**レッスン番号や Git tag の手順に沿って進める必要はありません**。

- **完成版 CRM サンプルプロジェクト**：一般的なテーマのガイドでは、[nocobase/doc-demo-crm](https://github.com/nocobase/doc-demo-crm)（英語 UI・英語サンプルデータ）の最新 `main` ブランチを参照実装として扱います。最新の状態には構築済みの全機能が含まれているため、履歴 tag を切り替えずにそのまま動かして確認したり、ガイドのルールやプロンプトを自分のアプリへ直接応用したりできます。
- **商用機能と外部サービス**：承認機能やメール接続など商用ライセンスや外部サービスが必要な条件は該当テーマのみに適用され、他のテーマの妨げにはなりません。
- **複雑なテーマのサンプル**：今後公開する高度な権限管理、複雑な承認ルール、外部システム連携では、購買や経費、契約など内容に合った独立サンプルを用います。
