このページでは、ITAM アプリ `itam-lite` を作成します。以降のページはすべて、このアプリの上で開発を続けます。

## 1. アプリを作成するスキルをインストールする

```bash
npx skills@latest add nocobase/skills-v3 --skill nocobase-create-app -g
```

表示されたら、使っているコーディングツールを選びます。このスキルはアプリを作成するだけです。アプリができたあとは、アプリに付属する開発スキルが引き継ぎます。

## 2. エージェントにアプリを作成させる

空のディレクトリ `itam-lite` を作成し、その中でコーディングエージェントのセッションを始めます。

```prompt
現在のディレクトリに、データベースに SQLite を使う NocoBase 3 アプリを作成してください。起動したら、URL とサインイン用のアカウントを教えてください。
```

エージェントは Node.js と pnpm のバージョンを確認し、プロジェクトを作成し、依存関係をインストールし、設定を生成してから、アプリを起動して URL（たとえば `http://127.0.0.1:13000/main/`）とアカウントを伝えます。アプリを手動で作成する場合や問題が起きた場合は、Core の [アプリを作成する](../core/getting-started/create-app.md) を参照してください。

`nocobase` / `admin123` でサインインすると、ホームページが表示されます。

![サインイン後のホームページ](https://static-docs.nocobase.com/20261030-itam-lite-create-app-home.webp)

## 3. プロジェクト内の 4 つのもの

| 場所 | 内容 | 管理者 |
| --- | --- | --- |
| `AGENTS.md` | エージェントがあらゆる作業の前に読むルールと索引：コードの置き場所、プラグインからそのまま使う機能 | 人とエージェント。短く保ちます |
| `.agents/rules/` | 業務ルールや命名など、このアプリ独自の規約 | 人とエージェント。コードと一緒にコミットします |
| `.agents/skills/` | 依存関係から同期された開発スキル。インストールされたバージョンに一致します | 自動で同期されます。手で編集しないでください |
| App foundation | **System settings › App foundation** ページ。アプリが使っている Core の機能の一覧 | NocoBase |

ここで **App foundation** を開くと、データモデリング、ユーザーと組織、権限、通知、ワークフローと承認などの機能が表示されます。このあとデバイス台帳、デバイスの申請と承認、ロールと権限を構築するとき、エージェントはこれらをゼロから書かずにそのまま使います。

![App foundation](https://static-docs.nocobase.com/20261030-itam-lite-create-app-foundation.webp)

## 4. 最初のコミット

```prompt
Git リポジトリを初期化して、最初のコミットを行ってください。
```

`config.yml`（シークレットを含む）、SQLite のデータベース、`node_modules/`、`.agents/skills/` は、すでに `.gitignore` で除外されています。以降、エージェントはステップごとにコミットします。

**完了の目安**：管理者としてサインインするとホームページが表示され、`git log` に最初のコミットが表示されること。
