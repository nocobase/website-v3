設計書の最初のステップはデバイス台帳です。要件はすでに [設計書](https://github.com/nocobase/docs-examples-v3/blob/main/apps/itam-lite/docs/design.md) に書かれているので、プロンプトではそれを指し示すだけで済みます。

## 1. 依頼する

```prompt
docs/design.md のステップ 1、デバイス台帳を実装してください。このステップでは管理者だけが使います。ロールと権限はあとで扱います。
```

エージェントが構築したもの：

| 部分 | 内容 |
| --- | --- |
| テーブル | `devices` テーブルを作成するマイグレーション。資産タグに一意インデックス付き |
| API | `/api/devices` の一覧、作成、更新、削除。それぞれ個別に認可され、`/main/api/swagger` の API ドキュメントに掲載 |
| ページ | サイドバーの **Devices**：一覧、検索、作成と編集のダイアログ。英語と中国語の文言 |
| システム設定 | アプリ独自のルールに従い、**Users** と **Permission management** のページも有効化 |
| テスト | API テストとマイグレーションテスト。`pnpm typecheck` と `pnpm lint` が通過 |

## 2. 試す

ブラウザーを再読み込みして **Devices** を開き、いくつかのデバイスを登録します。資産タグが重複すると、フィールドの横に表示されます。

![デバイスを登録する](https://static-docs.nocobase.com/20261030-itam-lite-devices-new-device.webp)

しばらく使うと、2 つの問題が見つかります。

- 2 台のモニターが同じシリアル番号で登録され、どちらも保存されてしまった。
- デバイスが増えると、在庫のあるものだけを見たくなるが、絞り込む方法がない。

## 3. 修正を依頼する

```prompt
デバイス台帳を 2 点変更してください。
1. シリアル番号は一意にしてください（空欄は可）。既存の重複があれば、まず一覧で教えてください。自動では修正しないでください。
2. 一覧をステータスとカテゴリーで絞り込めるようにし、検索でシリアル番号も対象にしてください。
```

エージェントはまず既存のデータを確認し、`IT-2026-0002` と `IT-2026-0007` がどちらもシリアル番号 `CN0ABC123` であると報告しました。台帳でどちらか一方をデバイスに記載された実際のシリアル番号に変更してから、続けるようエージェントに伝えます。

エージェントは、シリアル番号に一意インデックスを付ける新しいマイグレーションを追加しました（実行済みのマイグレーションは編集しません）。重複がある場合、マイグレーションは停止して重複しているデバイスを一覧表示します。変更後：

![シリアル番号が重複しているときのメッセージ](https://static-docs.nocobase.com/20261030-itam-lite-devices-duplicate-serial.webp)

![ステータスで絞り込む](https://static-docs.nocobase.com/20261030-itam-lite-devices-filter-by-status.webp)

**完了の目安**：デバイスを作成、編集、削除でき、資産タグやシリアル番号が重複するとフィールドの横に表示され、一覧をステータスとカテゴリーで絞り込め、再読み込みしてもデータが残っていること。
