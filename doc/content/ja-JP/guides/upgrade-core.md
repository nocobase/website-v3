---
title: NocoBase Core をアップグレードする
metaDescription: アプリに組み込まれたアップグレード用のスキルで、NocoBase Core を最新バージョンにアップグレードします。先に計画を立て、確認後にマージし、テストを実行してデータを確認します。
---

アップグレードは、アプリに組み込まれた `nocobase-app-upgrade` スキルが行います。テンプレートの新旧のバージョンを比較し、業務コードを保ったまま、差分をファイルごとにアプリへマージします。

```prompt
NocoBase Core を最新バージョンにアップグレードしてください。先にアップグレード計画を示し、私が確認してから変更してください。
```

計画には、テンプレートで変更されたファイル、アプリ側でも変更されているファイルのマージ方法、依存関係とデータベースのマイグレーションの変更が一覧表示されます。確認すると、エージェントは新しいブランチでマージし、依存関係をインストールし、スキルを同期し、テストとビルドを実行し、データを確認してから、メインブランチにマージし戻します。

手動でのアップグレード手順と確認のチェックリストについては、[NocoBase Core をアップグレードする](../core/developing-apps/upgrade-nocobase-core.md) を参照してください。アップグレード後のリリースは、ほかの新しいリリースの公開と同じです。新しいイメージをビルドし、デプロイ先のディレクトリをバックアップしてから置き換えます。[新しいリリースを公開する](../core/tutorials/deploy-with-docker.md#新しいリリースを公開する) を参照してください。

**完了の条件**：`package.json` の `nocobase.defaultTemplateVersion` が新しいバージョンになり、テストとビルドが通過し、アップグレード前のデータがすべて残っていること。
