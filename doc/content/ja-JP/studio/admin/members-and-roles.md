description: "チームのアカウントとロールを管理します。招待、プロフィールの編集、アカウントの無効化、パスワードの再設定を行い、組み込みロールまたはカスタムロールで各メンバーができることを決めます。"
---

メンバーは **Settings › Members** で、ロールは **Settings › Roles** で管理します。エージェントは作業を開始した人の代わりに動作し、その人より多くの権限を持つことはないため、メンバーのロールは、そのメンバーのために働くエージェントができることも決めます。

## メンバー

**Settings › Members** には、すべてのアカウントとそのロールが一覧表示されます。ステータスで絞り込んだり、名前、ユーザー名、メールアドレスで検索したりできます。

- **招待**：**Invite members** をクリックします。[メンバーを招待する](../setup/invite.md) を参照してください。全員が招待によって Studio に参加し、セルフ登録はオフになっています。
- **ロール**：ロールを付与したり外したりします。新しいメンバーには、最初に参加したときに **Settings › General** で設定された **Default role for new members** が付与されます。
- **無効化と有効化**：メンバーがチームを離れたら、そのアカウントを無効にします。アカウントは削除されず、そのメンバーが開始した作業とその記録は保持されます。必要に応じて再び有効にできます。無効なアカウントにはロールを付与できません。
- **プロフィールの編集とパスワードの再設定**：ほかの人の名前、ユーザー名、メールアドレスを変更したり、パスワードを再設定したりします。自分のパスワードは **Account settings › Account and security** で変更します。

だれが何をできるか：

| 操作 | できる人 |
| --- | --- |
| アカウントとロールを見る | すべてのメンバー |
| メンバーを招待する | Admin と Owner |
| ロールを付与する、ロールを定義する | Admin と Owner |
| アカウントを無効にする、ほかの人のプロフィールを編集する、ほかの人のパスワードを再設定する | Owner |

Owner のアカウントを変更できるのは Owner だけで、Owner ロールの付与と剥奪も Owner だけができます。最後の Owner は、自分の Owner ロールを外せません。

## 組み込みロール

| ロール | できること |
| --- | --- |
| Member | すべてのページ。要件を出し、自分に関係するタスクで作業します。自分がリーダーのプロジェクトで設定とナレッジベースを管理します。個人ランタイムを接続し、自分の API キーを作成します。すべての設定を閲覧します |
| Admin | すべてのページ、すべての業務操作、すべての設定。共有ランタイムの接続、エージェントの有効化、デプロイ環境・Git 接続・組織の API キーの管理、ロールの付与と定義 |
| Owner | Admin ができるすべてのことに加え、アカウントの管理。アカウントの無効化、プロフィールの編集、パスワードの再設定 |

Studio のインストール時に作成される最初の管理者は Owner でもあり、システム管理者です。システム管理者はすべての権限を持ち、このアカウントのロールはここでは管理されません。

## カスタムロール

組み込みロールが合わない場合は、**Settings › Roles** で **New role** をクリックするか、既存のロールで **Duplicate as new role** を使って調整します。

ロールエディターには 3 つのグループがあります。

| グループ | 対象 |
| --- | --- |
| Pages | ロールが開けるページ |
| Settings | Git 接続、API キー、ロール、アカウントなど、ロールが閲覧または管理できる設定 |
| Business operations | タスク、プロジェクト、アプリ、ナレッジベースに対してロールができること。それぞれ **None**、**Related**、**All** の 3 段階のいずれかです |

**Related** の意味は操作によって異なり、エディターに具体的に説明されています。たとえば：

- ナレッジベースの編集：自分がリーダーのプロジェクトのナレッジスペース。システムナレッジには **All** が必要です。
- アプリのデプロイ：自分が作成したアプリと、自分がリーダーのプロジェクトにひも付いたアプリ。

Owner ロールはすべての権限を持ち、編集できません。組み込みロールは削除できません。まだだれかが持っているロールや、新しいメンバーの既定のロールになっているロールは、変更してからでないと削除できません。

> [!NOTE] ロールで付与できる権限に上限はない
> ロールを定義できる人は、自分のロールを含め、どのロールにもあらゆる権限を入れられます。「Give and take roles」と「Create, edit and delete roles」は、信頼できる人にだけ付与してください。
