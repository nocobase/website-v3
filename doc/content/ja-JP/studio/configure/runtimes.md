---
title: "ランタイム"
description: "実行リソース、ツールの状態、同時実行数、作業ディレクトリを管理します。"
---

ランタイムは、コーディングツール、モデルへのサインイン状態、実行リソースを提供します。Studio から分離した専用コンテナや仮想マシンをおすすめします。初回は[ランタイムを接続する](../setup/shared-runtimes.md)を参照してください。

![ランタイムの接続状態、利用範囲、実行容量](https://static-docs.nocobase.com/studio-en-runtimes-20261111-normal-2x.webp)

runner の登録、ログ、更新、削除は [nocobase-runner コマンド](../reference/runner.md)を参照してください。

## 利用範囲を選ぶ

| 範囲 | 対象 | 接続する人 |
| --- | --- | --- |
| 共有 | すべてのメンバーのタスク | 管理者 |
| 個人 | 所有者が開始した作業 | メンバー本人 |

個人用の設定は[個人ランタイム](../join/personal-runtime.md)を参照してください。共有ランタイムに限定した変数は、個人ランタイムには送られません。

## ツールと同時実行数を調整する

詳細画面で、名前、有効なコーディングツール、最大同時実行数を変更します。マシンのリソース、プロジェクトのビルド負荷、モデルの利用枠に合わせてください。初回は 1 から始められます。

ツールが **Login required** の場合は、サービスを実行するシステムユーザーでサインインし、再検出します。**Not installed** の場合は、インストール状況とサービスの PATH を確認してください。

## 状態確認と保守

実行マシンで、状態確認、停止、起動を行います。停止は実行中の作業を中断します。

```bash
nocobase-runner status
nocobase-runner stop
nocobase-runner start
```

ターミナルではツールを使えるのに、サービスが見つけられない場合は、そのターミナルからサービスを再インストールします。

```bash
nocobase-runner service install
```

runner は自動更新できます。手動では `nocobase-runner update` を使います。作業ディレクトリと実行履歴から、ディスク使用量や未プッシュの変更を調べられます。クリーンアップ前に、必要な変更をリモートリポジトリに保存してください。

## ランタイムを削除する

先に認証情報を失効させてから削除します。実行履歴は残ります。マシンで `nocobase-runner uninstall` を実行すると、バックグラウンドサービスとプログラムを削除できます。別のマシンは新しい認証情報で登録してください。
