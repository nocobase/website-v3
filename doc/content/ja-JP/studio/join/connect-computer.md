---
title: "自分の PC を接続する"
description: "Studio の My Agent から、自分の PC のコーディングツールを使います。"
---

自分の PC を接続すると、Studio の **My Agent** からコーディングツールと対話できます。ツールは許可したローカルフォルダー内で作業します。

ターミナルから Studio を管理するには [nb-studio](local-agent.md) を使います。キュー内の開発タスクをマシンに実行させるには、[ランタイムを接続](personal-runtime.md)してください。

## 接続する

1. PC に Claude Code や Codex などをインストールし、サインインします。
2. Studio の **My sessions** で **My Agent** を選びます。
3. **Connect your computer** の設定手順を、その PC のコーディングエージェントに渡します。
4. エージェントが示す URL でブラウザーのサインインを完了します。
5. **My computers** に戻り、接続と利用可能なツールを確認します。

![PC を接続し、My Agent からコーディングツールを使う](https://static-docs.nocobase.com/studio-en-guide-connect-computer-20261031.png)

設定時に `nb-studio` とバックグラウンド接続サービスをインストールします。Node.js 24 以降が必要で、macOS、Linux、Windows に対応しています。ダウンロードリンクは 30 分で失効します。必要に応じて再生成してください。

## 許可するフォルダーを選ぶ

**My computers** で許可するフォルダーを設定します。既定はホームディレクトリ全体ですが、特定の作業フォルダーに制限できます。セッション開始時に、フォルダーとコーディングツールを選びます。

エージェントは実行するシステムユーザーの権限を持ちます。プロジェクトの分離が必要な場合は、専用ユーザーや仮想マシンを使ってください。

## 接続が切れたとき

スリープ中や電源を切った PC では、セッションを継続できません。ネットワークとバックグラウンドサービスを復旧し、状態を確認してください。ブラウザーを閉じても、PC 上の実行は停止しません。

使わなくなった PC は **My computers** から削除し、ローカルエージェントにバックグラウンドサービスのアンインストールを依頼します。過去のセッション記録は残ります。
