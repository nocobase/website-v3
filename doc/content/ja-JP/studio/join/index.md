title: プロジェクトに参加する
description: 招待を受け、チームのエージェントとランタイムを使って最初の要件を完了させます。
---

管理者がプロジェクトを準備すれば、チームのエージェントとランタイムを使えます。Studio をデプロイしたり、自分の PC にコーディングツールをインストールしたりする必要はありません。

## 作業を始める

1. [招待を受けてサインインします](sign-in.md)。プロジェクトを開けることを確認します。
2. [最初の要件を一通り試します](../setup/first-request.md)。小さな要件を出し、開発を追い、結果を検収します。
3. [My issues](../use/my-tasks.md) で進捗を追い、あなたを待っている質問や結果を確認します。

Studio やプロジェクトの準備がまだの場合は、管理者に [インストールと設定](../setup/index.md) から始めてもらいましょう。

## タスクを追う

| 目的 | ガイド |
| --- | --- |
| タスクを作成する前にアイデアを相談する | [My sessions](../use/sessions.md) |
| エージェントが何をしているかを見る | [進捗を追う](../use/follow-progress.md) |
| 情報を提供する、または判断する | [質問に答える](../use/answer.md) |
| 結果を確認して変更をマージする | [結果を検収する](../use/accept.md) |

Studio で直接要件を相談するには、[Runner Agent と対話します](runner-agent.md)。

## 自分のツールを使う（任意）

ターミナルを使いたい場合は、[ローカルのコーディングエージェントから Studio を使います](local-agent.md)。Studio から自分の PC 上のエージェントと対話するには、[自分の PC を接続します](connect-computer.md)。
