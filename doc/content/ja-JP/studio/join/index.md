管理者がプロジェクトを準備すれば、要件を提出し、タスクの進捗を確認できます。開発作業はチームのエージェントがランタイム上で実行します。

Studio で [Runner Agent と対話する](runner-agent.md)か、`nb-studio` CLI をインストールして[ローカルのコーディングエージェントから Studio を使う](local-agent.md)ことをおすすめします。

## 作業を始める

1. [招待を受けてサインイン](sign-in.md)し、担当のプロジェクトを開けることを確認します。
2. [最初の要件を一通り試します](../setup/first-request.md)。小さな変更を依頼し、進捗を追って結果を検収します。
3. 日常の質問への回答や作業結果の確認には [My issues](../use/my-tasks.md) を使います。

Studio やプロジェクトがまだない場合は、管理者が[インストールと設定](../setup/index.md)から始めてください。

![My issues に判断待ちの事項、作業結果、進捗をまとめる](https://static-docs.nocobase.com/studio-en-guide-my-issues-20261031.png)

## 作業方法を選ぶ

| 目的 | 方法 |
| --- | --- |
| Studio で要件を相談し、プロジェクトを調べる | [Runner Agent と対話する](runner-agent.md) |
| CLI を通じてローカルの Claude Code や Codex でタスクを管理する | [ローカルのコーディングエージェントを使う](local-agent.md) |
| ブラウザーから自分の PC のコーディングツールを操作する | [自分の PC を接続する](connect-computer.md) |
| 自分のタスク用の実行リソースを提供する | [個人ランタイムを接続する](personal-runtime.md) |

Runner Agent とローカルのコーディングエージェントのどちらからも、チームの共有ランタイムにタスクを任せられます。自分の PC や個人ランタイムは必要に応じて接続します。

## タスクを追う

- [進捗を追う](../use/follow-progress.md)：現在のステップ、引き継ぎ、実行履歴を確認します。
- [質問に答える](../use/answer.md)：業務ルールを確認し、資料を補い、実行上の問題に対応します。
- [結果を検収する](../use/accept.md)：成果物を確認し、マージするか修正を依頼します。
