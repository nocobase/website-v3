---
title: "個人ランタイムを接続する"
description: "自分のコーディングツールと実行容量を、自分の作業に使います。"
---

個人ランタイムは、自分がサインインしたコーディングツールと契約を使い、自分のための作業を実行します。実行容量を増やしたい場合や、別のモデルを自分のタスクに使いたい場合に接続します。

## 準備する

[マシンの準備](../setup/shared-runtimes.md#マシンを準備する)に従って依存ソフトウェアを導入し、コーディングツールにサインインします。Studio から分離した専用コンテナや仮想マシンを使ってください。

## ランタイムを追加する

1. **Agent management › Runtimes** で **Add runtime** を選びます。
2. 利用範囲を **Personal** にし、インストール済みのツールを選びます。
3. マシンと契約の上限に合わせて同時実行数を設定します。
4. インストールコマンドを生成し、OS を選んで、その環境のコーディングエージェントにプロンプトを渡します。

コマンドには一回限りの認証情報が含まれます。期限が切れたら再生成してください。[マシンへのインストール](../setup/shared-runtimes.md#マシンにインストールする)も参照してください。

![個人ランタイムと接続するコーディングツールを選択](https://static-docs.nocobase.com/studio-en-personal-runtime-20261111-normal-2x.webp)

## 接続を確認する

ランタイムに **Personal** と **Online**、選択したツールに **Signed in** と表示されることを確認します。対応するエージェントを有効にすると、**Where it runs** にこのランタイムが表示されます。

## 実行できる作業

- 自分のために実行されるタスクのステップと、自分が開始した Runner Agent の会話。
- 個人ランタイムだけで利用できるエージェントは、その所有者のためにだけ動作します。
- 共有ランタイム限定の変数を使う作業は、個人ランタイムでは実行できません。

別のメンバーが自分のタスクに作業を依頼し、自分の個人ランタイムを使う場合は、Studio が確認を求めます。[個人ランタイムへの依頼](../use/answer.md#個人ランタイムへの依頼)を参照してください。

## ランタイムを管理する

詳細画面で名前、同時実行数、利用するツールを変更します。個人ランタイムを編集できるのは所有者だけです。管理者は必要に応じて共有に変更できます。

マシン上で作業を停止・再開します。

```bash
nocobase-runner stop
nocobase-runner start
```

使わなくなった場合は、認証情報を失効させてから削除します。実行履歴は残ります。マシンで `nocobase-runner uninstall` を実行してサービスを削除します。[ランタイムの設定](../configure/runtimes.md)も参照してください。
