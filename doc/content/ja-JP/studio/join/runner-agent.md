---
title: "Runner Agent と対話する"
description: "Studio の会話から要件を相談し、プロジェクトのコードを調べ、タスクを作成します。"
---

Runner Agent は、ランタイム上のコーディングツールとモデルの組み合わせです。**My sessions** で直接対話し、要件の整理、コードの調査、タスクの確認を依頼できます。

オンラインの[ランタイム](../configure/runtimes.md)と、有効な[エージェント](../configure/agents.md)が必要です。共有ランタイムを使う場合、自分の PC の接続は不要です。

## 会話を始める

1. **My sessions** で **Runner Agent** を選びます。
2. 会話を作成し、エージェントを選びます。
3. プロジェクトのコードを調べる場合は、最初のメッセージを送る前にプロジェクトを選びます。
4. 質問を送ります。

```prompt
このプロジェクトの仕入先スコアの計算方法を説明してください。コードは変更せず、既存のルールを調べてください。
```

![Runner Agent の会話と関連タスクを一緒に確認する](https://static-docs.nocobase.com/studio-en-guide-runner-session-20261031.png)

最初のメッセージを送ると、対象プロジェクトが固定されます。別のプロジェクトには新しい会話を作成してください。エージェントは選択したプロジェクトのコードを準備します。テキスト、画像、添付ファイルを送信でき、実行中のメッセージはキューに入ります。

## 相談内容をタスクにする

```prompt
合意したスコア計算の変更をタスクにしてください。まだ開始しないでください。
```

作成したタスクは会話に表示されます。要件を確認し、**Start** を選ぶとコーディネーターエージェントが実行を手配します。`#task-identifier` で既存の作業を関連付けられます。

会話を見られるのは自分だけです。タスクはプロジェクトの権限に従って共有され、状態の更新が会話にも反映されます。

## エージェントやランタイムを変更する

- **Change Agent**：実行中の作業と待機メッセージを処理してから変更します。会話履歴と関連タスクは残ります。
- **ランタイムがオフライン**：再接続を待つか、**Switch runtime** を選びます。新しいランタイムには会話履歴を渡します。未プッシュの変更は元のマシンに残ります。
- **利用できるエージェントがない**：ランタイムの接続、ツールへのサインイン、エージェントの有効化を確認します。

会話からプロジェクトの調査と変更ができます。プッシュや PR が必要な場合は明示的に依頼してください。正式な要件はタスクにし、チームで進捗を追って[検収](../use/accept.md)します。
