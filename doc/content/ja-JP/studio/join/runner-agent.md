---
title: Runner Agent と対話する
description: Studio で Runner Agent を選び、要件を相談し、プロジェクトを調べ、相談内容をタスクにします。
---

Runner Agent は、ランタイム上で利用できるコーディングツールとモデルです。Studio で直接対話して、要件を相談したり、プロジェクトを調べたり、タスクを追ったりできます。

チームには、オンラインの [ランタイム](../configure/runtimes.md) と有効な [エージェント](../configure/agents.md) が必要です。共有ランタイムがあれば、自分の PC を接続する必要はありません。

## 会話を始める

1. **My sessions** を開き、**Runner Agent** に切り替えます。
2. 会話を作成し、エージェントを選びます。
3. 特定のプロジェクトについて作業する場合は、最初のメッセージを送る前にプロジェクトを選びます。
4. 依頼を送ります。たとえば次のとおりです。

   ```prompt
   このプロジェクトで仕入先の評価がどのように計算されているかを説明してください。コードは変更せずに、現在のルールを説明してください。
   ```

エージェントはランタイム上で作業します。返信と実行の進捗は会話に残ります。続けて質問したり、画像や添付ファイルを追加したりできます。

## 相談内容をタスクにする

要件が明確になったら、エージェントにタスクの作成を依頼します。

```prompt
合意した仕入先の評価の変更をタスクにしてください。まだ開始しないでください。
```

ひも付いたタスクは会話の横に表示されます。要件を確認し、**Start** を選ぶと、コーディネーターが実行を手配します。同じ会話で進捗を追い、質問に答えられます。

既存のタスクを含めるには **Link task** を使います。会話はあなただけが見られます。タスクはプロジェクトの権限に従って共有されます。

## 会話を続ける、調整する

- **エージェントを変更する：** 先に現在の実行を終えるか止め、キューのメッセージを処理します。会話の履歴とひも付いたタスクは保持されます。
- **ランタイムがオフライン：** メッセージは元のランタイムが戻るまで待機します。**Switch runtime** を使うと、会話の履歴を条件に合う別のマシンに送ります。古い作業ディレクトリのファイルは移動されません。
- **利用できるエージェントがない：** ランタイムの状態、コーディングツールのサインイン、有効なエージェントを確認するよう管理者に依頼します。

作業が引き渡されたら、[結果を検収して](../use/accept.md) 変更をマージします。
