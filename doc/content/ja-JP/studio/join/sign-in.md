## 招待を受ける

管理者に招待されると、招待メールが届きます。Studio でまだメールが設定されていない場合は、管理者から招待リンクが直接送られてきます。リンクの有効期間は 7 日間です。

1. 招待リンクを開きます。ページには招待した人が表示され、メールアドレスはすでに入力されています。
2. 名前と、8 文字以上のパスワードを入力します。
3. **Create account and join** をクリックします。

サインインした状態で **My issues** が開きます。管理者が招待時にプロジェクトを選んでいれば、すでにそのメンバーになっています。

- そのメールアドレスにすでにアカウントがある場合は、**Go to sign in** をクリックし、そのアカウントで続けます。
- ブラウザーがすでに別のアカウントでサインインしている場合は、先にサインアウトしてから招待を受けます。
- リンクの期限が切れているか取り消されている場合は、ページにその旨が表示されます。招待した人に新しいリンクを送ってもらいましょう。

## サインインする

管理者から、`https://studio.example.com/main/` のような Studio のアドレスが伝えられます。サインインページで、ユーザー名またはメールアドレスとパスワードを入力します。

サインインページに **Forgot password?** が表示されていれば、メールアドレスを入力し、届いたリンクから新しいパスワードを設定します。表示されていなければ、Studio でまだメールが設定されていません。Owner に **Settings › Members** でパスワードを再設定してもらいましょう。

## Account settings

右上のアバターをクリックすると、アカウントメニューが開きます。

- **Account settings**：プロフィール、パスワード、表示設定、API キー、Git アカウント。
- **Use Studio in your agent**：エージェントにセットアップ手順を渡し、コマンドラインから Studio を操作できるようにします。[ローカルのコーディングエージェントから Studio を使う](local-agent.md) を参照してください。
- **Language** と **Theme**：その場で画面の言語とカラーモードを切り替えます。
- **Sign out**。

**Account settings** には 5 つのページがあります。

| ページ | できること |
| --- | --- |
| Profile | 表示名とユーザー名を変更します。表示名はタスクとコメントに表示されます。メールアドレスは読み取り専用です。変更するには Owner に依頼してください |
| Account and security | パスワードを変更します。保存すると、ほかのデバイスではサインアウトされます |
| Preferences | 画面の言語、カラーモード、表示密度。音によるリマインダーとデスクトップ通知。このデバイスのプッシュ通知。エージェントが行うコミットへの署名の方法 |
| API keys | スクリプトや CI があなたとして Studio を呼び出せるよう、自分のキーを作成します。[API キー](../admin/api-keys.md) を参照してください |
| Git | 自分のコードホストのアカウントを接続します。次のセクションを参照してください |

表示設定はアカウントに保存されるため、どのブラウザーでも同じ設定が使われます。プッシュ通知はデバイスごとに登録し、Studio が HTTPS で提供されている必要があります。iPhone では、先に Studio をホーム画面に追加し、そこから開いて登録します。[通知とプッシュ](../admin/notifications.md) を参照してください。

**Commit attribution** は既定でプロジェクトの設定に従います。エージェントは常にあなたとしてコミットし、エージェントを共同作成者としても記載するかどうかを選べます。

## 自分の Git アカウントを接続する

**Account settings › Git** を開き、**Connect GitHub**（GitLab の場合は対応するボタン）をクリックします。コードホストでサインインして認可を承認すると、戻ってきたときに Studio にアカウントが接続済みと表示されます。

接続すると、エージェントはあなたとしてコードをプッシュして PR を作成し、Studio で行うマージもあなたとして実行されるため、コードホスト上でだれの作業かがわかります。接続するまでは、ワークスペースの Git 接続（たとえばチームがインストールした GitHub App）が使われます。チーム全員が自分のアカウントを接続することをおすすめします。

ブラウザーでの認可が不便な場合は、**Other ways** をクリックします。

- **Connect with a code**：コードホストのページを開いてサインインし、Studio に表示されたコードを入力します。
- **Use a personal token**：コードホストで作成したトークンを貼り付けます。Studio はトークンを検証して暗号化し、二度と表示しません。

どの方法を使えるかは、管理者が **Settings › Integrations › Git** で決めます。ページに **Personal accounts can’t be connected yet** と表示される場合は、個人アカウントを許可するよう管理者に依頼してください。トークンの期限が切れると Studio はワークスペースの接続に戻るので、接続し直すだけで済みます。
