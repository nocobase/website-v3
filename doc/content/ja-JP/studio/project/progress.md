プロジェクトの状況を、タスクごとに尋ねて回る必要はありません。プロジェクトリーダーが見る場所は 2 つです。チーム全体は **Dashboard**、個々のプロジェクトはそのプロジェクトの **Overview** です。

## ダッシュボード

**Dashboard** は 3 つの問いに答えます。引き渡しは順調か、エージェントはどう働いているか、何が止まっているか。期間を選ぶと、すべての数値が前の期間と比較され、現在の期間の推移がグラフで表示されます。

ダッシュボードで集計されるのは、あなたが閲覧権限を持つプロジェクトとタスクだけです。

### 主要な数値

| 数値 | 計算方法 |
| --- | --- |
| Issues completed | 期間内に完了したタスク |
| Median cycle time | タスクの開始から完了までの時間の中央値 |
| Completed by agents | 期間内に完了したタスクのうち、エージェントが作業したものの割合 |
| Cost per issue | 期間内のエージェントの使用量を現在のモデル価格で計算し、完了したタスク数で割ったもの |
| Run success rate | 終了した実行のうち、正常に完了したものの割合 |
| Rework rate | エージェントが作業したタスクのうち、差し戻されたか、完了後に再オープンされたものの割合 |
| Runs per issue | エージェントが完了した各タスクの平均実行回数 |
| Human intervention | エージェントが責任者に確認するためにタスクを **Blocked** にした実行の割合 |
| Median queue wait | 作業がキューに入ってからランタイムが引き受けるまでの時間の中央値 |

数値にカーソルを合わせると、計算方法が表示されます。

いくつかの数値は組み合わせて読みましょう。差し戻し率が高い場合は、要件が十分に明確でないか、エージェントの **Good at** の記述やスキルの調整が必要なことを示しています。人の介入が多い場合は、要件に業務ルールが欠けていることを示しています。キューの待ち時間が長い場合は、ランタイムが足りません。[エージェントの稼働状況とモデルの使用量](usage.md) を参照してください。

### エージェントのパフォーマンス

日ごとのキューに入った実行を、結果別（完了、失敗、キャンセル、進行中）に表示し、エージェントチームの調子がわかるようにします。

### 要対応

今止まっているものや期限を過ぎたものだけを表示します。ブロック中のタスク、期限切れのタスク、検収を長く待っているタスク、過去 24 時間に失敗した実行です。すべて順調なら、このセクションは空です。

### プロジェクト別

閲覧できるすべてのプロジェクトについて、これまでにどれだけ完了したか、期間内にどれだけ引き渡されたかを表示します。

## プロジェクトの概要

プロジェクトを開くと、**Overview** には次の内容があります。

- **主要な数値とステータスの内訳**：タスクの総数、進行中、検収待ち、完了の数。
- **Next steps**：リポジトリの追加、初期化の完了、プレビュー用 CI の接続など、プロジェクトにまだ必要な準備。すべて完了すると、このセクションは消えます。
- **Releases**：各環境で動いているバージョン。[リリースの承認とロールバック](release.md) を参照してください。
- **Merged, not released**：完了しているが、変更がまだ本番に反映されていないタスク。
