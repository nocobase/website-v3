**Releases** でプロジェクトを選び、本番カードの **Deployment guide** を開きます。プロジェクト責任者はバージョンを選び、デプロイコマンドやコーディングエージェント用のプロンプトを取得できます。

![本番のデプロイ手順を取得し、デプロイしたバージョンを記録する](https://static-docs.nocobase.com/studio-en-production-guide-20261111-normal-2x.webp)

## 準備してデプロイする

対象バージョンの成果物が利用可能か確認します。ガイドは記録済みのバージョンに応じて、初回インストールまたは更新の手順を表示します。

| 方法 | デプロイ先の前提 | デプロイ |
| --- | --- | --- |
| Docker | Docker と Compose | 成果物からイメージをビルドするか、登録済みイメージを取得して起動 |
| Installer | Node.js 24 と PM2 | `@nocobase/app-installer` でインストール・更新 |

本番イメージのビルドとデプロイは、自社のインフラで行います。本番の設定、データベース、シークレットはチームで管理してください。更新前にデータベースをバックアップし、更新後にサインインと主要業務を確認します。

自動化する場合は、対象サーバーにアクセスできるコーディングエージェントにガイドを渡します。Studio 自体は本番デプロイを実行しません。

## 本番バージョンを記録する

デプロイを確認したら、ガイドの下部またはバージョンの本番記録操作から登録します。Studio は、本番に含まれる完了タスクを計算します。

記録はチームが実施したデプロイの結果を示します。デプロイを開始する操作ではありません。

## ロールバックする

本番インフラで以前のイメージを復元するか、Installer のロールバックを使います。データベースのマイグレーションが行われた場合は、必要に応じて対応するバックアップも復元してください。動作を確認してから、復元したバージョンを Studio に記録します。
