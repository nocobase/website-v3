---
title: 品質指標
description: 指標の出所を理解し、比較可能な範囲で結果を確認します。
---

**Quality › Metrics** でテストの種類と期間を選び、結果と推移を確認します。概要にも直近の評価項目の結果が表示されます。

![記録された結果と未検証の項目を区別する指標](https://static-docs.nocobase.com/studio-en-quality-metrics-20261111-normal-2x.webp)

## 指標の定義

| データ | 出所 |
| --- | --- |
| タスク、シナリオ、確認項目の結果 | 各評価項目から提出された結論と証拠 |
| 自動テストの成功、失敗、スキップ、時間 | Vitest、Playwright などのテストレポート |
| 依存関係の脆弱性 | 依存関係の監査結果。実行用と開発用を区別 |
| 権限問題、性能リスク、コード品質の問題 | 対応する評価項目の確認結果 |
| フォローアップタスク | 関連する不具合、質問、テストケース、シナリオ、整理作業 |

レポートがなければ該当する指標もありません。空欄は問題がゼロという意味ではありません。未検証と対象外も成功には数えません。

## 推移と明細

指標を開くと関連するテスト、シナリオ、問題を確認できます。比較前に、種類、範囲、コミット、評価項目が一致しているか確かめます。

シナリオの追加や削除で総数は変わります。同じ識別子のシナリオはテスト間で比較できます。件数の増減だけで判断せず、範囲の変化と[レポートの証拠](reports.md)を確認します。
