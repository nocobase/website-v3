Studio EE の **Quality** では、プロジェクトのテスト、コアシナリオ、レポート、フォローアップをまとめて確認できます。Studio EE の入手は[お問い合わせください](../setup/install.md)。

**Development › Quality** でプロジェクトを選びます。[設定](settings.md)を確認してから[テストを開始](runs.md)します。新規プロジェクトでは自動実行は無効です。

![サンプルプロジェクトの機能、権限、セキュリティ、パフォーマンス、コード品質の結果](https://static-docs.nocobase.com/studio-en-quality-sample-20261111-normal-2x.webp)

## テストの種類

| 種類 | 対象と実行方法 |
| --- | --- |
| Daily | 完了済みで未検証の業務タスクを定時に確認。初回や長期間停止後は最大で直近 3 日間が対象 |
| Release | リリース待ちのタスクを確認。手動または設定した件数で実行 |
| Project | プロジェクト全体のコアシナリオを確認。手動、毎週、毎月の実行に対応 |
| Custom | 完了済みの業務タスクを選択するか、プロジェクト全体のコードを確認 |

Daily は定時実行のみです。今すぐ指定タスクを確認する場合は Custom を使います。

## テストとタスクの関係

テストごとに通常のタスクを作成します。対象範囲、固定した Skill のバージョン、実行履歴を保持し、タスクの納品レポートで受け入れます。

エージェントは評価項目ごとに確認し、発見事項をフォローアップタスクに関連付けます。テストの完了だけでは問題は解決しません。[フォローアップ](follow-ups.md)で対応し、後続のテストで修正を確認します。

PR チェックとコードレビューは個々の変更を検証します。プロジェクトの品質テストは、より広い範囲を継続的に確認します。[チェックとレビュー](../project/checks-and-review.md)も参照してください。
