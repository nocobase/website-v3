---
title: 品質基準
description: 五つの評価項目の指標、既定の合格基準、テスト方法と、プロジェクトでの調整方法。
---

Studio には評価項目ごとに指標と合格基準が用意されています。テストではツールを実行して各指標のテスト結果を得て、サーバーが基準と照らし合わせて合格かどうかを判定します。

**プロジェクトは独自の基準を定義できます**：性能予算は[品質テストの設定](settings.md#プロジェクトの基準を調整する)で変更します。その他の確認方法と判定ルールは評価項目の Skill が定義しており、Skill の差し替えや評価項目の追加で変更できます。

## 機能

| 指標 | 基準 | ツール | 方法 |
| --- | --- | --- | --- |
| タスクシナリオの失敗数 | = 0 | Vitest、Playwright、ブラウザー | ルールに沿ってタスクをシナリオに分け、一つずつ検証 |
| コアシナリオの失敗数 | = 0 | Vitest、Playwright、ブラウザー | Project テストでコアシナリオを一つずつ検証 |
| 製品不具合による自動テストの失敗数 | = 0 | Vitest、Playwright | 既存の自動テストを実行し、失敗の原因を一つずつ分析 |

## 権限

| 指標 | 基準 | ツール | 方法 |
| --- | --- | --- | --- |
| 未ログインでの権限違反数 | = 0 | 権限エンジン | 匿名ですべての API にアクセス |
| 読み取り権限違反数 | = 0 | 権限エンジン | 権限のないアカウントでデータを読み、見えてはいけない内容がないか確認 |
| 書き込み権限違反数 | = 0 | 権限エンジン | 権限のないアカウントで書き込み、再読込して変更されていないか確認 |
| 正常アクセスの対照失敗数 | = 0 | 権限エンジン | 権限のあるアカウントで同じ要求を行い、正常にアクセスできることを確認 |
| 権限未宣言の API 数 | = 0 | Vitest | タスク CI ですべての API が必要な権限を宣言しているか確認 |

## セキュリティ

| 指標 | 基準 | ツール | 方法 |
| --- | --- | --- | --- |
| 重大な依存関係の脆弱性数 | = 0 | pnpm audit | すべての依存関係を監査 |
| 高リスクの依存関係の脆弱性数 | = 0 | pnpm audit | すべての依存関係を監査 |
| 秘密情報の漏えい数 | = 0 | gitleaks | 現在のコードと Git 履歴を検査 |
| 重大なコードのセキュリティ問題数 | = 0 | Agent | セキュリティチェックリストでコードをレビュー |
| 高リスクのコードのセキュリティ問題数 | = 0 | Agent | セキュリティチェックリストでコードをレビュー |
| 受動スキャンの高リスク警告数 | = 0 | OWASP ZAP | すべての API のヘッダー、Cookie、情報漏えいを確認 |
| 能動スキャンの高リスク警告数 | = 0 | OWASP ZAP | すべての API にインジェクション、XSS などの攻撃テストを実施 |

セキュリティテストはテスト自身が用意した隔離環境で行い、チームが使用中のシステムはスキャンしません。権限違反は権限の評価項目で確認します。

## パフォーマンス

| 指標 | 基準 | ツール | 方法 |
| --- | --- | --- | --- |
| 初期表示の JS サイズ | ≤ 2 MB | Lighthouse | 画面の読み込みを実測 |
| API の P95 時間 | ≤ 500 ms | autocannon | 画面が使う API を実測。API ごとに 10 回測定 |
| API の応答サイズ | ≤ 500 KB | 採取スクリプト | API ごとの応答サイズを記録 |
| 要求ごとの SQL 数 | ≤ 20 | PostgreSQL | 要求ごとに発行される SQL を集計 |
| 最も遅い SQL の時間 | ≤ 50 ms | PostgreSQL（`EXPLAIN`） | 遅い SQL の実行計画を確認 |

これらは既定の予算で、プロジェクトは品質テストの設定で変更できます。

## コード品質

| 指標 | 基準 | ツール | 方法 |
| --- | --- | --- | --- |
| 重複率 | ≤ 3% | jscpd | 重複したコードを検出 |
| 複雑度 > 50 の新規関数数 | = 0 | eslint-plugin-sonarjs | 関数ごとの認知的複雑度を計算 |
| 新規の未使用ファイル数 | = 0 | knip | どこからも参照されないファイルを検出 |
| 新規の未使用依存関係数 | = 0 | knip | 使われていない依存関係を検出 |
| 新規循環依存数 | = 0 | dependency-cruiser | モジュール間のインポート関係を分析 |
| Agent レビューの高レベル問題数 | = 0 | Agent | モジュールごとに設計、プロジェクト規約、テストの価値を確認 |

コード品質は**新規**部分だけを判定します。既存コードの問題は別に集計し、今回の結論には影響しません。lint と型チェックは CI で実施し、この評価項目では確認しません。
