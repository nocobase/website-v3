## タスクのステータス

すべてのタスクは、6 つの固定のステータスのいずれかにあります。プロジェクトでステータスを追加、名前変更、削除することはできません。

| ステータス | 意味 | タスクをここに移す人 |
| --- | --- | --- |
| Backlog | まだ始まっていない。エージェントは手を付けません | 人、またはタスクの作成時に **Later** を選んだ場合 |
| In progress | エージェントチームが作業中 | **Start** をクリックした人、または返信を受けて作業を続けるコーディネーターエージェント |
| Blocked | タスク責任者の判断を待っている | 質問するときのコーディネーターエージェント、または実行を止めた人 |
| In review | 引き渡し済みで、タスク責任者の検収を待っている | 引き渡すときのコーディネーターエージェント |
| Done | 検収済み | タスクにひも付いたすべての PR がマージされたときに自動で、または人 |
| Cancelled | 不要になった | 人 |

- 人はタスクを任意のステータスに移せます。
- コーディネーターエージェントがタスクを移すのは In progress、Blocked、In review の間だけで、Blocked か In review に移すたびに、責任者に何を求めているかを伝えます。タスクを Done や Cancelled に移すことはありません。
- 実行エージェントはタスクのステータスを変更しません。
- タスクが Blocked か In review に移ると、責任者に通知されます。

タスクを開始すると、コーディネーターエージェントが実行者になります。開始できるのは、タスク責任者か、タスクを編集できる人だけです。実行者が人またはだれもいないタスクは、エージェントが作業する前に開始する必要があり、コメントでエージェントにメンションしても、それを回避することはできません。

## 組み込みロールができること

「関係する」の意味は対象によって異なります。表の下の注記を参照してください。

| 操作 | Member | Admin と Owner |
| --- | --- | --- |
| プロジェクトとタスクを見る | 関係するもの | すべて |
| プロジェクトを作成する | できる | できる |
| プロジェクトの設定を管理する | 自分がリーダーのプロジェクト | すべて |
| プロジェクトを削除する | できない | できる |
| タスクの作成、編集、コメント、クローズ、責任者の変更 | 関係するもの | すべて |
| タスクを削除する | できない | できる |
| エージェントを変更する | 自分のもの | すべて |
| アプリを見る、設定する、デプロイする | 自分が作成したアプリと、自分がリーダーのプロジェクトにひも付いたアプリ | すべて |
| アプリの作成と削除、保護された環境へのデプロイ | できない | できる |
| ナレッジベースを読む、変更を提案する | 閲覧できるプロジェクトとシステムナレッジ | すべて |
| ナレッジベースを編集する、その権限を管理する | 自分がリーダーのプロジェクト | すべて |
| 設定を見る | できる。ただし組織の API キー、Git 接続、ナレッジベースの検索設定を除く | できる |
| 設定を変更する：エージェント、ランタイム、デプロイ環境、Git 接続、組織の API キー | できない | できる |
| 個人ランタイムを接続する、自分の API キーを作成する | できる | できる |
| メンバーを招待する、ロールを付与・定義する | できない | できる |
| アカウントを無効にする、ほかの人のパスワードを再設定する | できない | Owner のみ |

「関係する」タスクとプロジェクトとは、自分が所属するプロジェクトのものに加え、自分が責任者、作成者、作業者であるタスクや、自分がフォローしているタスクです。カスタムロールでは、必要に応じてこれらの権限を組み合わせられます。[メンバーとロール](../admin/members-and-roles.md) を参照してください。

## エージェントができること

- エージェントは作業を開始した人の代わりに動作し、その人より多くの権限を持つことはありません。コーディネーターエージェントと、それが手配するすべてのステップは、タスク責任者のために動作します。セッション内のエージェントはあなたのために動作します。
- 実行エージェントはタスクのブランチでコミット、プッシュ、PR の作成ができますが、すでにプッシュされた履歴は書き換えられず、保護ブランチはコードホストが守ります。
- リリース管理では、エージェントができるのはせいぜいアプリの閲覧、ログの読み取り、保護されていない環境へのデプロイまでです。アプリの変更や削除、保護された環境へのデプロイはできません。
- エージェントはナレッジベースに書き込むことも、変更を提案することもできません。

人だけができること：

- タスクの検収と PR のマージ。
- デプロイリクエストの承認。
- メンバー、ロール、API キーの管理。
