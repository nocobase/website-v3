---
title: "PR プレビュー"
description: "PR のアプリを開き、マージ前に変更を検証します。"
---

PR プレビューでは特定のコミットのアプリを実行します。リポジトリの **Previews** で **Agent build**、**CI build**、**No build** から選びます。設定手順は[リポジトリのチェックと CI](../configure/checks.md)を参照してください。

## プレビューを開く

タスクの **Code & previews** で URL、コミット、ビルド状態を確認します。**Releases › Previews** には、選択したプロジェクトの全プレビューが表示されます。

![PR プレビューとビルド状態](https://static-docs.nocobase.com/studio-en-previews-20261111-normal-2x.webp)

新しいコミットは、ビルドが完了するとプレビューに反映されます。検収前に、マージする変更と一致することを確認してください。

環境でサンプルデータの読み込みを有効にすると、初回デプロイ時も再デプロイ時も、未適用のサンプルが読み込まれます。個別のアプリで無効にするには、アプリの変数に `APP_SAMPLE_DATA=false` を設定し、**Apply & restart** を選びます。

プレビューの起動後、タスクを編集できる人はタスク上部の PR 行で **Account** を選び、初期管理者のログイン情報をコピーできます。必須変数が不足している場合は、案内に従ってプレビュー環境または個別アプリに設定します。

## プレビューを省略する

タスクのプロパティで **No preview needed** を有効にします。エージェントが PR に `no-preview` ラベルを付け、生成された CI テンプレートがそれを認識します。すでにあるプレビューは、この設定では自動削除しません。

## ライフサイクル

以下の既定値は[ホスト環境](../admin/environments.md)で変更できます。

| 条件 | 動作 |
| --- | --- |
| 10 分間アクセスなし | プロセスを停止し、次のアクセスで起動 |
| 24 時間アクセスなし | 休止し、展開ファイルを削除。設定とデータは保持 |
| PR のマージ・クローズ、またはプレビューの破棄 | プレビューとデータを削除 |

既定の上限は 20 件です。休止したアプリは、次回アクセス時の準備に時間がかかります。

プレビューは Studio が起動するアプリのサブプロセスです。チームで使う場合は、専用ドメインと権限を制限したシステムユーザーを設定してください。[設定リファレンス](../reference/config.md)を参照してください。

Studio 内のアプリはホストプロセスのメモリーを共有します。起動前に空き容量を確認し、安全に停止できるアイドル状態のアプリを優先して停止します。解放できない場合は容量不足が表示されます。時間を置いて再試行するか、ホストのリソースを調整してください。
