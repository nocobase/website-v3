## タスクのプレビューを開く

1. タスクの **Code & previews** で確認したい PR を探します。
2. プレビューのコミットを確認します。PR に新しい変更がある場合は、そのビルドの公開を待ちます。
3. プレビューアプリを開きます。ログインが必要な場合、タスクを編集できるメンバーはタスク上部の PR 行の **Account** から初期管理者のログイン情報をコピーできます。

![PR プレビューに、ビルドの状況とアクセス用リンクが表示されます](https://static-docs.nocobase.com/studio-en-req-preview-20261111-normal-2x.webp)

アプリで納品レポートの受け入れシナリオを確認します。その後、[タスクの検収](../use/accept.md)に戻って承認するか、修正を依頼します。

休止中のプレビューは次のアクセスで起動します。PR がマージまたはクローズされると、そのプレビューアプリは削除されます。[ホスト環境](../admin/environments.md#プレビューアプリを管理する)を参照してください。

## プレビューを省略する

タスクのプロパティで **No preview needed** を有効にします。エージェントが PR に `no-preview` ラベルを付け、生成された CI テンプレートがそれを認識します。すでにあるプレビューは、この設定では自動削除しません。

リポジトリの既定値を変更するには、[PR プレビューの設定](../configure/pr-previews.md)を参照してください。
