タスクの詳細には、現在の実行、次のステップ、作業結果がまとまっています。要件の補足や変更はコメントで伝えます。

## タスクの詳細

![誰が作業しているか、次に何をするかを確認する](https://static-docs.nocobase.com/studio-en-guide-task-progress-20261031.png)

| 項目 | 内容 |
| --- | --- |
| Now | 実際の実行状態。エージェント、ランタイム、待機理由 |
| Next | コーディネーターエージェントの次のステップ |
| Needs you | 質問や検収依頼と対応操作 |
| Delivery report | 変更、検証、受け入れ基準 |
| Properties | 責任者、実行担当、優先度、ラベル、日付 |

**Activity** にはコメントと状態変更が残ります。既定は会話のみで、**All** を選ぶとシステム記録も表示します。**Description** は要件、**Code & previews** は PR とチェック、**Runs** はエージェントの実行記録です。サブタスクがあれば表示されます。

## コメントで伝える

- **Comment**：要件を追加し、質問に答え、エージェントを `@` で指定します。関連するエージェントとタスクの実行担当を起動します。
- **Note**：エージェントを起動せず、情報を記録します。
- **Reply**：元のコメントの下で議論を続けます。

```prompt
仕入先を停止しても、既存注文の閲覧と入荷処理はできるようにしてください。禁止するのは新規注文だけです。この動作に修正してください。
```

変更した要件は後続の作業に影響します。変更せずに相談だけしたい場合は、明示してください。

## エージェントに聞く

**Ask agent** はタスクの背景を含む個人の会話を開きます。阻害要因の調査や変更内容の理解に使えます。プロジェクトメンバーと共有する結論は、タスクのコメントにも記録してください。

## 実行履歴

![各実行のエージェント、状態、時間、記録を確認する](https://static-docs.nocobase.com/studio-en-guide-runs-20261031.png)

| 操作 | 用途 |
| --- | --- |
| View transcript | 実行過程と結果を読む |
| View full prompt | エージェントに渡された背景を確認する |
| Stop | 実行の停止を依頼する。既存の変更は元に戻さない |
| Retry | 失敗した実行を再びキューに入れる |

停止後は、済んだ作業を確認してから続け方を伝えてください。[実行の失敗](answer.md#実行の失敗)を参照してください。

## プロジェクト全体の進捗

プロジェクト内のタスクと阻害要因は[プロジェクトの進捗](../project/progress.md)、実行容量と使用量は[作業量とモデル使用量](../project/usage.md)で確認できます。
