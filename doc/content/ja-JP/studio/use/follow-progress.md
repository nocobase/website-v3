エージェントチームがタスクを進めている間、待機したり何度も尋ねたりする必要はありません。タスクページを開けば、どこまで進んでいて次に何をするかがわかり、伝えたいことがあればタスク上でそのまま伝えられます。

## タスクページ

タスクページは、一覧、ボード、リンクのどこから開いても同じです。

::figure req-now | タスクの概要：Now、Up next、プロパティ、ひも付いた PR

**最上部の行** には、一覧内でのタスクの位置、キー（クリックするとリンクをコピー）、プロジェクトが表示されます。右側には、ステータス、フォローの星、**Ask agent**、その他の操作があります。

**概要**：

- **Now**：タスクが実際に何を待っているかを Studio が書きます。たとえば「Codex · GPT-6.1 Sol working · 8 min · server-01」「Waiting for a runtime」「Waiting for the PR's checks」「Waiting for Zhou Hang to accept」です。この行は、人やエージェントが書いた内容ではなく、事実から Studio が生成します。
- **Up next**：コーディネーターエージェントが計画している次のステップ。
- **Needs you**：タスクがブロック中または検収待ちで、あなたの判断を待っているときに表示されます。何をすべきかが書かれ、その場で操作するためのボタンがあります。[エージェントの質問に答える](answer.md) と [結果を検収する](accept.md) を参照してください。
- **Delivery report**：コーディネーターエージェントが作業を検収に引き渡すときに提出するもので、次の引き渡しで置き換えられるまで残ります。

**プロパティ**：優先度、責任者、実行者に加え、**More properties** にラベル、プロジェクト、開始日と期日、通知などがあります。

**タブ**：

| タブ | 内容 |
| --- | --- |
| Activity | コメント、引き継ぎ、ステータスの変更。既定では **Conversation only** を表示します。システムの記録も見るには **All** に切り替えます。 |
| Description | タスクの説明。 |
| Sub-issues | サブタスクとそのステータス。 |
| Code and deployments | ひも付いた PR、チェック結果、変更。 |
| Runs | このタスクでエージェントが行ったすべての実行。 |

## コメントでエージェントと話す

タスク下部の入力欄に書きます。入力には 2 種類あります。

- **Comment**：全員に表示されます。メンションしたエージェント、返信先のコメントを書いたエージェント、タスクの実行者（通常はコーディネーターエージェント）を起動します。その時点でエージェントが実行中なら、コメントはそのエージェントに直接届きます。
- **Note**：人だけのための記録です。どのエージェントも起動しません。

::figure composer | コメントはエージェントを起動し、ノートは人だけのためのものです

よくある使い方：

- 要件を追加・変更する：コメントを書くだけで、コーディネーターエージェントが計画を調整します。
- 特定のエージェントに特定の質問をする：コメントでメンションします。エージェントは聞かれたことだけに答え、タスクのステータスは変えません。
- コメントに返信する：そのコメントの下に返信すると、議論が 1 つのスレッドにまとまります。

## Ask agent

タスクページ右上の **Ask agent** を使うと、エージェントパネルが開き、このタスクについてのセッションが始まります。「このタスクはどこで止まっているか」「この PR は何を変えるのか」といった質問に向いています。セッション内のエージェントはあなたの身元と権限で動作し、あなたが頼んだことだけを行います。[My sessions](sessions.md) を参照してください。

## 実行記録

**Runs** タブには、タスクのすべての実行が一覧表示されます。どのエージェントが、どのランタイムで、何回目の試行で実行したか、その結果と使用量です。

::figure runs | Runs：トランスクリプトとプロンプトを表示したり、実行中の実行を止めたりできます

- **View transcript**：この実行でエージェントが行ったことの完全な記録。
- **View full prompt**：今回エージェントが受け取ったすべての内容。なぜそのように動いたのかを理解するのに役立ちます。
- **Stop**：実行中の実行を止め、すでに行われた変更は残します。タスクは **Blocked** に移り、どう続けるかをあなたがコメントで伝えるまでエージェントの作業は一時停止します。
- **Retry**：失敗した実行をもう一度キューに入れます。

## タスクを引き取る

自分で作業するには、自分を実行者にします。キューにあるエージェントの作業は取り下げられ、実行中の実行には停止が求められます。あとからエージェントチームに戻すには、**Hand over to the lead agent to start** をクリックします。

## プロジェクト全体を見る

プロジェクト全体の進み具合、止まっているもの、コストを確認するには、[プロジェクトの進捗](../project/progress.md) と [エージェントの稼働状況とモデルの使用量](../project/usage.md) を参照してください。
