---

トップバーのアイコンから受信トレイを開きます。タスクの判断は **My issues**、エージェントの会話への回答は **My sessions** で行います。

## 更新を確認する場所

| 入口 | 内容 |
| --- | --- |
| My issues | 検収、ブロック、実行失敗、責任者の引き継ぎ |
| My sessions | エージェントの返信、会話中の質問、権限の要求 |
| Inbox | 人のコメント、メンション、割り当て、タスク以外のシステム通知と判断 |

![受信トレイでメッセージを読み、関連する作業を開く](https://static-docs.nocobase.com/studio-en-guide-inbox-20261031.png)

## 受信トレイの表示

- **All**：メッセージと判断事項。
- **Needs my decision**：タスク以外の未対応の判断。
- **Notifications**：情報通知。

<kbd>J</kbd> / <kbd>K</kbd> で項目を移動します。既読や削除は自分の受信トレイにだけ反映され、タスクは完了しません。

## 通知方法

**Account settings › Preferences** で設定します。

| 方法 | 用途 |
| --- | --- |
| Sound | Studio が前面にあるときの新しい対応事項、返信、メンション |
| Desktop notifications | Studio が背面にあるときのブラウザー通知。ブラウザーの許可が必要 |
| Push notifications | ページを閉じていても購読端末に通知。管理者の設定が必要 |

![個人設定で通知方法を選ぶ](https://static-docs.nocobase.com/studio-en-guide-preferences-20261031.png)

表示中のタスクや会話の通知は抑制されます。ナビゲーションのバッジは、その入口の未対応・未読件数を示します。

## 携帯端末で購読する

Studio は HTTPS で公開する必要があります。端末ごとに購読してください。iOS/iPadOS 16.4 以降の iPhone・iPad は、Safari からホーム画面に追加し、そこから開いて購読します。

購読できない場合は、[通知とプッシュ](../admin/notifications.md)でサーバー設定とブラウザーの権限を確認してください。

## タスクを購読する

タスクのプロパティで購読・解除します。作業一覧に残したい場合はフォローの星を使います。[タスクをフォローする](my-tasks.md#タスクをフォローする)を参照してください。
