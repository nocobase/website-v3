## 何がどこに届くか

| | 内容 |
| --- | --- |
| **My issues** | タスクであなたを待っている判断。結果の検収、質問への回答、失敗した実行への対応、引き継がれたタスクの引き取りです。すべてタスクページで対応します。[My issues](my-tasks.md) を参照してください |
| 受信トレイ | 同僚からのコメント、メンション、割り当てと、タスク以外の事柄。あなたの承認を待っているデプロイのリクエスト、デプロイの結果と失敗、ナレッジベースの変更提案、ランタイムのお知らせなどです |

上部バーの受信トレイのアイコンから受信トレイを開きます。

## 受信トレイのビュー

| ビュー | 表示するもの |
| --- | --- |
| All | すべてのメッセージ |
| To decide | デプロイの承認や、ナレッジベースの変更提案を受け入れるかどうかなど、あなたの判断が必要なもの |
| Notifications | 知っておくだけでよいメッセージ |

<kbd>J</kbd> / <kbd>K</kbd> で一覧を上下に移動します。対応済みの項目は自動で閉じます。既読にしたり削除したりしても、影響するのは自分の受信トレイだけです。

## リマインダー

新しく何かがあなたを待っているとき：

- サイドバーの **My issues** と **My sessions** の横、上部バー、ブラウザーのタブのタイトルに件数が表示されます。
- 音によるリマインダーがオンなら、チャイムが鳴ります。今見ているタスクやセッションについては、改めて通知されません。

右上のアカウントメニューから **Account settings › Preferences** に進み、リマインダーのセクションを調整します。

- **Sound reminder**：オンまたはオフ。
- **Desktop notifications**：既定ではオフです。オンにすると、ブラウザーが許可を求めます。ブラウザーにブロックされる場合は、ブラウザーのサイト設定で通知を許可してください。
- **Push notifications**：Studio を開いていなくても、スマートフォンや別の PC にリマインダーが届きます。デバイスごとに、このセクションから個別に登録します。

> [!NOTE] スマートフォンでプッシュ通知を登録する
> Android では、Chrome で Studio を開いて直接登録します。iPhone と iPad では iOS または iPadOS 16.4 以降が必要です。Safari の共有メニューで先に **Add to Home Screen**（ホーム画面に追加）を選び、ホーム画面から Studio を開いて登録します。プッシュ通知には、Studio が HTTPS で提供され、管理者がプッシュ通知を設定している必要があります。

## タスクを購読する

タスクページの **More properties** にある **Notifications** に、このタスクについて通知を受け取る人が表示されます。**Subscribe** または **Unsubscribe** をクリックして、自分が受け取るかどうかを選びます。

タスクを常に目に入る場所に置いておきたい場合は、フォローの星を使います。フォローしたタスクは **My issues** の先頭に表示されます。
