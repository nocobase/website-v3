状況を知るために、プロジェクトごと、ターミナルごとに見て回る必要はありません。すべてのプロジェクトであなたに関係するタスクが **My issues** に集まります。エージェントがあなたに質問への回答、結果の検収、失敗した実行への対応を求めると、そのタスクが先頭に移ります。作業をセッションごとに追いたい場合は、[My sessions](sessions.md) を参照してください。

## ここに表示されるタスク

**My issues** には、あなたが責任者のタスクと、あなた自身が作業しているタスクが、それぞれ 1 回ずつ表示されます。あなたがフォローしているタスクも、責任者がだれであってもここに表示されます。

サイドバーの **My issues** の横の数字は、今あなたを待っているものの数です。セッションで待っている確認や、タスク以外の判断も含みます。

::figure my-tasks-list | My issues はだれの番かでグループ分けされ、各行にあなたがすべきことが表示されます

## だれの番かでグループ分け

上から順に次のとおりです。

| グループ | 内容 |
| --- | --- |
| Following | あなたがフォローしているタスク。最上部に表示され、ほかの人による新しい更新の数が示されます。 |
| Waiting for you | 今あなたの判断が必要なタスク。待っている時間が長いものから表示されます。 |
| In progress | エージェントやほかの人が進めているタスク。 |
| Waiting for others | 検収待ちやブロック中だが、ほかの人を待っているタスク。各行にだれを待っているかが表示されます。たとえば「Waiting for Li Na to accept」です。 |
| Backlog | まだ始まっていないタスク。 |
| Done | 過去 7 日間に完了したタスク。既定では折りたたまれています。 |

キャンセルされたタスクは表示されません。必要なときはステータスのフィルターで探してください。

## 何があなた待ちになるか

| ラベル | 表示されるとき | 対応する場所 |
| --- | --- | --- |
| Needs your acceptance | あなたが責任者のタスクが In review に移ったとき | [結果を検収する](accept.md) |
| Needs your reply | あなたが責任者のタスクが質問でブロックされているとき | [エージェントの質問に答える](answer.md#ブロックされたタスクの質問に答える) |
| Run failed | エージェントの実行が再試行後も失敗し、どうするかをあなたの判断を待っているとき | [エージェントの質問に答える](answer.md#失敗した実行) |
| Needs plan approval | このタスクの計画の下書きがあなたの承認を待っているとき | タスクページ |
| Needs you to take over | だれかがタスクの責任をあなたに引き継いだとき | [エージェントの質問に答える](answer.md#引き継がれたタスクを引き取る) |

各行には、あなたがすべきことが表示されます。タスクに対応したあとも、別のタスクに移るまではその位置に残ります。ページ下部のメッセージから、変更を **Undo** したり、あなたを待っている次のタスクに直接移動したりできます。

## ビュー

右上で 4 つのビューを切り替えられます。

- **Split**：左に一覧、右に詳細を表示します。**My issues** の既定で、タスクを 1 つずつ処理するのに向いています。
- **Table**：タスクのツリーを展開します。サブタスクを見るのに向いています。
- **Board**：ステータスごとに 1 列です。カードをドラッグするとステータスが変わります。
- **Agent queue**：エージェントごとに 1 レーンで、何をしているか、次に何をするか、だれを待っているかを表示します。[エージェントの稼働状況とモデルの使用量](../project/usage.md) を参照してください。

Studio は最後に使ったビューを記憶します。

## キーボードショートカット

一覧で、入力欄に入力していないとき：

| キー | 操作 |
| --- | --- |
| <kbd>J</kbd> / <kbd>K</kbd> または矢印キー | 次 / 前のタスク |
| <kbd>S</kbd> | フォローする / フォローを解除する |
| <kbd>Enter</kbd> | タスクページを開く |
| <kbd>/</kbd> | 検索 |
| <kbd>Esc</kbd> | 一覧に戻る |

## タスクをフォローする

タスクの右上の星をクリックするとフォローできます。フォローしたタスクは一覧の先頭に残り、ほかの人が追加したコメントや変更の数が表示されます。責任者でないタスクもフォローして、ここで追跡できます。同時にフォローできるタスクは 100 件までです。

## ある日の流れ

1. **My issues** を開き、**Waiting for you** から始めます。結果を検収し、質問に答え、失敗した実行に対応します。
2. **Following** の新しい更新にざっと目を通します。
3. 新しい要件があれば、[要件を出して](raise-a-request.md) エージェントチームに引き渡します。

それ以外は、エージェントチームがランタイム上で進め続けます。あなたが必要になると、タスクは **Waiting for you** に戻ってきます。
