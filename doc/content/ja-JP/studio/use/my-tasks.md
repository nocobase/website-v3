**My issues** には、自分が責任者、実行担当、またはフォローしているタスクが集まります。判断が必要な質問、作業結果、実行上の問題は **Waiting for you** に表示されます。

![グループ化した一覧からタスクを選び、詳細画面で対応する](https://static-docs.nocobase.com/studio-en-my-issues-20261111-normal-2x.webp)

## グループ

| グループ | 内容 |
| --- | --- |
| Following | フォロー中のタスクと他の人による新しい更新 |
| Waiting for you | 自分の判断を待つ事項。古い依頼から表示 |
| In progress | 進行中の作業 |
| Waiting for others | 別の責任者の回答や検収を待つタスク |
| Backlog | 未着手の作業 |
| Done | 過去 7 日間に完了したタスク。既定では折りたたみ |

同じタスクは一度だけ表示します。キャンセルしたタスクは既定で非表示です。状態の絞り込みで探せます。サイドバーの件数は、自分の対応が必要なタスクとタスク案の数であり、全タスク数ではありません。

## 対応待ちの作業を処理する

| 表示 | 操作 |
| --- | --- |
| Needs your acceptance | [報告を読んで検収](accept.md) |
| Needs your reply | [作業を止めている質問に回答](answer.md#作業を止めている質問に答える) |
| Run failed | 原因を確認し、再試行するか判断 |
| Plan awaiting confirmation | 下書きを確認・修正 |
| Ownership handoff | 責任者の引き継ぎを承認・拒否 |

操作後も、別の項目を選ぶまではタスクが同じ位置に残ります。表示される取り消し操作を使うか、次の対応待ち項目に進んでください。

## 表示方法

- **Split**：一覧と詳細を並べます。仕切りをドラッグして幅を変更できます。
- **Table**：サブタスクをタスクツリーで表示します。
- **Board**：状態別にまとめ、カードをドラッグして状態を変更します。
- **Agent queue**：エージェントごとの実行中・待機中の作業を表示します。

選んだ表示方法は保存されます。キューは[作業量とモデル使用量](../project/usage.md)を参照してください。

## タスクをフォローする

タスク上部の星を選ぶと、自分が責任者でなくてもフォローできます。上限は 100 件です。

## キーボードショートカット

入力欄以外で使えます。

| キー | 操作 |
| --- | --- |
| <kbd>J</kbd> / <kbd>K</kbd> または矢印キー | 次・前のタスク |
| <kbd>S</kbd> | フォロー・解除 |
| <kbd>Enter</kbd> | 詳細を開く |
| <kbd>/</kbd> | 検索 |
| <kbd>Esc</kbd> | 一覧に戻る |
