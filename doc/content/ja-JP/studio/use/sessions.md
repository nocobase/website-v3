::figure sessions-list | My sessions：各セッションの下のバーは、タスクごとに 1 区画で、ステータスに応じて色分けされます

一覧の各セッションには、プロジェクトとタスクの数が表示されます。バーの各区画が 1 つのタスクです。緑は完了、紫は検収待ち、青は進行中、琥珀色はブロック中、灰色は Backlog です。あなたを待っているタスクがあるセッションには印が付きます。

セッションはあなただけが見られます。セッション内のエージェントは、タスクの作成やコメントの投稿など、Studio であなたの身元と権限で動作し、あなたにできないことはできません。

## だれと対話するか

セッションパネルには 2 つのモードがあります。

| | My sessions | Runner Agent |
| --- | --- | --- |
| 相手 | Claude Code や Codex など、自分のエージェント | エージェントチームのエージェント。ランタイムが実行します |
| 見られるもの | 許可したフォルダー内のコード、ツール、設定 | ランタイム上のリポジトリ |
| 準備 | [自分の PC を接続する](../join/connect-computer.md)（1 回だけ） | 不要 |
| 向いている用途 | 手元のコードを見ながら要件を相談し、タスクにする | 質問、調べもの、要件をタスクにする |

どちらのモードのセッションも **My sessions** に一覧表示されます。

## セッションを始める

1. **My sessions** で **New session** をクリックします。
2. モードを選びます。**My sessions** では、自分のエージェントと作業ディレクトリを選びます。**Runner Agent** では、チームのエージェントを選びます。どちらのモードでも、セッションが属するプロジェクトを設定できます。
3. やりたいことを伝えます。複数のことを一度に書いても、スクリーンショットを貼り付けてもかまいません。

要件を相談するときは、要件を正しく理解してもらえるよう、最も能力の高いモデルを選びましょう。

タスクやプロジェクトのページで **Ask agent** をクリックすると、現在のページをコンテキストとしてセッションが始まります。

## 相談内容をタスクにする

内容が明確になったら、相談内容をタスクにするようエージェントに依頼します。たとえば「Supplier Management プロジェクトに、この 3 つのタスクを作成してください」です。

::figure req-session | セッションに作成したタスクが一覧表示され、開始できる状態になっています

- セッションで作成したタスクはセッションにひも付いたまま残り、セッションには最新のステータスと進捗が表示されます。
- **Start** をクリックするとエージェントチームに引き渡され、**Not now** をクリックすると **Backlog** に残ります。
- 入力欄で `#` を使って既存のタスクに言及すると、エージェントにそのタスクを読ませたり、コメントさせたり、指示どおりに変更させたりできます。
- タスクページから、そのタスクを作成したセッションに戻ることもできます。

## セッションを追う

- セッションの一覧は **Needs you** や **In progress** で絞り込めます。エージェントが許可を求めたり、あなたの確認を待ったりしているセッションには印が付きます。
- セッションのタスクがエージェントチームで節目を迎えると（実行の終了、タスクのブロック、検収待ち、失敗、クローズ、PR の作成など）、カードがセッションに戻ってきて、エージェントが内容をまとめ、次にすべきことを提案します。
- 不要になったセッションはアーカイブでき、いつでも元に戻せます。
