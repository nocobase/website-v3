**My sessions** は、エージェントとの相談と関連タスクをまとめます。同じ会話に戻って要件を補足し、結果について質問できます。

![会話履歴と関連タスクの状態を一緒に確認する](https://static-docs.nocobase.com/studio-en-guide-runner-session-20261031.png)

## 接続するエージェントを選ぶ

| モード | 実行場所 | 準備 |
| --- | --- | --- |
| Runner Agent | 共有または個人ランタイム | オンラインのランタイムと利用可能なエージェント |
| My Agent | 接続した自分の PC と許可フォルダー | [自分の PC を接続する](../join/connect-computer.md) |

会話を見られるのは自分だけです。エージェントは自分の名義と権限で動作します。関連タスクは、プロジェクトの権限に従って共有されます。

## 会話を始める

1. モードを選び、**New session** を選びます。
2. エージェントを選びます。My Agent は PC と作業フォルダーも指定します。
3. コードが必要な場合は、最初のメッセージの前にプロジェクトを選びます。
4. 要件を伝え、画像、添付資料、`#task-identifier` の参照を追加します。

プロジェクトやタスクの **Ask agent** には、そのページの背景が含まれます。プロジェクトの固定、待機メッセージ、ランタイムの変更は [Runner Agent と対話する](../join/runner-agent.md)を参照してください。

## 相談からタスクを作成する

```prompt
合意した変更を Supplier Management の 3 つのタスクとして作成してください。それぞれに受け入れ基準を含め、まだ開始しないでください。
```

作成したタスクは会話に表示されます。確認して開始するか、Backlog に残します。タスクのプロパティから関連する会話にも戻れます。

## 会話を追う

- 一覧には関連タスク数と、各タスクの進捗が表示されます。
- **Needs me** や **In progress** で進行中の作業に絞れます。
- タスクの開始、ブロック、検収依頼、完了が会話に反映されます。
- 使わない会話はアーカイブし、必要になれば復元できます。

アーカイブは永久保存ではありません。Runner Agent の会話は、既定でアーカイブから 30 日後に削除されます。長く使う決定事項はタスク、[ナレッジベース](../project/knowledge-base.md)、[プロジェクトメモリー](../project/project-memory.md)に保存してください。
