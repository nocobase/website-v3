**My issues** brings together tasks you own, execute, or follow. Questions, deliveries, and execution problems that need your decision appear under **Waiting for you**.

![Choose a task from the grouped list and handle it in the detail pane](https://static-docs.nocobase.com/studio-en-guide-my-issues-20261031.png)

## Groups

| Group | Content |
| --- | --- |
| Following | Followed tasks and new activity from others |
| Waiting for you | Decisions you need to make, with older requests first |
| In progress | Work moving forward |
| Waiting for others | Tasks awaiting another owner's answer or acceptance |
| Backlog | Work that has not started |
| Done | Tasks completed in the last seven days, collapsed by default |

Each task appears once. Canceled tasks are hidden by default; use a status filter to find them. The sidebar badge counts tasks and task plans that need your attention. It is not a total of all your tasks.

## Handle waiting work

| Prompt | Action |
| --- | --- |
| Needs your acceptance | [Read the report and accept](accept.md) |
| Needs your reply | [Answer the blocking question](answer.md#answer-a-blocking-question) |
| Run failed | Inspect the cause and decide whether to retry |
| Plan awaiting confirmation | Check the draft and confirm or revise it |
| Ownership handoff | Accept or decline responsibility |

After an action, the task stays in place until you select another. Use the offered undo action or move to the next waiting item.

## Views

- **Split**: list and details side by side. Drag the divider to resize them.
- **Table**: view subtasks as a task tree.
- **Board**: group by status and drag cards to change status.
- **Agent queue**: see running and waiting work by Agent.

Studio remembers your selected view. See [Workload and model usage](../project/usage.md) for the queue.

## Follow a task

Select the star in the task header to follow it, even if you are not its owner. You can follow up to 100 tasks.

## Keyboard shortcuts

Outside an input field:

| Key | Action |
| --- | --- |
| <kbd>J</kbd> / <kbd>K</kbd> or arrow keys | Next / previous task |
| <kbd>S</kbd> | Follow / unfollow |
| <kbd>Enter</kbd> | Open task details |
| <kbd>/</kbd> | Search |
| <kbd>Esc</kbd> | Return to the list |
