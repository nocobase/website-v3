NocoBase Core 是 AI 开发和运行业务系统的开源应用底座。它提供数据、权限、流程、文件、AI 接入等每个业务系统都需要的基础能力，以及统一的项目结构和开发规范。Agent 使用这些现成能力，只开发企业自己的业务部分。

## 一个应用里有什么

用 Core 创建的应用是一个普通的代码仓库，代码和数据都在你自己的仓库和服务器上。仓库里有三部分：

- **业务代码**：`client/`、`server/`、`database/` 下的页面、接口、数据表和业务规则。由你和 Agent 编写，随应用发布。
- **Core 的包**：`package.json` 中声明的依赖，提供登录、用户、权限、文件、通知等基础能力。由 NocoBase 维护，通过升级获得新版本。
- **Skill 和项目规范**：`.agents/skills/` 里的 Skill 告诉 Agent 怎样使用 Core 的包，随依赖同步；`AGENTS.md` 和 `.agents/rules/` 记录这个应用自己的约定，由你维护。

## Core 提供什么，应用里写什么

以[开发第一个功能](build-your-first-app.md)中的客户管理为例：

| 需求 | Core 提供 | 应用里写 |
| --- | --- | --- |
| 登录 | 账号、登录和会话 | 不用写 |
| 保存客户 | 迁移、数据访问和输入校验 | `customers` 表、客户接口和业务规则 |
| 展示客户 | 表格、表单、弹窗等 UI 组件 | 客户列表、新建弹窗、搜索和分页 |
| 控制权限 | 角色、操作权限、数据范围和服务端检查 | 三种角色：销售主管管理全部客户，销售只处理自己负责的客户，只读用户只能查看 |
| 管理用户和角色 | 用户管理和权限管理页面 | 加到应用的系统设置里 |

Core 现有的全部能力见[插件使用概览](../using-plugins/overview.md)。

## 怎样开发

你用业务语言描述需求：谁在用、要做什么、有哪些规则。Agent 按 Skill 先给出设计请你确认，再编写数据表、接口、页面和测试，自己验收后交给你一份报告。你在应用里试用，决定接受还是继续调整。

Agent 写的是普通源码。你可以评审和修改，也可以全部自己写，用的是同一套框架和命令。

## 部署和维护

应用部署在你自己的服务器上，独立运行。管理员在系统设置里调整用户、角色和数据范围，不用改代码；页面、数据结构或业务规则有变化时，改代码后重新部署。
