NocoBase Core 是 AI 开发和运行业务系统的开源应用底座。权限、流程、文件等基础能力现成可用，Agent 在统一架构上只开发企业自己的业务。

## 开始使用

1. [认识 NocoBase Core](getting-started/what-is-core.md)：Core 提供什么，应用里写什么。
2. [创建应用](getting-started/create-app.md)：在本机创建并运行一个应用。
3. [开发第一个功能](getting-started/build-your-first-app.md)：让 Agent 在应用里做客户管理。
4. [持续开发应用](getting-started/develop-with-an-agent.md)：之后的每个功能，从提需求到验收，你和 Agent 各做什么。
