## 平台身份与子应用账号

主应用使用商业插件 `@nocobase/app-plugin-identity-provider` 提供 OIDC 身份认证，NocoBase 子应用使用商业插件 `@nocobase/app-plugin-platform-sso` 接入。应用管理与客户端开通由商业插件 `@nocobase/app-plugin-multi-app` 衔接。

用户登录平台后，进入获授权的子应用会经过认证重定向。平台会话有效时无需再次输入账号密码，子应用随后建立自己的会话。

子应用按 issuer（身份提供方标识）和 subject（该身份源中的用户标识）绑定本地账号，不复制平台用户表，也不按邮箱自动合并已有账号。已有用户需要接入时，先制定[身份保留方案](migration.md)。

## 配置身份提供方与子应用登录

主应用注册身份提供方、合并原生认证配置并提供认证续接页面，子应用注册 SSO 插件并合并登录配置。接入注意事项见[应用开发](development.md)。

在创建实例前固定 HTTPS 入口。为每个应用登记独立客户端和精确回调地址，使用授权码流程、PKCE S256 和客户端认证，不开放浏览器动态客户端注册。

子应用的配置含义如下：

| 配置 | 含义 |
| --- | --- |
| `PLATFORM_SSO_ISSUER` | 平台身份服务的 issuer，不是工作台首页 |
| `PLATFORM_SSO_APP_ID` | 平台登记的应用标识 |
| `PLATFORM_SSO_CLIENT_ID` | 这个应用自己的客户端标识 |
| `PLATFORM_SSO_CLIENT_SECRET` | 仅供服务端使用的客户端密钥 |
| `PLATFORM_URL` | 平台导航入口，包含平台部署路径 |
| `APP_PUBLIC_ORIGIN` | 子应用自身的公网源，不包含路径 |
| `APP_BASE_PATH` | 子应用自身的部署路径前缀 |

托管实例通过平台接入流程和部署变量服务接收配置；独立应用由其管理员安全写入运行环境。SSO 凭据由运行时环境变量读取，不能假设写入任意 YAML 字段就会生效。

没有 issuer 时，子应用保留本地认证。填写 issuer 却缺少其他凭据会导致配置失败，不会启用不完整的统一登录。更改启动配置后需重启或重新部署。

已有托管实例接入时，先在详情中登记统一登录，再部署支持 SSO 的模板版本。只写变量不会让旧模板自动获得登录功能。重新接入可按实际地址更新回调并保留客户端凭据；变更 issuer 还涉及原有身份绑定，不能只更新 URL。

## 授予应用访问权限

在应用详情的访问授权中选择具体平台用户，授予所需访问资格。当前成员管理由无限制管理员操作；平台管理员自己也需要显式成员资格才能通过 SSO 进入子应用。

工作台只展示当前用户可进入的应用。托管应用还需要运行中且没有阻止进入的未完成部署。找不到入口时，先检查成员资格和实例状态，而不是先扩大业务权限。

用普通成员测试从工作台进入应用，再用未授权账号直接打开该应用地址。前者应成功建立子会话，后者应被拒绝。隐藏入口只是界面表现，服务端仍必须拒绝未授权请求。

## 区分应用成员资格与业务权限

平台决定是否允许进入，子应用的 Permission Sets 等业务授权机制决定可读写的数据与操作。当前接入角色为 `reader` 和 `editor`，它们不是所有业务系统通用的权限集名称。

子应用通过 `applyRole` 映射自己的最小权限。例如库存应用的编辑成员可以登记出入库，但不因此获得用户管理或无限制管理员权限。

从编辑改成只读时，子应用需要移除旧的 SSO 写权限。若用户仍有其他角色提供写权限，只读角色不会抵消它；应检查所有有效授权来源。角色映射注意事项见[应用开发](development.md)。

## 撤销授权、退出与本地恢复登录

NocoBase 子应用在检查平台用户会话时复核成员授权。撤销成员或禁用平台用户后，后续检查会拒绝访问；已经在处理中的请求不会被追溯撤销。身份服务不可用时，平台身份访问失败关闭，不继续离线放行。

退出子应用仅结束本应用会话，不会同时结束其他应用或主应用的会话。退出后停留在 `/login?signedOut=1`，用户主动重新进入时才发起 SSO，避免立即自动登录。

保留子应用本地管理员，并通过 `/login?auth=local` 进入恢复登录。该账号不依赖平台会话复核，也不能因此读取平台应用目录。

至少检查以下行为：

- 从未登录的业务深链接进入，登录后返回原页面。
- 已登录用户被降权或撤销后，后续写入或访问被拒绝。
- 退出子应用后不会立即自动登录。
- 平台身份服务不可用时，本地恢复账号仍能登录。

第三方 OIDC 应用的已有会话撤销由其自身实现，不能套用 NocoBase 子应用的复核行为。当前不提供全平台联动退出或组织同步。示例的[统一登录说明](https://github.com/nocobase/app-example-multi-app/blob/2e2df1793ec51372ca9b3890b37e9d4748732689/docs/sso.md)可供对照完整交互。
