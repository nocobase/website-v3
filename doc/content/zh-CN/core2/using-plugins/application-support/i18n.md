## 提供的能力

`@nocobase/app-plugin-i18n` 提供应用运行时的语言切换接口和 Hooks。翻译资源、命名空间和翻译机制由框架负责；本插件负责让用户选择语言，并同步服务端的语言偏好。

插件提供切换和同步的行为；翻译资源和选择器的外观仍由应用负责。

## 使用场景与示例

### 示例：中英文界面

1. 应用同时提供 `zh-CN` 和 `en-US` 两种语言的客户端资源和服务端资源。
2. 在顶栏接入语言选择器，或者复用默认模板中已有的实现。
3. 选择另一种语言，检查页面、插件内容和服务端返回的错误提示。
4. 刷新页面，确认浏览器保留了这次选择；启动时的同步可以使用 `useSyncServerLocale()`。

相关的接口为 `GET /api/i18n/locales` 和 `PUT /api/i18n/locale`。如果服务端不支持所选的语言，会保存 `en-US` 并返回 `fallback: true`，而浏览器界面仍保留自己的语言；网络失败时，也不会自动撤销浏览器中的选择。

**开发提示词**（交给当前应用目录中的 Coding Agent）：

```prompt
请使用多语言插件，为应用接入中英文切换。
检查并补齐客户端和服务端资源加载器，复用 useAppLocale 与模板已有选择器。
切换时处理 loading 和失败，保留浏览器选择，并在启动时同步服务端语言。
验证刷新、服务端不支持的语言、网络失败和多标签页行为，不实现业务内容自动翻译。
```

**完成的标志**：切换后，应用和插件的文案随之更新，刷新后保留选择；服务端回退或网络失败时，都有明确的处理。

## 重要原理与实现

下表列出实现本例时的接入位置和预期的界面变化。这些是开发说明，具体的文件名沿用当前应用的结构。

| 接入位置 | 代码或配置的变化 | 界面与行为的变化 |
| --- | --- | --- |
| `client/locales`、`server/locales` | 补充资源及其加载器 | 可选的语言来自应用实际拥有的资源 |
| 顶栏的语言选择器 | 使用 `useAppLocale`，处理 `switching` 和失败 | 页面和插件的文案随选择更新 |
| 布局中的启动同步与错误展示 | 使用 `useSyncServerLocale`，按稳定的原因展示错误 | 服务端偏好得到同步，回退行为可以解释 |

### 接入与语言来源

注册 Client 和 Server 插件。可选的语言来自应用自己在 `client/locales/index.ts` 和 `server/locales/index.ts` 中声明的加载器，而不是插件另外维护的一份语言清单。

新增一种语言时，需要为应用补充相应的资源和加载器。即使其他插件提供了某种语言，它也不会被自动加入应用的语言选择列表。默认语言的配置为：

```yaml
i18n:
  defaultLocale: zh-CN
```

`APP_DEFAULT_LOCALE` 可以覆盖这个默认值。应用没有提供资源的默认语言，不会作为一个新的选项出现。

### 接入语言选择器

插件提供行为，选择器的外观由应用负责。在 `AppClientRoot` 内部使用：

```tsx
import { useAppLocale } from '@nocobase/app-plugin-i18n/client';

const { locale, locales, setLocale, switching } = useAppLocale();
```

这是组件内部的调用片段。用 `locales` 渲染选项，选择后调用 `setLocale(next)`；切换期间根据 `switching` 禁止重复操作，并处理 Promise 的失败。

切换时，会加载各个命名空间的资源、更新界面和 HTML 的语言及方向、保存浏览器偏好并通知服务端。各插件共享同一个翻译运行时，不需要另写一套跟随切换的逻辑。

## AI 开发的约束与验证

### 本插件的开发约束

- 语言选项由应用的加载器决定，不要另外硬编码一份与资源不一致的列表。
- 等待 `setLocale` 的结果并处理失败；不能把服务端的回退误当作浏览器的切换已被撤销。
- 测试缺失的文案、刷新后的持久化、多个标签页共享会话，以及服务端的错误文案；类型检查通过，不能代替语言覆盖的检查。

### 验证与边界

多个标签页共享同一个会话的服务端语言，因此一个标签页切换语言后，另一个标签页中接口返回的提示也可能随之改变。自定义的界面可以按稳定的 `error.reason` 显示对应语言的文案。

本插件不提供业务内容的自动翻译，也不提供翻译管理后台。资源的编写方式见 [多语言](../../developing-apps/localization.md) 和 [服务端多语言](../../developing-apps/server-localization.md)。
