## 提供的能力

`@nocobase/app-plugin-api-keys` 为脚本和外部系统提供 API 密钥认证。请求通过 `x-api-key` 携带密钥，并以密钥所属用户的身份执行；带范围的密钥还会受到其自身范围的限制。

插件提供密钥认证和管理接口；个人密钥管理页，以及业务接口的范围接入，由应用实现。

## 使用场景与示例

### 示例：给报表脚本只读访问权限

1. 由应用为报表业务声明对应的密钥权限组和记录范围。
2. 用户登录后打开密钥管理页，选择自己已被授予的只读能力和有效期，并保存创建时返回的 secret。
3. 脚本通过 `x-api-key` 调用报表接口。
4. 验证允许的查询能够成功，而写入、访问超出范围的记录以及撤销后的请求都被拒绝。

带范围密钥的有效权限，是“用户当前的权限”与“密钥范围”的交集；密钥范围不会授予用户原本没有的权限。使用 `auth.required()` 的业务接口，需要明确允许 scoped key，并通过授权系统或相应的范围检查执行操作；尚未接入的接口会拒绝这类密钥。

**开发提示词**（交给当前应用目录中的 Coding Agent）：

```prompt
请使用 API 密钥插件，为报表脚本提供有有效期的只读密钥。
沿用认证配置，为报表声明操作与记录范围，接入个人密钥的创建、轮换和撤销。
只在签发或轮换时展示返回的 secret，不把密钥写入源码或日志。
验证允许查询、越界读取、写入、旧密钥与撤销后的请求。
```

**完成的标志**：脚本只能读取允许的报表记录，写入请求和使用失效密钥的请求都被拒绝。

## 重要原理与实现

下表列出实现本例时的接入位置和预期的界面变化。这些是开发说明，具体的文件名沿用当前应用的结构。

| 接入位置 | 代码或配置的变化 | 界面与行为的变化 |
| --- | --- | --- |
| 认证配置与插件数组 | 组合 `apiKey()` 和 `apiKeyClient()`，并执行迁移 | 密钥认证与管理端点可用 |
| 个人设置页面 | 接入密钥的范围、有效期、轮换和撤销 | 用户管理自己的密钥，secret 只在返回时展示一次 |
| 报表接口 | 显式支持 scoped key，并应用数据策略 | 脚本只能访问用户权限与密钥范围的交集 |

### 接入与配置

除了在 Client 和 Server 两侧注册插件、执行数据库迁移之外，还要在服务端的认证配置中加入 `/server` 导出的 `apiKey()`，在客户端的认证配置中加入 `/client` 导出的 `apiKeyClient()`。默认模板已经组合了这些配置，请先检查，再按需补充。

只注册服务端插件，会创建密钥的数据表，但不会启用 Better Auth 的密钥端点；只加入 `apiKey()` 而不执行插件迁移，则会缺少数据表。插件不注册密钥管理页，应用可以使用认证客户端或 `/api/apiKeys` 构建个人密钥管理页。

### 创建与使用

用户必须通过交互式登录后的会话来管理自己的密钥；密钥本身不能创建、修改或删除其他密钥。带范围的密钥可以通过以下接口管理：

| 接口 | 用途 |
| --- | --- |
| `GET /api/apiKeys/scopeOptions` | 获取可选的权限组、预设和有效期信息 |
| `POST /api/apiKeys` | 创建密钥，并一次性返回明文 secret |
| `GET /api/apiKeys` | 查看自己的密钥及其范围，不返回 secret |
| `POST /api/apiKeys/:keyId/rotate` | 轮换 secret，旧值立即失效 |
| `DELETE /api/apiKeys/:keyId` | 撤销密钥 |

例如，应用挂载在 `/main` 时，可以用密钥读取它的 API 文档：

```bash
curl -H 'x-api-key: <your-key>' https://app.example.com/main/api/swagger
```

请把 `<your-key>` 替换为实际的密钥，并按应用的部署位置调整地址。能够读取 API 文档，并不代表已经获准调用其中的每一个接口。

## AI 开发的约束与验证

### 本插件的开发约束

- 管理密钥必须使用登录会话，不能让一个 API 密钥去管理其他密钥。
- 不带范围的密钥并不等于只读；报表接口必须落实操作范围和记录范围，而不只是校验密钥是否有效。
- 测试轮换后旧 secret 立即失效，以及用户失去权限、密钥过期和被撤销之后的调用。

### 使用边界

不带范围的密钥会继承所属用户的全部权限，不能把它描述成默认只读。用户失去权限或被停用后，密钥也会受到影响。`apiKeys.maxScopedKeyDays` 可以限制带范围密钥的最长有效期；轮换之后，需要更新调用方保存的 secret。
