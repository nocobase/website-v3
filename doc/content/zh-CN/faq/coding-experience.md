---
title: "不会写代码，可以使用 NocoBase 吗？"
---

可以参与应用开发。你可以用自然语言描述业务需求，让 Agent 实现功能，再通过实际操作确认结果。例如开发客户管理功能时，需要说明客户有哪些资料、销售能查看哪些客户，以及负责人可以执行哪些操作。Agent 负责实现，你负责确认业务规则和验收结果。

在已经配置好的 Studio 中，业务人员可以提出需求、回答 Agent 的问题并验收功能，不必先学习编程或配置自己的开发环境。具体流程见[使用 Studio 协作开发](../getting-started/collaborate-with-studio.md)。

团队仍需有人负责环境、账号授权、测试评审、部署和后续维护。这些工作可以由 Agent 协助，但需要负责人提供必要信息并确认结果。首次搭建由管理员按[安装概览](../studio/setup/index.md)完成；自己动手试用 Core，可以从[开发第一个应用](../getting-started/develop-your-first-app.md)开始。
