---
title: "使用 Core 必须安装 Studio 吗？"
---

不必。你可以只使用 Core，在应用目录中通过 Claude Code、Codex 等编码工具开发业务功能，并由团队自行组织测试、评审和部署。开始操作见[开发第一个应用](../getting-started/develop-your-first-app.md)。

Core 提供应用运行所需的基础能力与开发规范；Studio 用于组织人与 Agent 的协作。当团队需要同时推进多个项目和任务，统一跟进进展、组织检查和验收时，可以使用 Studio。两种方式开发的应用都建在 Core 上。

如果准备引入 Studio，可以先阅读[使用 Studio 协作开发](../getting-started/collaborate-with-studio.md)。Studio 的安装与团队配置见[安装概览](../studio/setup/index.md)。
