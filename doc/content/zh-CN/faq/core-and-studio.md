---
title: "使用 Core 必须安装 Studio 吗？"
---

不必。你可以只使用 Core，在应用目录中通过 Claude Code、Codex 等编码工具开发业务功能，并由团队自行组织测试、评审和部署。开始操作见[用 Core 开发第一个应用](../getting-started/develop-your-first-app.md)。

Core 提供应用运行所需的基础能力与开发规范；Studio 用于组织人与 Agent 的协作。实际项目推荐先在探索期用本地编码工具和 Core 快速出 MVP，等业务试用反馈涌来后再零迁移切入 Studio，具体做法和切换时机见[先用 Core，再接入 Studio](../getting-started/from-core-to-studio.md)。两种方式开发的应用都建在 Core 上。

如果准备引入 Studio，可以先阅读[用 Studio 协作开发](../getting-started/collaborate-with-studio.md)，或通过[一键安装 Studio](../getting-started/quick-install-studio.md) 在本机免费试用社区版；团队部署与版本选择见[安装概览](../studio/setup/index.md)。
