---
title: "NocoBase 3 只是 Skills 吗？用户、组织和权限需要自己开发吗？"
---

NocoBase Core 提供应用运行时、数据库等基础库，以及认证、用户、权限、文件和通知等插件。Skills 指引 Agent 使用这些能力开发应用，应用运行时仍依赖 Core，并非只有一组提示词。

默认模板已注册认证、用户和权限等插件，并准备了用户与角色管理模块，开发应用时按需接入管理页面。你不需要重新实现登录和授权机制，但需要定义业务操作与数据范围，并在接口中执行检查。例如“销售只能修改自己负责的客户”，必须落实到服务端的数据访问，不能只隐藏页面按钮。见[认证、权限与数据范围](../core/developing-apps/authentication-and-permissions.md)。

用户和角色不等于完整的组织架构。部门层级、岗位、跨部门协作及其数据范围需要按业务建模或对接现有组织系统，不能假定创建应用后就具有与 NocoBase 2 相同的部门管理功能。

已有能力及其启用方式见[插件索引](../core/reference/plugins.md)和[管理插件](../core/developing-apps/manage-plugins.md)。
