---
title: "开发出来的应用可以独立部署和运行吗？"
---

可以。基于 Core 开发的业务应用可以部署到自己的服务器，发布后独立运行，日常业务请求不经过 Studio。使用 Studio 开发，不要求生产应用在 Studio 中运行。

## Docker 与 PM2 部署

可以从自己的应用源码构建 Docker 镜像，也可以通过 app-installer 安装部署包，由 PM2 托管 Node.js 进程。选择取决于团队已有的容器或服务器运维方式，见[选择部署方式](../core/deployment/choose-a-deployment-method.md)。

两条路径都提供首次部署和更新步骤：[使用 Docker 部署](../core/tutorials/deploy-with-docker.md)、[使用 PM2 部署](../core/tutorials/deploy-with-app-installer.md)。构建和运行环境需要满足应用的版本、操作系统和 CPU 架构要求。

## 生产配置与数据持久化

为生产环境准备独立配置、数据库、稳定密钥和文件存储。构建产物不会自动携带开发数据库、上传文件或运行密钥；需要保留的数据应另行迁入。容器重建或替换程序后，持久化存储中的业务数据应仍可使用。

应用使用的外部服务也需要生产配置。例如，业务 AI 需要可用的模型服务和访问权限；独立运行不代表所有功能都不依赖外部服务。

## 后续更新与维护

修改源码、完成测试后，重新构建并按原部署方式更新。发布前备份数据，发布后检查原有数据、用户权限和主要业务操作，见[发布应用新版本](../core/deployment/publish-app-release.md)。

回退程序不会自动撤销数据库变更。备份范围、数据迁移和恢复要求见[应用如何备份、恢复和迁移数据](backup-and-migration.md)。
