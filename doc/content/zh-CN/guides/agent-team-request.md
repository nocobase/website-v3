资产管理员提了一个新需求：每季度盘一次设备，现在靠导出表格手工勾，容易漏。这一篇把它交给 Agent 团队，从提出到合并走一遍。

需求在 Studio 里是一个任务，只有「阻塞中」（要你回答）和「待验收」（要你验收）两种状态需要人，其余由调度 Agent 推进。状态说明见 [任务状态与权限](../studio/reference/statuses-and-permissions.md)。

![任务看板：每种状态一列](https://static-docs.nocobase.com/20261028201236304.png)

## 1. 提出需求，整理成任务

![「新建任务」在页面右上角](https://static-docs.nocobase.com/20261029151913059.png)

在「我的会话」点「新会话」，选你的 Codex 和 itam-lite 的本地目录，项目选 itam-lite（需要先 [连接自己的电脑](../studio/join/connect-computer.md)）：

```prompt
资产管理员每个季度要盘点一次设备。想做成这样：
- 资产管理员发起一次盘点，选这次要盘的设备范围；
- IT 支持逐台核对：设备在不在、存放位置对不对、使用人对不对，不对的记录实际情况；
- 盘点结束后出一份结果：盘了多少台，正常多少台，有差异的逐条列出来。
有不清楚的先问我，再建任务。
```

Agent 会追问几个问题。你定下：按存放位置选范围；盘点期间不限制领用；员工看不到盘点。Agent 把这些写进任务描述和验收场景，建成 `ITAM-12 设备盘点`。

**完成的标志**：itam-lite 项目里有了“设备盘点”任务，描述里写着定下的规则和验收场景。

## 2. 开始执行

在会话里点「开始执行」。任务进入「进行中」，调度 Agent 先请设计 Agent 写方案（新增“盘点”和“盘点明细”两张表、两种状态、两个角色的权限），再交给开发 Agent 在 `agent/ITAM-12` 分支上开发、写测试、截图、开 PR。

任务页顶部的「现在」和「接下来」显示谁在做、下一步是什么，「动态」里是每次交接。想补充要求，在任务里发评论。见 [跟进进展](../studio/use/follow-progress.md)。

**完成的标志**：任务状态是「进行中」，执行者是调度 Agent。

## 3. 回答提问

写方案时，Agent 遇到一个需要人决策的业务问题：盘点发现差异后，台账要不要自动改？任务移到「阻塞中」，「我的任务」里标着“等你回复”。

![阻塞中的任务：“需要你”卡片写清要你决策什么](https://static-docs.nocobase.com/20261028203035957.png)

打开任务，点「回复」：

```text
不自动改台账。盘点结束后列出差异清单，由资产管理员逐条确认，确认的才更新到台账。
```

见 [回答 Agent 的提问](../studio/use/answer.md)。

**完成的标志**：任务回到「进行中」。

## 4. 检查与评审

PR 开出后，先跑 CI，再交给另一家厂商的 Agent 评审，问题由开发 Agent 修完再评审，都通过才交给你。见 [检查与评审](../studio/project/checks-and-review.md)。

## 5. 验收与合并

任务进入「待验收」，「我的任务」里标着“等你验收”。读交付报告和截图，再在任务页打开预览，用初始管理员登录试一遍：以资产管理员按存放位置发起盘点，换 IT 支持核对几台设备，故意填一条位置不对的，结束盘点，看结果里有没有这条差异、台账有没有被自动改掉。见 [验收](../studio/use/accept.md)。

![交付报告和开发 Agent 附上的截图](https://static-docs.nocobase.com/20261028203712314.png)

![PR 的预览：任务页上能看到初始管理员的账号和密码](https://static-docs.nocobase.com/20261028204209835.png)

符合预期就点「合并」；不对就点「退回修改」，写清哪里要改。

![待验收的任务：“需要你”卡片上的「合并」按钮](https://static-docs.nocobase.com/20261028201509073.png)

在意的任务可以点右上角的星标关注，它会排在「我的任务」最前面。

![关注一个任务](https://static-docs.nocobase.com/20261029152227386.png)

**完成的标志**：任务「已完成」，设备盘点合并到 itam-lite 的默认分支。
