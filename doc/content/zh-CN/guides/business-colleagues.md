设备盘点的需求来自资产管理员，提出、回答、验收却都是你在转述。这一篇请资产管理员许宁（业务同事）直接加入 itam-lite 项目：在 Studio 网页里提需求、回答 Agent 的业务问题、亲自验收，不写代码，也不用装 Agent。

## 1. 邀请许宁

打开「设置 › 成员」，点「邀请成员」，填许宁的邮箱，「加入的项目」选 itam-lite，点「发送邀请」。见 [邀请成员](../studio/setup/invite.md)。

许宁打开邀请链接，填写姓名和密码，点「创建账号并加入」。见 [登录与个人设置](../studio/join/sign-in.md)。

**完成的标志**：许宁出现在「设置 › 成员」的列表里。

## 2. 许宁提需求

许宁想做设备报废。打开「我的会话」，点「新会话」，模式选「Runner Agent」，项目选 itam-lite：

```prompt
设备坏了或者太旧了要报废，现在是直接在台账里删掉，没有记录。想做成这样：
- IT 支持发现设备要报废时提一个报废申请，写明原因，附上照片；
- 资产管理员审批，通过后设备状态改成“已报废”，不再出现在可领用的设备里；
- 报废过的设备要能查到是谁申请、谁批准、什么原因。
不确定的地方先问我。
```

Agent 追问后，许宁按公司制度回答：笔记本电脑满 4 年、显示器满 5 年可以报废，没到年限的要写明损坏情况；员工手上的设备要先归还；由资产管理员审批。许宁说“建成任务”，再点「开始执行」。任务负责人是许宁，之后的提问和验收都直接找许宁。见 [我的会话](../studio/use/sessions.md)。

**完成的标志**：itam-lite 项目里有了“设备报废”任务，负责人是许宁，状态是「进行中」。

## 3. 许宁回答提问

开发时 Agent 问：已经报废的设备，台账里还要不要显示？许宁在「我的任务」里看到标着“等你回复”的任务，点「回复」：

```text
台账默认不显示已报废的设备，但要能按状态筛选出来查看。审计时要查历史。
```

## 4. 许宁验收

任务进入「待验收」后，许宁读交付报告和截图，在预览里试一遍：给一台还在员工手上的设备提报废，看是否被拦下；归还后再提，审批通过后，看它是否从可领用的设备里消失。符合预期就点「合并」。见 [验收](../studio/use/accept.md)。

**完成的标志**：“设备报废”任务「已完成」，业务问题都由许宁直接回答。
