许宁（业务同事）定下的报废年限、盘点差异要人确认等规则，现在散在两个任务的会话和评论里。Studio 用三个地方沉淀它们：

| | 放什么 | 谁来写 |
| --- | --- | --- |
| 知识库 | 业务是怎样的：制度、规则、关键决策 | 人 |
| 技能 | 事情怎么做：开发规范、检查清单 | 人 |
| 项目记忆 | Agent 被纠正过的做法、踩过的坑 | Agent |

## 1. 把资产管理制度放进知识库

打开「开发 › 知识库」，选中 itam-lite 的项目空间，新建文件夹“资产管理制度”，上传现有的制度文件，或者新建一篇文章：

```markdown
# 设备领用、报废与盘点规则

## 领用标准
- 新员工入职标配：笔记本电脑 1 台、显示器 1 台。
- 超出标配的领用，需要部门负责人在领用申请里说明理由，由资产管理员审批。

## 报废规则
- 笔记本电脑满 4 年、显示器满 5 年可以申请报废；未满年限的，要写明损坏情况并附照片。
- 员工手上的设备不能直接报废，先办理归还。
- 已报废的设备台账里默认不显示，可以按状态筛选查看，审计时要能查到申请人、批准人和原因。

## 盘点周期
- 每季度盘点一次，按存放位置分批进行；每年 12 月全量盘点。
- 盘点发现的差异不自动改台账，由资产管理员逐条确认后更新。
```

只写从代码里看不出来的规则和决策。要让许宁直接维护，在这个文件夹上给许宁「编辑」权限。空间、权限和 Agent 怎样读取，见 [知识库](../studio/project/knowledge-base.md)。

![知识库：左边是空间和文件夹，右边是文档](https://static-docs.nocobase.com/20261028205037978.png)

**完成的标志**：在会话里问“笔记本几年可以报废”，Agent 答出 4 年，并注明引用了这篇。

## 2. 写一个技能：ITAM 检查清单

验收时你每次都要换角色登录看权限、看台账改动有没有留痕。写成技能后，开发和评审的 Agent 都会照着查。

先让本地的 Codex 起草：

```prompt
读 itam-lite 的代码和设备盘点、设备报废两个任务的交付报告，起草技能 itam-checklist：这个系统每次改动都要检查的权限和留痕要求，只写项目特有的约定。
```

大致是这样：

```markdown
---
name: itam-checklist
description: 在 itam-lite 里开发、自测或评审任何涉及设备、领用、报废、盘点的改动时读。列出这个系统必须检查的权限和留痕要求。
---

# ITAM 检查清单

## 三个角色都要试
- 员工：只能看到自己领用的设备，看不到盘点和报废。
- IT 支持：能处理领用、填写盘点核对结果、提报废申请，不能审批。
- 资产管理员：能审批领用和报废，发起和结束盘点，确认盘点差异。
- 每个验收场景，至少用会受影响的两个角色各登录一次，截图附在交付报告里。

## 台账改动要留痕
- 设备的状态、位置、使用人发生变化，要能查到是谁、什么时候、因为哪张单据改的。
- 不允许直接删除设备记录；报废是改状态，不是删除。

## 业务规则以知识库为准
- 领用标准、报废年限、盘点周期，以知识库《设备领用、报废与盘点规则》为准，不要写死在代码里猜。
```

打开「Agent 管理 › 技能」，点「新建技能」，粘贴保存。再打开 itam-lite 的「项目设置 › 默认技能」，「应用于」选「整个项目」，加上 `itam-checklist`。全局和代码仓库范围的挂载见 [技能](../studio/project/skills.md)。

**完成的标志**：下一个涉及设备的任务，评审 Agent 按清单检查了角色权限和留痕，交付报告里有不同角色的截图。

## 3. 看项目记忆

项目记忆由 Agent 自己写，存在仓库的 `.nb-studio/memory/` 里，随 PR 提交和评审，换 Claude 还是 Codex 都读同一份。在「开发 › 项目记忆」里查看，例如：

| 类型 | 例子 |
| --- | --- |
| 反馈 | 盘点差异不自动改台账，资产管理员确认后才更新 |
| 项目 | 报废是改设备状态，不删除记录，审计要查历史 |
| 参考 | 报废年限、盘点周期以知识库《设备领用、报废与盘点规则》为准 |

![项目记忆：按项目和代码仓库查看，按类型筛选](https://static-docs.nocobase.com/20261028205613068.png)

想让 Agent 记住某条规则，在任务里直接告诉它。见 [项目记忆](../studio/project/project-memory.md)。

**完成的标志**：资产管理制度在知识库里，`itam-checklist` 挂在 itam-lite 上。
