## 选择编码工具

编码工具可以用 Codex、Claude Code 或 OpenCode 等常见的 Coding agent，提示词通用。按各工具的官方说明安装并登录。

## 选择模型

截止 2026 年底，推荐 Claude 和 GPT 系列的顶尖模型，国产模型推荐 DeepSeek：

| 模型          | 特点                                                                             |
| ------------- | -------------------------------------------------------------------------------- |
| Claude Opus   | 写出的页面更好看，综合能力更强                                                   |
| GPT Astra/Sol | 有相对完整的系统设计文档时，能写出完整的系统                                     |
| DeepSeek      | 速度快，成本低。可以在 OpenCode 里使用，也可以按 DeepSeek 的文档接入 Claude Code |

写设计文档、开发新功能，用强模型、调高思考强度；改文案、调样式这类小改动，可以换快一些、便宜一些的模型。

评审代码时换另一家厂商的模型，更容易发现问题。例如 Codex 用 GPT 写的功能，开一个 Claude Code 会话让 Opus 评审：

```prompt
评审当前未提交的改动，按 AGENTS.md 的约定找问题，按严重程度列出，不要改代码。
```
