适合需要围绕具体业务能力深入使用 NocoBase Core 的开发者与团队。每个专题聚焦单一能力，不混杂多项主题；你可以按当前要实现的功能直接挑选对应专题，既可以在 Studio 中交给 Agent 团队完成，也可以在本地用 Coding Agent 直接开发。

## 示例项目说明

本系列按独立能力专题组织，**不再按课号或 Git tag 分步串行学习**：

- **完整 CRM 参考示例**：常规专题配有 [nocobase/doc-demo-crm](https://github.com/nocobase/doc-demo-crm)（界面与演示数据采用英文）作为参考实现，其默认分支 `main` 的最新状态已包含完整搭建好的业务功能。你可以直接拉取最新代码运行、对照查看对应能力的实现，或把专题中的业务规则与提示词直接应用到自己的项目中，无需切换任何历史 tag。
- **商业能力与外部服务**：审批、邮件等依赖商业授权或外部邮箱服务的能力仅影响对应专题，不会阻断其他专题的学习。
- **复杂专题示例**：后续发布的复杂权限、复杂审批与系统集成专题，将按业务特点采用采购、费用、合同等独立示例。
