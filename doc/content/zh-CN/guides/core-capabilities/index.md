适合需要围绕真实业务场景深入使用 NocoBase Core 的开发者与团队。核心专题围绕同一个 **CRM 销售管理示例** 逐步展开 Core 的各项应用能力与插件，每篇聚焦单一能力，可按分组顺序学习，也可按当前需求直接选学，在 Studio 中交给 Agent 团队完成或在本地用 Coding Agent 直接开发。

## 示例项目说明

每个专题相互独立，可以按需直接选学，并结合示例项目或自己的应用完成实践：

- **完整 CRM 参考示例**：各专题均以 [nocobase/doc-demo-crm](https://github.com/nocobase/doc-demo-crm)（英文界面与演示数据）作为主线参考实现，默认分支 `main` 包含已搭建完成的全部业务功能。你可以拉取 `main` 分支运行并对照查看对应能力的实现，也可以直接把专题中的业务规则与提示词应用到自己的项目中。
- **安装与运行**：按照示例项目的 [README](https://github.com/nocobase/doc-demo-crm/blob/main/README.MD) 完成安装并启动应用。
- **商业能力与外部服务**：审批、待办中心、邮箱等依赖商业授权或外部服务的前提仅作用于对应专题，不影响其他专题的实践。
