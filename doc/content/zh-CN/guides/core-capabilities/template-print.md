基于固定模板将已确认的业务单据生成可下载的正式文件。本专题以 CRM 正式报价单为例，说明如何保证生成结果不随产品目录或客户名称的后续改动而变化。

在完整示例中体验时，准备一份已确认报价（例如 **Northstar Manufacturing** 下 **Regional CRM rollout** 商机的 **Phase one implementation**，明细为 `2 × 12000.00 USD`、折扣 `15%`、总额 `20400.00 USD`；如尚未准备，可参考[审批流程与待办中心](approval-workflows.md#在待办中心查看和处理审批)完成确认），并保持 Alex 为客户负责人。

**学习模块**

- [模板打印（Skill）](../../core/using-plugins/automation/template-print.md)
- [文件存储](../../core/framework/file-storage.md)

## 明确正式单据的内容与快照规则

正式报价单记录已经确认的对外方案，必须保持内容稳定：

- 使用随应用发布的固定英文 DOCX 模板，包含客户名称、商机名称、商品明细、数量、单价、折扣、币种与总额。
- 仅已确认的报价允许生成正式文件；草稿、审批中、退回或拒绝的报价只提示需先确认，不提供生成操作。
- 报价明细使用确认时的版本，客户名称和商机名称在首次生成时定格。之后重复点击生成始终返回同一份文件，不随商品目录调价或客户改名而改变；如需调整方案，应另建新报价并在确认后生成。
- 暂不引入 PDF 转换或在线模板编辑；生成失败时保留报价状态并允许重试，避免出现内容不完整的正式文件。

## 从已确认报价生成 DOCX 文档

[模板打印](../../core/using-plugins/automation/template-print.md)提供开发指引与参考代码，生成逻辑和页面由 Agent 在应用中实现。完整示例使用[固定 DOCX 模板](https://github.com/nocobase/doc-demo-crm/blob/main/docs/templates/quotation-v1.docx)，渲染实现见[报价文件代码](https://github.com/nocobase/doc-demo-crm/blob/main/server/providers/quotation-renderer.ts)，无需额外的 PDF 转换器。

向开发 Agent 发送：

```prompt
给已确认报价增加“生成报价单”，下载英文 DOCX：
- 使用固定模板，包含客户、商机、商品明细、数量、单价、折扣、币种和总额。
- 报价内容使用确认时的版本，客户和商机名称在首次生成时保存。之后始终返回同一份文件，不随产品或客户改名而变化。
- 未确认报价不能生成文件。失去客户访问权限后，不能生成或下载报价单。
- 管理员能在系统设置中查看实际使用的模板。
```

打开已确认的 **Phase one implementation**，在 **正式报价文件** 区域点击 **生成 DOCX**，生成后点击文件名预览或下载。核对以下字段：

| 项目 | 预期值 |
| --- | --- |
| Customer | Northstar Manufacturing |
| Opportunity | Regional CRM rollout |
| Product | CRM implementation |
| Quantity / Unit price / Discount | 2 / 12000.00 / 15% |
| Total / Currency | 20400.00 / USD |

![运行示例中预览已生成的正式报价 DOCX](/assets/guides/quotation-document.png)

管理员可在 **系统设置 → 文件与报价文档** 查看当前生效的模板信息。

## 检查文档内容与访问权限

使用独立测试账号核对内容、幂等性与权限边界：

- 下载 DOCX 并在本地打开，逐项核对客户、商机、每条明细与总额。
- 修改商品目录单价和客户名称后，再次点击生成，应返回原文件且内容保持不变。
- 连续点击或重试生成，不产生第二份正式文件；对未确认报价直接调用生成接口应被服务端拒绝。
- 客户负责人、有权主管和只读共享用户可下载已生成的报价单；无关销售、未登录用户及失去客户访问权限的原负责人不能生成或下载。

并发触发生成、渲染失败重试以及升级后已生成单据是否保留，交给 Agent 在独立环境自动测试，并核对报告中的实际结果和未完成项。

## 小结与下一步

**完成的标志**：已从已确认报价生成并打开正式 DOCX 文件，核对客户、商机、明细和 `20400.00 USD` 总额无误；修改主数据或重复生成仍返回原文件，且访问权限随客户访问范围实时生效。

如果还需要为业务记录管理可增删的普通附件，查看[业务附件与文件管理](file-management.md)；如果要通过邮件发送生成的报价单，查看[邮件接入与业务收发](email.md)。
