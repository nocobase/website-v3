成员在「设置 › 成员」里管理，角色在「设置 › 角色」里管理。Agent 代表发起工作的人做事，权限不超过这个人，所以成员的角色也决定了替这位成员工作的 Agent 能做什么。

## 成员

「设置 › 成员」列出所有账号和各自的角色，可以按状态筛选、按姓名、用户名或邮箱搜索。

- **邀请**：点「邀请成员」，见 [邀请成员](../setup/invite.md)。Studio 的账号都通过邀请加入，不开放自助注册。
- **角色**：给某人添加或撤下角色。新成员第一次加入时，自动获得「设置 › 常规」里设定的「新成员默认角色」。
- **停用和启用**：有人离开团队时，停用这个账号。账号不会删除，这个人发起过的工作和记录都保留；需要时可以重新启用。停用的账号不能再分配角色。
- **修改资料、重置密码**：修改别人的姓名、用户名和邮箱，或者为别人重置密码。自己的密码在「个人设置 › 账号与安全」里修改。

谁能做这些事：

| 操作 | 谁能做 |
| --- | --- |
| 查看账号和角色 | 所有成员 |
| 邀请成员 | 管理员、所有者 |
| 分配角色、定义角色 | 管理员、所有者 |
| 停用账号、修改别人的资料、重置别人的密码 | 所有者 |

所有者的账号只有所有者能改，所有者角色也只有所有者能给或撤。最后一位所有者不能撤掉自己的所有者角色。

## 内置角色

| 角色 | 能做什么 |
| --- | --- |
| 成员 | 所有页面；提出需求，处理与自己相关的任务；在自己负责的项目里管理设置和知识库；接入个人运行环境，创建自己的 API 密钥；查看所有设置 |
| 管理员 | 所有页面、所有业务操作和所有设置：接入共享运行环境、启用 Agent、管理部署环境、Git 连接、组织的 API 密钥，分配和定义角色 |
| 所有者 | 和管理员一样，另外管理账号：停用账号、修改资料、重置密码 |

安装 Studio 时创建的初始管理员，同时是所有者，并且是系统管理员。系统管理员拥有全部权限，这个账号的角色不在这里管理。

## 自定义角色

内置角色不够用时，在「设置 › 角色」点「新建角色」，或者把一个已有的角色「复制为新角色」再修改。

角色编辑器分三组：

| 分组 | 管什么 |
| --- | --- |
| 页面 | 能打开哪些页面 |
| 设置 | 能查看或管理哪些设置，例如 Git 连接、API 密钥、角色、账号 |
| 业务操作 | 对任务、项目、应用、知识库的操作，每项分为「无」「相关」「全部」三级 |

「相关」的意思随操作而定，编辑器里会写明，例如：

- 知识库的编辑权限：“我负责的项目的”知识空间；系统知识需要「全部」。
- 应用的部署权限：我创建的应用，以及关联到我负责的项目的应用。

所有者角色拥有全部权限，不能编辑。内置角色不能删除；还有人持有、或者被设为新成员默认角色的角色，也要先改掉才能删除。

> [!NOTE] 角色能给到的上限
> 能定义角色的人，可以把任何权限放进角色里，包括给自己。只把「分配角色」「定义角色」交给信任的人。
