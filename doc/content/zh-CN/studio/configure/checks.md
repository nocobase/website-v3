description: 让代码仓库的 CI 构建应用、创建 PR 预览，并交付到 Studio 的测试环境。
---

在「项目设置 › 代码仓库 › 检查」中，为每个仓库选择检查来源。

## 检查来源

| 来源 | 谁执行检查 | 如何接入 |
| --- | --- | --- |
| 代码平台 CI | GitHub Actions、GitLab CI 等流水线 | 使用页面生成的 CI 配置 |
| 外部 CI | 团队已有的 CI 服务 | 使用仓库的 CI 密钥上报检查结果和发布预览 |
| Agent 自检 | 执行任务的 Agent | 选择后保存，无需添加 CI 文件 |

Studio 只采用所选来源的检查结果。切换来源后，旧来源的上报不再生效。

### Agent 自检

Agent 根据项目脚本、README 和 AGENTS.md 确定验证方法，通过 `nb-studio check report` 逐项上报结果，再构建并发布 PR 预览。交付回复中会说明验证结果。

### 外部 CI

选择「外部 CI」，按页面说明生成仓库的 CI 密钥。将密钥保存到现有流水线的密钥管理中，使用页面提供的命令上报检查和发布预览。不要把密钥写入仓库。

下面介绍代码平台 CI 的接入方式。

## 准备条件

- **CI 能访问 Studio**：云端 CI 无法访问本机或内网地址。使用可访问 Studio 的自托管执行机，或先配置可达的 HTTPS 地址。
- **目标环境已就绪**：Studio 默认提供预览环境。需要测试环境时，由管理员在[托管环境](../admin/environments.md)中添加。
- **有项目管理权限**：接入时需要为项目生成 CI 密钥，并保存到代码平台。

预览和测试应用以 Studio 子进程运行。生产环境由团队自行构建镜像并部署，见[部署到生产](../project/release.md)。

## 生成配置

1. 打开项目概览，点「接入预览 CI」。也可以进入「设置 › 代码仓库」，点对应仓库的「检查」。
2. 在「检查结果来自」中选择代码平台的 CI，例如「GitHub Actions」。选择触发方式和目标环境。

   | 触发方式 | 用途 |
   | --- | --- |
   | Pull request | 为每个 PR 创建独立预览，合并或关闭后删除 |
   | 推送到分支 | 将指定分支的改动交付到测试环境 |
   | 标签 | 将匹配标签的版本交付到选定测试环境，默认匹配 `v*` |

3. 填写应用目录和应用 ID。应用在仓库根目录时，目录填 `.`。
4. 点「复制给 Agent 的提示词」，交给本地 Coding Agent。它会添加 CI 文件、保存密钥并创建 PR。
5. 需要手动接入时，展开「自己手动配置」，生成 CI 密钥并保存到代码平台，再将页面提供的 CI 文件加入仓库。

![选择检查来源、触发方式和预览环境](https://static-docs.nocobase.com/studio-zh-setup-ci-options-full-1440x900-20261030.png)

每次配置一种触发方式。需要 PR 预览和分支测试环境时，分别接入。

GitHub 使用 `.github/workflows/` 下的工作流文件和 Actions 密钥 `NB_STUDIO_API_KEY`。GitLab 的文件放在 `.gitlab/` 下，由 `.gitlab-ci.yml` 引用。Studio 不会自动提交这些文件。

如果目标环境设置了保护规则，部署申请需要经过该环境的审批流程。

## 验证流水线

提交一个 PR，等待 CI 完成构建和上报：

1. 「设置 › 代码仓库」的「构建记录」出现本次构建。
2. 任务的「代码与预览」中出现检查结果和 PR 预览。
3. 打开预览，确认应用能够登录和使用。

显示「还没收到上报」时，CI 尚未完成验证。

## 维护 CI 密钥

CI 密钥属于组织，不依赖某位成员的账号。密钥只在生成时展示，保存到代码平台的 CI 密钥中，不要提交到仓库。

密钥默认 90 天到期。Studio 会在到期前 14 天、3 天和到期当天提醒项目负责人及管理员。按提醒更新代码平台中的密钥；停用或删除密钥后，CI 无法继续向 Studio 部署。

## 预览的使用范围

PR 预览使用示例数据，不包含企业业务数据。初始管理员凭据可由有权编辑任务的人在任务页查看。

不需要预览的任务，可以在任务属性中选择「不需要预览」。Agent 为 PR 添加 `no-preview` 标签，CI 模板据此跳过。预览的容量和休眠策略见[PR 预览](../release/previews.md)。
