title: NocoBase Studio
---

Studio 是人与 Agent 协同开发的治理平台，连接项目与任务、编码工具、Git 和交付流程。团队在这里推进工作、处理决策和验收；业务应用发布后独立运行。首次使用可先阅读[使用 Studio 协作开发](../getting-started/collaborate-with-studio.md)，具体操作按下方手册查阅。
