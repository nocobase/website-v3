Runner Agent 是运行环境中的编码工具与模型。你可以直接在 Studio 页面中与它对话，讨论需求、分析项目或跟进任务。

先确认团队有在线的[运行环境](../configure/runtimes.md)，并已启用可用的 [Agent](../configure/agents.md)。使用共享运行环境时，不必连接自己的电脑。

## 开始对话

1. 打开「我的会话」，切换到「Runner Agent」。
2. 新建会话，选择要对话的 Agent。
3. 涉及具体项目时，在发送第一条消息前选择项目。
4. 输入问题并发送。例如：

   ```prompt
   帮我看看这个项目里供应商评分是怎么计算的，先解释现有规则，不要修改代码。
   ```

Agent 在运行环境中执行，回复和过程保存在会话里。你可以继续补充问题，也可以添加图片或附件。

## 把讨论转为任务

需求明确后，可以让 Agent 整理为任务：

```prompt
把刚才确认的供应商评分调整整理成一个任务，先不要开始。
```

关联任务显示在会话右侧。确认需求后点「开始」，由调度 Agent 安排执行。任务有新进展或需要你回答时，可以从会话继续跟进。

已有任务也可以通过「关联任务」加入会话。会话只有你自己可见，任务按项目权限与团队共享。

## 继续或调整对话

- **切换 Agent**：结束或停止当前执行，处理排队消息后，更换 Agent。对话历史和关联任务会保留。
- **运行环境离线**：消息等待原环境恢复。需要换机器时，使用「更换运行环境」；新环境会接收对话历史，旧机器上的工作目录不会迁移。
- **没有可用 Agent**：请管理员检查运行环境是否在线、编码工具是否登录，以及 Agent 是否启用。

任务交付后，按[验收](../use/accept.md)检查结果并合并改动。
