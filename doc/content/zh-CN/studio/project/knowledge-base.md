---
title: 知识库
description: 保存需求背景、业务规则和团队资料，供成员和 Agent 共同参考。
---

知识库保存成员编写和上传的资料。Agent 按权限读取，开发中积累的经验则保存在[项目记忆](project-memory.md)。

## 选择知识空间

| 空间 | 用途 | 维护者 |
| --- | --- | --- |
| 系统知识 | 各项目共用的制度、术语和背景资料 | 管理员 |
| 项目知识 | 项目需求、业务规则和附件 | 项目负责人及获授权成员 |

打开项目的「知识库」。项目工作可以引用项目知识，也可以引用有权访问的系统知识。

![在项目知识库中整理业务资料](https://static-docs.nocobase.com/studio-zh-guide-knowledge-20261031.png)

## 添加与维护资料

1. 选择空间或文件夹。
2. 新建 Markdown 文章，或上传现有文件。
3. 保存后检查正文，必要时标为已核实。

PDF、Word、Excel、PowerPoint、CSV、文本、Markdown 和 JSON 可提取文字供搜索和阅读。图片不做文字识别，原文件可下载。文件夹最多四层。

每次保存保留新版本。过时资料可以归档，归档后不再出现在搜索中，需要时可恢复。

## 从任务保存附件

Agent 可以建议将任务附件存入知识库。上传者或任务负责人有目标空间的编辑权限时，可在建议卡片中选择保存位置。只与本次任务有关的文件不必保存。

## 控制访问

空间、文件夹、文章和文件均可设置访问权限，默认继承上级权限。可以授权给成员、角色或项目成员。

有编辑权限的成员直接维护资料；需要他人修改时，在任务评论中说明。管理权限用于调整访问范围。Agent 只能读取发起工作的人有权访问的内容。
