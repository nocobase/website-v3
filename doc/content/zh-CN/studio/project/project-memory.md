项目记忆保存在代码仓库中。Agent 在后续任务中读取，团队更换成员或模型后仍可复用。

## 保存什么

| 类型 | 内容 | 例子 |
| --- | --- | --- |
| 反馈 | 已确认的做法和纠正 | C 级供应商订单不论金额都要审批 |
| 项目 | 代码中看不出的决定与约束 | 迁移编号按合并顺序排列 |
| 参考 | 仓库外资料的位置 | 评分权重以知识库中的评分表为准 |

代码、README 或 AGENTS.md 已说明的内容不重复记录。任务进度、临时日志、密钥和个人信息也不写入记忆。

## 查看记忆

打开「项目记忆」，选择项目和仓库。也可以在项目的「记忆」页签中查看。按类型筛选或搜索，打开条目阅读正文和来源提交。

![查看项目的共享记忆](https://static-docs.nocobase.com/studio-zh-memory-20261111-normal-2x.webp)

## 更新记忆

Agent 将记忆写入仓库的 `.nb-studio/memory/`，每条一个文件。改动随任务 PR 一起评审和合并，后续任务从仓库读取。

在任务中说明需要长期遵守的规则，Agent 会判断是否值得记录。记忆与当前代码不符时，Agent 在任务 PR 中修改或删除。一个项目有多个仓库时，各仓库分别维护。

记忆沿用仓库规定的语言，未规定时使用英文。建议每个仓库不超过 50 条，单条不超过 4 KB。面向成员维护的业务资料放在[知识库](knowledge-base.md)，开发流程放在[技能](skills.md)。
