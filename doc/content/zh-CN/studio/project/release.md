---
title: 生产交付
description: 在自己的环境部署应用，并记录生产运行的版本。
---

在「发布」中选择项目，从生产卡片打开「部署指引」。项目负责人可选择版本，取得部署命令或交给 Coding Agent 的提示词。

![取得生产部署指引并记录交付版本](https://static-docs.nocobase.com/studio-zh-production-guide-20261111-normal-2x.webp)

## 准备并部署

确认版本已有可用制品。指引按当前记录提供首次安装或升级步骤。

| 方式 | 目标环境 | 部署内容 |
| --- | --- | --- |
| Docker | Docker 与 Compose | 用制品构建镜像，或拉取已登记镜像，再启动应用 |
| 安装器 | Node.js 24 与 PM2 | 用 `@nocobase/app-installer` 安装或升级应用 |

推荐在自己的基础设施构建镜像并部署。生产配置、数据库和密钥由团队维护。升级前备份数据库，完成后检查登录和关键业务流程。

需要自动执行时，将指引交给能访问目标服务器的 Coding Agent。Studio 本身不执行生产部署。

## 记录生产版本

确认部署成功后，在指引底部记录已部署版本，或在版本的更多操作中选择「记录为生产版本」。Studio 据此计算哪些已完成任务进入生产。

记录表示团队确认的部署结果，不会触发部署。

## 回滚

在生产环境恢复之前的镜像或使用安装器回滚。涉及数据库迁移时，同时按升级前的备份恢复数据。确认应用正常后，在 Studio 中记录回滚到的版本。
