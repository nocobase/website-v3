项目负责人和管理员可以修改项目设置。打开项目，通过「成员」管理协作人员，通过「设置」配置开发工作。

## 成员与可见性

在「成员」中搜索并添加已有成员。新成员先[加入 Studio](../setup/invite.md)，也可以在邀请时直接加入项目。

- **所有人**：工作区成员都能查看项目。
- **仅项目成员**：只有项目成员和管理员可见。
- **项目负责人**：从项目成员中指定。移除当前负责人前，先指定另一位负责人。

项目状态、优先级和起止日期在项目属性中修改。

![项目成员与负责人](https://static-docs.nocobase.com/studio-zh-project-members-20261111-normal-2x.webp)

## 配置项目

| 分区 | 配置内容 |
| --- | --- |
| 常规 | 名称、描述和默认提交署名 |
| 代码仓库 | 仓库、检查来源、分支规则和预览 |
| Agent 运行变量 | 开发任务使用的环境变量与密钥 |
| 默认技能 | 项目或仓库每次运行使用的技能 |

![在仓库卡片中配置检查、分支规则和预览](https://static-docs.nocobase.com/studio-zh-project-repositories-20261111-normal-2x.webp)

多个仓库按顺序排列，第一个为主仓库。移除关联不会删除 Git 平台上的仓库。检查和预览的配置见[检查与 CI](../configure/checks.md)，技能配置见[技能](skills.md)。

### 接入已有仓库

在「新建项目」中选择「已有仓库」，从 Git 连接可访问的仓库中选择。已有应用通常选择「不初始化」。

需要补充应用基础配置时，可选择「NocoBase 应用」或「根据提示词」初始化。Agent 保留现有文件，通过分支和 PR 提交改动，由负责人验收。没有仓库时可选择「稍后添加」。从空白应用开始，见[创建首个项目](../setup/new-project.md)。

### 提交署名

项目可默认使用成员本人署名，或将 Agent 列为共同作者。成员在个人偏好中作出的选择优先于项目默认值。

### Agent 运行变量

变量可以属于整个项目，也可以只属于某个仓库。同名变量按项目、仓库、Agent 的顺序覆盖。

- 保存后隐藏值。查看密钥会记录查看人和时间。
- 选择「从运行环境取」时，在运行环境中用 `nocobase-runner env set NAME` 提供值。
- 勾选「仅限共享运行环境」，可限制带此变量的工作只在共享运行环境执行。

预览和测试应用的配置应放在[托管环境](../admin/environments.md)或应用配置中，不放在 Agent 运行变量里。

## 删除项目

管理员可在项目的更多操作中删除项目。项目关联会删除，任务保留并移出项目，Git 仓库不受影响。
