---
title: 技能
description: 将团队的设计、开发、评审和交付规范提供给每次 Agent 运行。
---

技能由 `SKILL.md` 和可选的参考文件、脚本组成。`name` 标识技能，`description` 说明何时使用，正文规定工作方法。

## 按用途查找技能

在「技能」中按用途筛选。选择「执行流程」查看任务步骤，例如标准流程的开发、评审和交付。「普通技能」用于设计、实现、评审或评论规范，可随每次运行加载。「插件托管」包含质量测试等功能自带的技能。

![技能库中的普通技能](https://static-docs.nocobase.com/studio-zh-skills-20261126-61a3c15c4f.webp)

## 创建和更新

打开「技能」，点「新建技能」，填写 `SKILL.md` 并添加参考文件。也可以导入 Agent Skills 格式的 ZIP 包。修改团队技能后，点「保存新版本」。在历史版本中可以查看内容或导出 ZIP。

让 Agent 代为查询或维护团队技能时，使用发起人的技能权限。内置流程和插件托管技能为只读。

## 设置使用范围

在项目的[工作流程](../use/multi-role-workflow.md)中选择默认流程。要让同一份开发规范随每次运行加载，在「常驻技能」中选择项目或仓库，再添加普通技能。

如果所有项目都需要这项规范，可以在普通技能详情中启用全局挂载。

要为以后创建的项目设置初始值，打开技能详情。流程可以「设为新项目默认流程」，同一时间只有一个默认流程。普通技能可以分别开启「新项目自动挂载」。

质量维度在[质量配置](../quality/settings.md)中绑定 Skill。每次测试固定创建时的技能版本，修改只对后续测试生效。
