---
title: 技能
description: 将团队的设计、开发、评审和交付规范提供给每次 Agent 运行。
---

技能由 `SKILL.md` 和可选的参考文件、脚本组成。`name` 标识技能，`description` 说明何时使用，正文规定工作方法。

## 内置技能

| 技能 | 用途 |
| --- | --- |
| studio-workflow | 调度、任务步骤和交付条件 |
| studio-development | 实现、验证和失败处理 |
| studio-approach | 方案设计 |
| studio-review | 代码评审和问题分级 |
| studio-comment-style | 评论和交付报告 |

前四项默认挂到新项目，评论规范默认全局挂载。团队可以修改内置技能，升级不会覆盖已保存的修改。NocoBase 应用模板还包含 Core 的开发规范。

![统一维护团队技能与版本](https://static-docs.nocobase.com/studio-zh-skills-20261111-normal-2x.webp)

## 创建和更新

在「技能」中点「新建技能」，填写 `SKILL.md` 并添加所需文件。也可以导入 Agent Skills 格式的 ZIP 包。

修改后点「保存新版本」。历史版本可查看和导出为 ZIP。创建技能需要 Agent 管理权限；创建者和管理员可修改，项目负责人可将已有技能挂到项目。

## 设置使用范围

| 范围 | 入口 | 生效范围 |
| --- | --- | --- |
| 全局 | 技能详情的全局挂载 | 所有项目 |
| 项目 | 项目设置 › 默认技能 | 该项目的运行 |
| 仓库 | 默认技能中选择仓库 | 该仓库的运行 |

三个范围叠加，同名技能以更具体的范围为准。打开「新项目自动挂载」只影响之后创建的项目。

技能应说明团队特有的规则，例如测试要求、评审标准和交付证据。一次围绕一项工作写清楚，修改后通过后续任务的运行记录和交付报告检查效果。

质量维度在[测试设置](../quality/settings.md)中绑定 Skill。每次测试固定创建时的技能版本，修改只对后续测试生效。
