## 简介

随着 Studio 中的功能持续开发与迭代，团队需要持续测试，了解每次交付的业务效果及其对已有功能的影响，持续掌握项目质量。

质量模块提供专业的测试能力，为项目交付提供质量保障，通过持续测试发现问题、跟进修复并验证效果，不断改进项目质量。

![Studio 为开发交付提供内置业务与专题测试能力，输出功能检查结果、测试报告和后续问题](/assets/studio/quality/quality-assurance-overview-v2.png)

- **持续测试，跟上项目迭代。** 每日验证新增交付，发布前检查待发布功能，修复后持续回归，让团队持续掌握项目质量。
- **内置专业测试能力。** Studio 提供业务测试和多种专题测试计划，配套专业的测试方法与检查标准，可以按需启动或定时执行。
- **主动发现问题与测试盲区。** Agent 根据需求和业务规则设计检查点，主动检查容易遗漏的边界与异常情况，发现功能缺陷和自动化保障缺口，并形成可跟进的问题。

## 查看项目质量

在「质量」中，可以查看有权限访问的项目，了解各项目当前的质量状态。

![查看有权限访问的项目及其当前质量状态](/assets/studio/quality/quality-projects-overview-simple.png)

点击项目，可以查看质量详情及各项测试的最近执行情况，并结合测试结果和业务需要，按需启动新一轮测试。

![项目质量详情：查看自动化覆盖率和未解决问题，并使用内置测试计划](/assets/studio/quality/quality-functional-plans-simple.png)

Studio 的质量计划提供**专业的测试方法和检查标准**。Agent 会结合项目需求与业务规则，设计正常流程、边界条件、异常处理等检查点，并**根据风险选择单元、接口或页面验证**。

测试会**复用已有自动化用例**，并对覆盖缺口**补充验证**。报告明确记录实际结果、自动化保障缺口和发现的问题，帮助团队**跟进修复、持续回归**，逐步减少缺陷和测试盲区。

**功能测试**主要针对项目的业务功能进行验证，包含：

- **整体质量摸底**：摸底全系统功能，分析业务检查点的自动化覆盖情况，找出保障缺口。
- **发布测试**：验证待发布任务的业务功能及其对已有流程的影响，帮助发现发布前需要解决的问题。
- **每日测试**：每天验证前一天已完成的开发任务，及时发现功能与回归问题。

**专题测试**针对整个项目的专项风险，按各专题的测试方法和检查标准开展验证，包含：

- **安全测试**：检查异常输入处理、敏感信息保护和数据泄露风险。
- **性能测试**：检查关键流程的响应时间、并发处理和负载下的稳定性。
- **权限测试**：交叉验证不同角色、数据归属和访问方式，检查越权操作与访问隔离。
- **UX 测试**：检查操作流程、交互反馈、错误恢复和键盘操作等使用体验。
- **浏览器兼容测试**：验证关键业务流程在不同浏览器中的显示与交互是否一致。

![专题测试：选择需要检查的方向，开始测试或设置定时](/assets/studio/quality/quality-thematic-plans-simple.png)

## 测试执行

可以通过三种方式开始一轮测试：

- **直接执行**：在计划上点击「开始测试」。
- **与 Agent 对话**：在会话中让 Agent 为指定项目启动一轮测试。
- **定时执行**：设置执行频率和时间，由系统定时启动测试。

![设置测试执行频率和时间，并查看下次执行安排](/assets/studio/quality/schedule.png)

## 阅读报告

测试报告按业务场景展示本轮验证的功能点。展开场景，可以看到具体检查了什么，以及哪些检查点通过、未通过或尚未验证。

![展开测试场景，查看具体功能点、检查内容及验证结果](/assets/studio/quality/scenario-tree.png)

报告概览展示质量结论、本轮通过率、已有测试覆盖率、复用测试及后续任务，帮助判断这轮验证的结果。

同时可以查看上次测试时间，以及此后新增、尚未被报告覆盖的需求，判断是否需要再测试一轮。点击「查看新增需求」可查看对应任务。

![测试报告概览：查看本轮结论、指标，以及上次测试后新增的待测需求](/assets/studio/quality/report-overview-freshness.png)

点击「查看报告」阅读完整测试报告，需要分享或留档时可以下载。

![打开完整测试报告，阅读详细验证结果并下载](/assets/studio/quality/report-preview-v2.png)

## 问题跟进

在「后续任务」中查看测试发现的缺陷、待确认问题和自动化缺口，关联 Studio 任务安排处理，并跟踪修复进展。

![在后续任务中跟进测试发现的问题及修复进展](/assets/studio/quality/followups.png)

修复完成后，可以再次执行相关测试，确认问题是否解决。

## 自定义测试

你可以随时在「我的 Agent」中与 AI 对话，描述想要测试的项目或功能。AI 会根据需求生成测试计划，确认后开始执行。

![Agent 根据对话中的测试需求生成计划，确认后开始测试](/assets/studio/quality/plan-confirmation-framed.png)

测试完成后，可以在会话中打开报告，查看测试结果和发现的问题。
