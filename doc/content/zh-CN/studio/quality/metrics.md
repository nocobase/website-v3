在项目的「质量 › 指标」中选择测试类型和时间范围，查看结果与变化。概览页也会显示主要维度的最新数据。

![指标区分已有结果与未验证项目](https://static-docs.nocobase.com/studio-zh-quality-metrics-20261111-normal-2x.webp)

## 指标口径

| 数据 | 来源 |
| --- | --- |
| 任务、场景与检查点结果 | 各维度提交的明确结论和证据 |
| 自动化测试的通过、失败、跳过和用时 | 上传的 Vitest、Playwright 等测试报告 |
| 依赖漏洞 | 依赖审计输出，区分生产和开发依赖 |
| 权限问题、性能风险、代码质量问题 | 各维度的实际检查结果 |
| 跟进任务 | 测试关联的缺陷、问题、用例、场景和整理任务 |

没有报告就没有对应指标，不能把空值理解成零问题。未验证和不适用也不等于通过。

## 趋势与明细

点击指标查看对应测试、场景或问题明细。比较时先确认测试类型、范围、代码提交和维度是否一致。

新增或删除场景会改变总数。相同标识的场景可跨次比较；测试数量增加或问题数量下降，都需要结合范围变化判断。用[报告与证据](reports.md)确认变化的原因。
