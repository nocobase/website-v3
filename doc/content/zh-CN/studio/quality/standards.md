---
title: 质量标准
description: 五个维度的指标、默认达标标准和测试方法，以及项目如何调整。
---

Studio 为每个维度内置了一组指标和达标标准。测试时，工具实际运行得出每项指标的测试结果，服务端再与标准比对，判定是否达标。

**项目可以定义自己的标准**：检查方法和判定规则由维度使用的 Skill 定义，可以[替换 Skill](settings.md#调整项目标准)或新增维度。

## 功能

| 指标 | 标准 | 工具 | 方法 |
| --- | --- | --- | --- |
| 任务场景失败数 | = 0 | Vitest、Playwright、浏览器 | 按规则把任务拆成场景，逐条验证 |
| 核心场景失败数 | = 0 | Vitest、Playwright、浏览器 | 项目测试按核心场景清单逐条验证 |
| 产品缺陷导致的失败用例数 | = 0 | Vitest、Playwright | 运行已有的自动化用例，逐个分析失败原因 |

## 权限

| 指标 | 标准 | 工具 | 方法 |
| --- | --- | --- | --- |
| 未登录越权数 | = 0 | 通用权限引擎 | 用匿名身份请求每个接口 |
| 读越权数 | = 0 | 通用权限引擎 | 用没有权限的身份读取数据，检查响应中有没有不该看到的内容 |
| 写越权数 | = 0 | 通用权限引擎 | 用没有权限的身份写入数据，再读回确认有没有被修改 |
| 正向对照失败数 | = 0 | 通用权限引擎 | 用有权限的身份执行同样的请求，确认能正常访问 |
| 未声明权限的接口数 | = 0 | Vitest | 在任务 CI 中检查每个接口都声明了所需的权限 |

## 安全

| 指标 | 标准 | 工具 | 方法 |
| --- | --- | --- | --- |
| 严重依赖漏洞数 | = 0 | pnpm audit | 审计全部依赖 |
| 高危依赖漏洞数 | = 0 | pnpm audit | 审计全部依赖 |
| 密钥泄露数 | = 0 | gitleaks | 扫描当前代码和 Git 历史 |
| 严重代码安全问题数 | = 0 | Agent | 按安全检查清单审查代码 |
| 高危代码安全问题数 | = 0 | Agent | 按安全检查清单审查代码 |
| 被动扫描高危告警数 | = 0 | OWASP ZAP | 检查每个接口的响应头、Cookie 和信息泄露 |
| 主动扫描高危告警数 | = 0 | OWASP ZAP | 对每个接口做注入、XSS 等攻击测试 |

安全测试在测试自己准备的隔离环境中进行，不扫描团队正在使用的系统。越权问题由权限维度负责。

## 性能

| 指标 | 标准 | 工具 | 方法 |
| --- | --- | --- | --- |
| 首屏 JS 体积 | ≤ 2 MB | Lighthouse | 实测页面加载 |
| 接口 P95 耗时 | ≤ 500 ms | autocannon | 实测页面用到的接口，每个接口采样 10 次 |
| 接口响应体 | ≤ 500 KB | 采集脚本 | 记录每个接口的响应大小 |
| 每次请求的 SQL 数 | ≤ 20 条 | PostgreSQL | 统计每个请求发出的 SQL |
| 最慢 SQL 耗时 | ≤ 50 ms | PostgreSQL（`EXPLAIN`） | 慢 SQL 查看执行计划 |

## 代码质量

| 指标 | 标准 | 工具 | 方法 |
| --- | --- | --- | --- |
| 重复率 | ≤ 3% | jscpd | 找出重复的代码段 |
| 新增复杂度 > 50 的函数数 | = 0 | eslint-plugin-sonarjs | 计算每个函数的认知复杂度 |
| 新增未使用的文件数 | = 0 | knip | 找出没有被引用的文件 |
| 新增未使用的依赖数 | = 0 | knip | 找出没有被使用的依赖 |
| 新增循环依赖数 | = 0 | dependency-cruiser | 分析模块之间的导入关系 |
| Agent 审查的高级别问题数 | = 0 | Agent | 按模块审查设计、项目约定和测试价值 |

代码质量只要求**新增**部分达标，已有代码的问题单独统计，不影响本次结论。lint 和类型检查由 CI 把关，不在本维度检查。
