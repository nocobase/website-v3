「发布」按项目汇总改动的交付进展。选择项目，查看预览、测试环境、版本和生产记录。

![从项目查看预览、测试和版本交付](https://static-docs.nocobase.com/studio-zh-guide-releases-20261031.png)

| 环节 | 内容 | 下一步 |
| --- | --- | --- |
| 预览 | PR 的独立应用和构建状态 | 验证改动 |
| 测试 | 测试应用当前运行的提交或版本 | 检查合并后的效果 |
| 发布 | Git tag 对应的版本及制品 | 选择交付版本 |
| 生产 | 团队记录的生产版本 | 在自己的环境部署后更新记录 |

预览和测试应用可由 Studio 托管。生产由团队自行构建镜像或使用安装器部署，Studio 不承接生产部署。

## 查看待发布任务

「待发布」列出尚未交付到生产的已完成任务，并标出是否已进入测试环境。先核对本次版本包含的任务，再发布和部署。

任务上的测试、生产标记由提交关系计算。生产标记依据负责人记录的版本；回滚到较早版本后，不再包含的改动会撤下标记。

## 继续交付

- 配置合并前验证：[PR 预览](previews.md)。
- 管理测试应用：[托管环境](../admin/environments.md)。
- 创建版本和准备制品：[版本与发布](versions.md)。

项目负责人会收到待发布改动提醒。部署失败或受保护测试环境的审批事项在[收件箱](../use/inbox.md)中处理。
