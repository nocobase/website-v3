## 打开任务的预览

1. 打开任务的「代码与预览」，找到要验证的 PR。
2. 核对预览对应的提交。如果 PR 已有新提交，等新构建发布后再验证。
3. 打开预览应用。需要登录时，有权编辑任务的成员可以在任务顶部的 PR 行点「账号」，复制初始管理员的登录信息。

![任务中的 PR 预览提供构建状态、访问入口和登录信息](https://static-docs.nocobase.com/studio-zh-req-preview-20261111-normal-2x.webp)

在应用中逐项验证交付报告里的验收场景，再回到[任务验收](../use/accept.md)通过交付或退回修改。

预览闲置后会在下次访问时唤醒。PR 合并或关闭后，对应的预览应用会被回收。见[托管环境](../admin/environments.md#管理预览应用)。

## 不需要预览时

在任务属性中打开「不需要预览」。Agent 为 PR 添加 `no-preview` 标签，生成的 CI 模板据此跳过预览。已有预览不会因此自动删除。

仓库默认是否构建预览，见[配置仓库的 PR 预览](../configure/pr-previews.md)。
