---
title: 配置 Agent
description: 确认可用模型，并为调度 Agent 选择执行模型。
---

运行环境在线后，打开「Agent 管理 › Agent」。常用模型会自动加入团队并启用，无需逐个添加。

## 确认可用 Agent

检查「在哪跑」是否包含刚接入的运行环境。每个「编码工具 · 模型」组合对应一个 Agent。

![运行环境上报并启用的 Agent 团队](https://static-docs.nocobase.com/studio-zh-setup-agents-full-1440x900-20261030.png)

首次配置保留默认分工和推理强度。调度 Agent 会根据「擅长什么」分派工作。

## 设置调度 Agent

1. 在页面上方的「调度 Agent」中点「设置」。
2. 「首选」选择一个可用、适合推理和任务规划的 Agent。
3. 有其他可用模型时，可以设置「备选」。
4. 保存，其他设置保留默认值。

![为调度 Agent 设置首选和备选模型](https://static-docs.nocobase.com/studio-zh-setup-coordinator-full-1440x900-20261030.png)

**完成的标志**：团队有已启用的 Agent，调度 Agent 的首选有可用运行环境。

接着[创建首个项目](new-project.md)。添加模型、调整分工和调度规则，见[Agent 配置](../configure/agents.md)。
