---
title: 邀请成员
description: 邀请团队成员加入 Studio，分配项目和角色。
---

项目准备好后，管理员可以邀请需求方和团队成员加入。发送邮件前，先[配置邀请邮件](../admin/notifications.md#邀请邮件)。

## 发送邀请

1. 打开「设置 › 成员」，点「邀请成员」。
2. 填写邮箱。多个邮箱用换行、逗号或空格分隔，一次最多 50 个。
3. 选择「加入的项目」。被邀请人以项目成员身份加入。
4. 点「发送邀请」。

![填写成员邮箱并选择加入的项目](https://static-docs.nocobase.com/studio-zh-setup-invite-full-1440x900-20261030.png)

已配置邮件服务时，Studio 会发送邀请邮件。未配置时，结果显示「邮件未发送」，可以复制邀请链接，单独发给对方。

邀请链接有效期为 7 天。对方打开链接、设置姓名和密码后加入团队。

## 分配角色

新成员使用「设置 › 常规」中设置的默认角色。内置角色包括：

| 角色 | 权限 |
| --- | --- |
| 成员 | 提出、跟进和验收相关任务，管理自己负责的项目，接入个人运行环境 |
| 管理员 | 管理 Studio 设置、共享运行环境、Agent、Git 连接和托管环境 |
| 所有者 | 包含管理员权限，还可管理账号资料、停用账号和重置密码 |

在「设置 › 成员」中调整角色。需要自定义权限时，见[成员与角色](../admin/members-and-roles.md)。

**完成的标志**：受邀成员已出现在成员列表中，可以打开分配给自己的项目。

将[开始使用](../join/index.md)发给成员，按「登录 → 提出需求 → 跟进 → 验收」开始工作。连接个人 Git 账号和个人运行环境是按需配置，不是提出需求的前提。
