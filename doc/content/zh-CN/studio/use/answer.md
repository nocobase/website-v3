---
title: 回答 Agent 的提问
description: 确认业务规则，处理失败运行、负责人交接和个人运行环境请求。
---

任务需要业务决策或补充信息时，调度 Agent 会说明问题。你可以从「我的任务 › 等你处理」打开并回答。

## 回答阻塞中的提问

1. 阅读「需要你」卡片。需要更多背景时，点「查看调度 Agent 最新说明」。
2. 点「回复」，在对应线程中写下决定或补充资料。
3. 发送后，调度 Agent 根据答复继续安排。

![阻塞中的任务明确列出需要负责人确认的问题](https://static-docs.nocobase.com/studio-zh-guide-answer-20261031.png)

```prompt
C 级供应商的订单不论金额都需要采购经理审批。其他供应商仍按金额判断。
```

拿不准时，可请 Agent 先列出方案及其影响。缺少密钥时，通过项目变量或相应配置入口提供，不要放入评论。

## 运行失败

打开运行记录查看失败原因。临时网络故障、额度不足或运行环境离线，处理方式不同。

失败运行用完自动重试次数后，任务上的决定卡片会提供重试、重新分配或停止重试等选项。先恢复依赖，再决定是否重试。调度 Agent 也会尝试将失败步骤交给其他合适的 Agent。

## 评论运行达到上限

默认每个任务每 24 小时最多触发 20 次 Agent 评论运行，管理员可调整。达到上限后，Studio 暂停继续触发并通知负责人。

先检查是否在重复修复同一问题。确需继续时，使用任务页的继续操作，或发出新的有效指令。

## 接手转给你的任务

收到负责人交接后，Agent 工作暂停，等待你接受。

- **接手**：成为负责人，继续回答提问或验收。
- **拒绝**：回到原负责人；原账号已停用时，由你保留并保持暂停。

## 个人运行环境的请求

别人请求继续你的任务，且工作要使用你的个人运行环境时，Studio 会先请求确认。接受后，该次工作才可在你的环境中执行；拒绝则不执行。

个人运行环境的范围见[接入个人运行环境](../join/personal-runtime.md)。
