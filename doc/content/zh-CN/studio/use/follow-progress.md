任务详情集中展示当前执行、下一步安排和交付结果。需要补充要求时，直接在任务中评论。

## 任务页

![摘要说明现在谁在做，以及接下来的安排](https://static-docs.nocobase.com/studio-zh-guide-task-progress-20261031.png)

| 区域 | 内容 |
| --- | --- |
| 现在 | 实际运行状态：正在工作的 Agent、执行环境，或等待原因 |
| 接下来 | 调度 Agent 安排的下一步 |
| 需要你 | 等待负责人回答或验收的事项及处理按钮 |
| 交付报告 | 本次交付的改动、验证和验收标准 |
| 属性 | 负责人、执行者、优先级、标签和日期 |

「动态」保留评论与状态变化，默认只看对话；切换到「全部」查看系统记录。「说明」是任务要求，「代码与预览」汇总 PR、检查和预览，「运行记录」记录每次 Agent 执行。有子任务时，也可查看其进展。

## 用评论和 Agent 沟通

- **评论**：补充要求、回复问题或 `@` 指定 Agent，会唤醒对应 Agent 和任务执行者。
- **备注**：留下记录，不唤醒 Agent。
- **回复**：在某条评论下继续讨论，保留线程上下文。

```prompt
供应商暂停合作后，已有订单仍可查看和收货，只限制新建订单。请按这个规则调整。
```

要求变更会影响后续安排。需要讨论而暂不改动时，在评论中明确说明。

## 问 Agent

右上角「问 Agent」打开带有任务上下文的私有会话。适合询问阻塞原因或改动范围。要把结论共享给项目成员，请写回任务评论。

## 运行记录

![查看每次执行的 Agent、状态、用时和过程](https://static-docs.nocobase.com/studio-zh-guide-runs-20261031.png)

| 操作 | 用途 |
| --- | --- |
| 查看执行过程 | 阅读本次执行的过程与结果 |
| 查看完整提示词 | 检查 Agent 收到的上下文 |
| 停止 | 请求停止当前执行，已有改动不会自动撤销 |
| 重试 | 将失败的运行重新加入队列 |

停止后，先检查已完成的工作，再说明如何继续。运行失败的处理见[回答提问](answer.md#运行失败)。
