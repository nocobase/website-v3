顶栏的收件箱图标打开消息列表。任务决策主要在「我的任务」处理，会话回复在「我的会话」跟进。

## 收件箱和「我的任务」的分工

| 入口 | 内容 |
| --- | --- |
| 我的任务 | 验收、阻塞问题、运行失败和负责人交接 |
| 我的会话 | Agent 回复、会话问题和权限确认 |
| 收件箱 | 同事评论、提及、指派，以及任务之外的系统消息和决定 |

![在收件箱中阅读消息并打开相关任务](https://static-docs.nocobase.com/studio-zh-inbox-20261111-normal-2x.webp)

## 收件箱的视图

- **全部**：消息与需要决定的事项。
- **待我决定**：尚待处理的非任务决定。
- **通知**：供你了解的消息。

用 <kbd>J</kbd> / <kbd>K</kbd> 切换列表项。标为已读、删除消息只影响自己的收件箱，不会替你完成任务。

## 提醒

在「个人设置 › 通知」配置提醒：

| 方式 | 使用场景 |
| --- | --- |
| 提示音 | Studio 在前台时提醒新待办、会话回复和提及 |
| 桌面通知 | Studio 在后台时显示浏览器通知，需允许通知权限 |
| 推送通知 | 页面关闭后向已订阅设备发送提醒，需管理员配置推送 |

![在通知设置中选择提醒方式](https://static-docs.nocobase.com/studio-zh-notifications-20261111-normal-2x.webp)

正在查看的任务或会话不会重复提醒。各入口的数字按各自待办和未读内容计算。

## 在手机上订阅推送

Studio 需使用 HTTPS。每台设备单独订阅；iPhone 和 iPad 需 iOS/iPadOS 16.4 或更高版本，先在 Safari 中添加到主屏幕，再从主屏幕打开 Studio 订阅。

无法订阅时，按[通知与推送](../admin/notifications.md)检查服务器配置与浏览器权限。

## 订阅一个任务

在任务属性中订阅或取消订阅通知。若只是想把任务保留在工作列表中，使用关注星标，见[我的任务](my-tasks.md#关注任务)。
