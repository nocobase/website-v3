「我的任务」汇总你负责、执行或关注的任务。需要你回答、验收或处理执行问题的事项，会进入「等你处理」。

![左侧按待办分组，右侧直接处理选中的任务](https://static-docs.nocobase.com/studio-zh-my-issues-20261111-normal-2x.webp)

## 按“轮到谁”分组

| 分组 | 内容 |
| --- | --- |
| 关注 | 已关注的任务，以及别人新增的动态 |
| 等你处理 | 需要你决定的事项，等待较久的排在前面 |
| 进行中 | 正在推进的任务 |
| 等别人 | 等其他负责人回答或验收的任务 |
| 待规划 | 尚未开始的任务 |
| 已完成 | 最近七天完成的任务，默认折叠 |

每个任务只出现一次。已取消的任务默认不显示，可用状态筛选查找。侧边栏的数字统计需要你处理的任务和任务计划，不等同于任务总数。

## 处理待办

| 提示 | 操作 |
| --- | --- |
| 等你验收 | [阅读报告并验收](accept.md) |
| 等你回复 | [回答阻塞中的提问](answer.md#回答阻塞中的提问) |
| 运行失败 | 查看原因，决定是否重试 |
| 等你确认方案 | 检查草稿并确认或修改 |
| 等你接手 | 接受或拒绝负责人交接 |

处理后，任务会暂时保留在当前位置，直到切换到其他任务。页面提供撤销或跳到下一条待办的操作。

## 视图

- **分栏**：列表与详情并排，适合逐项处理；可拖动中间边界调整宽度。
- **表格**：按任务树查看子任务。
- **看板**：按状态查看，拖动卡片可更新状态。
- **Agent 队列**：按 Agent 查看运行和等待的工作。

Studio 会记住所选视图。队列说明见[工作负荷与模型用量](../project/usage.md)。

## 关注任务

点任务右上角的星标，将它加入「关注」。即使不是负责人，也可以在这里跟进。最多关注 100 个任务。

## 快捷键

输入框之外可使用：

| 按键 | 操作 |
| --- | --- |
| <kbd>J</kbd> / <kbd>K</kbd> 或方向键 | 下一个 / 上一个任务 |
| <kbd>S</kbd> | 关注或取消关注 |
| <kbd>Enter</kbd> | 打开任务页 |
| <kbd>/</kbd> | 搜索 |
| <kbd>Esc</kbd> | 回到列表 |
