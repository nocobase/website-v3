::figure sessions-list | 「我的会话」：每段会话下面的进度条，一段代表一个任务，颜色表示它的状态

列表里的每段会话写明属于哪个项目、有几个任务。进度条一段代表一个任务：绿色已完成，紫色待验收，蓝色进行中，琥珀色阻塞中，灰色待规划。有任务等你处理时，会标出来。

会话只有你自己能看到。会话里的 Agent 以你的身份和权限在 Studio 里做事，例如建任务、发评论，做不了你做不了的事。

## 和谁对话

会话面板里有两种模式：

| | 我的会话 | Runner Agent |
| --- | --- | --- |
| 是谁 | 你自己的 Agent，例如 Claude Code、Codex | Agent 团队里的一个 Agent，由运行环境执行 |
| 它看得到什么 | 你允许的目录里的代码、工具和配置 | 运行环境上的代码仓库 |
| 需要准备 | [连接自己的电脑](../join/connect-computer.md)，只需一次 | 不需要 |
| 适合 | 结合你手上的代码讨论需求、整理成任务 | 提问、查资料、整理成任务 |

两种模式的会话都列在「我的会话」里。

## 开始一段会话

1. 在「我的会话」点「新会话」。
2. 选择模式。用「我的会话」时，选择你的 Agent 和工作目录；用「Runner Agent」时，选择团队里的一个 Agent。两种模式都可以指定会话所属的项目。
3. 说说要做什么。可以一次说好几件事，也可以贴截图。

讨论需求时，选能力最强的模型，理解会更准确。

在任务页、项目页点「问 Agent」，会带上当前页面作为上下文开始会话。

## 把讨论整理成任务

聊清楚之后，让 Agent 把讨论整理成任务，例如“把这三件事建成任务，放进供应商管理项目”。

::figure req-session | 会话里列出它建的任务，可以直接开始执行

- 会话建的任务挂在这段会话上，会话里显示它们的最新状态和进度。
- 点「开始执行」，把任务交给 Agent 团队；点「先不开始」，任务留在「待规划」。
- 在输入框里用 `#` 提到已有的任务，让 Agent 读它、在上面评论，或者按你的要求修改。
- 从任务页也能回到当初建它的会话。

## 跟进会话

- 会话列表可以按「等你确认」「进行中」筛选。Agent 请求权限或等你确认时，会话会标出来。
- 会话里交给 Agent 团队的任务，关键进展会以卡片的形式回到会话中，例如运行结束、阻塞、待验收、失败、关闭、开出 PR，Agent 会总结并建议下一步。
- 不再需要的会话可以归档，之后随时恢复。
