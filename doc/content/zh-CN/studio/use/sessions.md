「我的会话」保存你与 Agent 的讨论和关联任务。需要继续补充需求或询问结果时，可以回到同一段会话。

![与 Runner Agent 讨论需求，查看关联任务](https://static-docs.nocobase.com/studio-zh-req-session-20261111-normal-2x.webp)

## 和谁对话

Runner Agent 在团队共享或自己的个人运行环境中工作。开始前，需要有在线运行环境和可用 Agent。

会话默认只有你可见。分享后，指定成员可以只读查看分享时的内容；后续消息需要再次分享。Agent 按发起人的权限执行，关联任务按项目权限开放。

## 开始一段会话

1. 点「新会话」。
2. 选择 Agent。
3. 需要项目代码时，在首次发送前选择项目。
4. 描述需求，按需添加图片、附件或 `#任务编号`。

在项目或任务页点「问 Agent」，会带上当前页面的上下文。Runner Agent 的项目绑定、消息排队和更换运行环境，见[与 Runner Agent 对话](../join/runner-agent.md)。

## 把讨论整理成任务

```prompt
把刚才确认的三个改动建到供应商管理项目，分别写清验收方式，先不要开始。
```

创建的任务显示在会话中。检查后点「开始执行」，或先保留在「待规划」。从任务属性也可以返回关联会话。

## 跟进会话

- 列表显示关联任务数和状态进度条，一段对应一个任务。
- 按「等你确认」「进行中」筛选需要关注的会话。
- 任务开始、阻塞、待验收或完成时，相关进展会返回会话。
- 不再活跃的会话可以归档，需要时恢复。

归档并非永久保留。Runner Agent 会话默认归档 30 天后清理；长期需要的结论请保存到任务、[知识库](../project/knowledge-base.md)或[项目记忆](../project/project-memory.md)。
