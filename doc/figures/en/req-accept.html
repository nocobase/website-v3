Before the change

Suppliers had only basic profiles, with no scores or tiers, and orders to tier C suppliers needed no approval.

What changed
  • Suppliers now have a score and an A, B, or C tier, recalculated every night
  • Orders to tier C suppliers need purchasing manager approval
  • New suppliers start at tier B and are re-tiered after three months
Acceptance criteria
  • The supplier list shows each supplier’s tier
  • An order to a tier C supplier goes to the purchasing manager for approval after it is submitted
