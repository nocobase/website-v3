Delivery report
How it was before

Suppliers had only basic profiles, with no score or tier. An order needed the purchasing manager’s approval only above ¥50,000.

What changed
  • Suppliers now have a score and a tier, A, B, or C, recalculated every night from on-time delivery, quality pass rate, and price
  • Every order to a tier C supplier now goes to the purchasing manager for approval when it is submitted, whatever the amount. Other suppliers keep the amount rule
  • New suppliers start at tier B and are re-tiered after three months
How it was checked

Walked through all three acceptance scenarios in the preview. All tests and CI passed, and a model from another vendor approved the review.

Open issues
  • Existing suppliers get a tier only after the first nightly recalculation. Recommend running it once by hand on release day.
Acceptance criteria
  • The supplier list shows each supplier’s tier (screenshot 1)
  • A ¥10,000 order to a tier C supplier goes to the purchasing manager for approval when submitted (screenshots 2 and 3)
