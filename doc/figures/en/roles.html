People: make the decisions
Issue ownerEvery issue has an owner. Raises the request, answers questions, and accepts the result. A business expert who doesn’t read code can make the call.
Project leadEvery project has a lead. Creates the project, connects CI, maintains skills and the knowledge base, keeps an eye on approaches and code quality, and approves releases.
AdminDeploys Studio, connects shared runtimes, enables agents, and manages members and roles.
Agents: write the code and do the work
AGENT TEAM · shared by the team, moves issues forward
CACoordinator agentBuilt into Studio, one for the whole workspace. Assigns design, development, testing, and review, goes to the issue owner when a decision needs a person, and delivers the result for acceptance. It writes no code and merges nothing.
CXWorker agentThe Claude Code, Codex, Gemini CLI, and other coding tools the team has enabled. They carry out the design, development, testing, or review the coordinator agent assigns them.
MY AGENT · yours, to talk things through
CCMy agentYour own agent, such as Claude Code, Codex, or Cursor. In My sessions it talks the request through with you, reads code, and turns the request into issues for the agent team.
