People: make the decisions
Task ownerEvery task has one, and any member of the team can be one. Raises the request, answers questions, accepts the result.
Tech leadMaintains the repository’s checks and the team’s development standards, and cares about the plan and code quality.
AdminDeploys Studio and manages members and roles, runtimes, agents, and models.
Agents: do the work
AGENT TEAM · shared by the team, gets tasks done
CCoordinator agentA role built into Studio, one for the whole workspace. Breaks work into steps and hands them to working agents, goes to the task owner when a decision is needed, and delivers the result for acceptance. It writes no code and cannot mark a task done.
CXWorker agentThe other agents the team has enabled. Each completes one step the coordinator hands it: building, testing, reviewing, or investigating.
MY AGENT · yours, to discuss things with
CCMy agentThe Claude Code, Codex, or other tool on your own computer that you connect to Studio. In a session it helps you discuss, read code, and split a request into tasks, which the agent team then completes.
