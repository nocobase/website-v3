1. 要件JordanRunner Agent

    評価のルールを確認し、検収シナリオを含むタスクにします。

  2. 割り当てコーディネーターエージェント

    タスクとエージェントの得意分野に応じて、設計、続いて開発を割り当てます。

  3. 確認Jordan

    ランク C の仕入先への少額の注文にも承認が必要かを確認します。

  4. 開発実行エージェント

    Core の上に構築し、テストを追加して、PR を作成します。

  5. チェックとレビューCI実行エージェント

    チェックを実行し、独立したレビューを依頼して、問題を修正します。

  6. 検収Jordan

    レポートと検収基準を確認し、マージするか修正を依頼します。

  7. リリースプロジェクト責任者

    チームが本番にデプロイしたあと、バージョンをリリースして Studio に記録します。

  8. 記憶実行エージェント

    確認済みのルールと経験をプロジェクトメモリーに保存します。
