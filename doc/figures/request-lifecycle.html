1. 提出周航Runner Agent

    确认评分规则，由 Agent 整理为任务和验收场景。

  2. 分派调度 Agent

    根据任务内容和 Agent 能力，先安排方案设计，再安排开发。

  3. 回答提问周航

    确认 C 级供应商的小额订单是否需要审批。

  4. 开发执行 Agent

    基于 Core 实现业务功能，补充测试并创建 PR。

  5. 检查与评审CI执行 Agent

    运行自动化检查，由另一家厂商的模型评审，发现问题后修复。

  6. 验收周航

    依据交付报告和验收标准确认结果，决定合并或退回修改。

  7. 上线项目负责人

    发布版本，团队完成生产部署后，在 Studio 记录上线版本。

  8. 沉淀执行 Agent

    将已确认的规则与经验写入项目记忆，供后续任务复用。
