日常使用

提出需求

把一件事交给 Agent 团队：在会话里说清要什么，由 Agent 建好任务；也可以手动填写。

新建任务

在「我的任务」「开发 › 任务」或项目页点「新建任务」，也可以在列表页按 C。

Studio 会打开 Agent 面板，开始一段新会话，并带上“新建任务”的意图和当前项目：

  1. 在输入框里描述你想做的事。可以一次说好几件事，也可以贴截图。
  2. 需求清楚时，Agent 直接建好任务；不清楚的地方，它会先问你，或者先看看现有的代码再建。
  3. 建好的任务会列在会话里。点「开始执行」交给 Agent 团队；暂时不做就点「先不开始」，任务留在「待规划」。

面板右上角可以在「我的 Agent」和「Agent 团队」之间切换。连接了自己的电脑时默认用「我的 Agent」，它能直接看你电脑上的代码；没连接时由 Agent 团队回复。两者的区别见 我的会话。

手动填写

想直接填表时，在新会话里点「手动填写」：

  1. 填写标题和描述。描述支持 Markdown。
  2. 确认项目和负责人。负责人默认是你。
  3. 选择「什么时候开始」：
    • 立即开始：任务进入「进行中」，调度 Agent 马上开始安排。
    • 以后再说：任务放进「待规划」，之后在任务页点「开始」。
  4. 点「创建并开始」（或「创建」）。
待规划的任务不会自动开始

放在「待规划」里的任务，Agent 不会动。准备好后在任务页点「开始」。

怎样说清一个需求

Agent 团队会按你写的内容理解任务，说得越清楚，返工越少。建议包括：

  • 目标：要解决什么问题，给谁用。
  • 业务规则：数据怎么算、流程怎么走、谁能看到什么。
  • 验收场景：做完后你会怎样检查，例如“采购员登录后，在供应商列表里能看到每家的等级”。
  • 范围：这次不做什么。
  • 资料：相关的表格、截图、制度文件；已经在知识库里的，写明文档名称即可。

不确定的地方可以直接说“不确定，请先提出方案”。调度 Agent 会先安排一个 Agent 写出方案，需要你决定时再来问你。

子任务和依赖

  • 在任务页点「新建子任务」，同样会开始一段会话，并带上父任务。所有子任务完成后，父任务会被唤醒。
  • 在任务属性里添加「前置依赖」：依赖的任务完成之前，这个任务不会开始。
  • 优先级会影响排队：运行环境先领取紧急任务的工作。

交给人做

任务的执行者也可以是一位成员，这种任务不会触发 Agent。之后想交给 Agent，在任务页点「交给调度 Agent 开始」即可。
