NocoBase 3 文档

NocoBase 是企业用 AI 开发和持续改进业务系统的开源平台。Agent 写业务部分，NocoBase 提供底座和工作流程，人确定目标、作出决定。

NocoBase 3 由什么组成

  • Core 是开发和运行业务系统的开源底座。只用 Core，你可以让自己的 Agent 直接开发应用。
  • Studio 是人带领 Agent 团队开发应用的工作台，在商业版中提供。开发出来的应用同样建在 Core 上。

关于这份文档

  • 文档分三部分，在顶栏切换：开始（全站共用的介绍和术语）、Core、Studio。
  • 例子都来自同一个场景：一家企业的采购团队用 NocoBase 做采购应用。Core 讲这个应用怎样做出来，Studio 讲团队怎样带领 Agent 团队继续改进它。
  • 文档按中文界面编写。产品自带的界面名称写在「」里，路径写成「A › B」，例如「系统设置 › 用户管理」。
  • NocoBase 3 的各个包目前都是 beta 版本，接口和界面可能还会调整，以产品为准。
