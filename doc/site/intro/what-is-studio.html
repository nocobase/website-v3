入门

Studio 是什么

NocoBase Studio 是团队与 Agent 协同开发的治理平台，让团队专心做决策，执行交给 Agent 团队。

整理需求、提出方案、写代码、测试、评审，开发中的大部分工作已经可以交给 Agent。Agent 正在成为团队里新的执行力量。

团队管理员工，靠的是组织、制度、流程和记录。管理 Agent 也需要同样的东西，Studio 提供的就是这一套，并把需要判断的事交给人。

Studio 提供什么

组织
一支共用的 Agent 团队

成员电脑和团队服务器上的 Claude Code、Codex 等接入后，组成一支 Agent 团队。调度 Agent 按每个 Agent 擅长的事分派工作，多个任务同时推进，团队下班后也能继续。

制度
按团队的方法做事

Agent 按内置的 NocoBase 开发技能和团队的规范工作，读知识库里的业务规则；工作中学到的经验，Agent 自己记进项目记忆，下次开工前先读。

流程
每次交付走同一条路

每个任务在独立分支上开发，经过团队定义的检查和另一个模型的评审，再交给负责人验收；发布上线由人批准。

记录
每一步都有据可查

每次运行、每个决定、每次交付都留有记录：谁发起、哪个 Agent、在哪台机器上、做了什么、用了多少。

决策
判断留给人

需要判断的事，调度 Agent 会写清问题、附上依据，交给任务负责人。验收和合并由人完成。团队专心做决定，执行交给 Agent 团队。

团队里的分工

Studio 里有两类角色：人做决定，Agent 做执行。

人主要在三个时刻出现：

  1. 交代目标：说清要什么，可以是一段话、一份资料，或者一次讨论的结论。
  2. 回答提问：方案取舍、业务规则和例外情况，由人决定。
  3. 验收：看交付报告和改动，确认结果。通过就合并，不通过就退回修改。

其余时间，Agent 团队在运行环境上持续推进。「我的任务」把等你处理的事放在最前面，你不需要盯着 Agent 工作。

与 NocoBase Core 的关系

NocoBase 是用 AI 开发和运行业务系统的开源平台。Agent 写代码、做执行，NocoBase 提供底座和流程，人来做决策。

Core 是开发和运行业务系统的开源底座，Studio 带领 Agent 基于 Core 开发和改进你的应用。应用上线后独立运行，日常业务请求不经过 Studio。

适合哪些团队

  • 中大型企业的 IT 与数字化团队：业务系统多，需求不断，希望用 AI 扩展交付能力，同时满足安全、合规和长期维护的要求。懂业务、不写代码的专家，也可以主导一项需求，从提出到验收。
  • 为企业交付系统的软件公司与伙伴：用同一套底座和方法为不同客户开发，把行业经验整理成技能和知识库。

Studio 和开发用的 Agent 都部署在企业自己的环境中，模型与编码工具由企业选择。Studio 在 NocoBase 商业版（Professional 与 Enterprise）中提供。
