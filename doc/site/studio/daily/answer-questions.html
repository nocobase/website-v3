Studio · 日常使用

回答提问

任务等你做决定时怎样处理：回答提问、运行失败、运行上限、接手任务。

Agent 什么时候会找你

情况 你会看到 处理方式
需要你做一个决定 任务进入「阻塞中」，「我的任务」里标着“等你回复” 回复问题
一次运行重试后仍然失败 任务上出现运行失败的决定卡片，标着“运行失败” 重试、改派给人，或不再重试
Agent 之间触发的运行达到上限 任务页提示「继续（评论运行已达上限）」 确认后继续
有人把任务转给你负责 「我的任务」里标着“等你接手” 接手或拒绝
有人请求在你的个人运行环境上继续 任务页上的请求 确认或拒绝

这些事都在任务页上处理，并汇总在「我的任务」的“等你处理”里。

回答阻塞中的提问

调度 Agent 遇到需要人判断的事，例如方案取舍、业务规则、例外情况，会把任务转为「阻塞中」，并在任务页顶部的“需要你”卡片里写清要你决定或提供什么。

  1. 打开任务，读“需要你”卡片。需要背景时，点「查看调度 Agent 最新说明」，看它的完整说明。
  2. 点「回复」。回复框会打开在调度 Agent 那条说明的下面。
  3. 写下你的决定，点发送。

调度 Agent 收到回复后会被唤醒，根据你的回答继续安排。

怎样回答更快推进

直接给结论，再补一句理由，例如“新供应商先按 B 级，满三个月后重新评分。因为没有历史数据，不宜直接定为 A 级。”拿不准的，可以让它先列出几种方案和各自的影响。

运行失败

Agent 的运行可能因为运行环境离线、编码工具额度用完、网络问题等失败。可以重试的失败会自动重试；重试次数用完后，负责人会收到一张决定卡片：

  • 重试：让 Agent 重新尝试。适合临时性的问题，例如运行环境刚恢复在线。
  • 改派给人：把执行者改成一位成员，由人来做。
  • 不再重试：放弃这次运行。

运行记录里可以看到失败的原因。调度 Agent 也可能自己把失败的步骤换给另一个合适的 Agent；同一步失败两次后，它会把任务转为「阻塞中」来问你。

评论运行达到上限

为防止 Agent 之间来回触发，每个任务每 24 小时内由 Agent 评论触发的运行有上限（默认 20 次，管理员可以调整）。达到上限后，Agent 的评论不再启动新的运行，负责人会收到通知。

确认任务确实需要继续后，在任务页点「继续（评论运行已达上限）」。你自己发一条会唤醒 Agent 的评论，也会重新开始计数。

达到上限往往是个信号

先看看动态和运行记录：Agent 是不是在反复修同一个问题？如果是，补充说明或调整任务，比直接继续更有效。

接手转给你的任务

有人把任务的负责人转给你后，任务会出现在“等你接手”。在你接手之前，Agent 的工作会暂停，任务上等负责人决定的事也要等你接手后才能处理。

  • 打开任务，点「接手任务」，你就成为负责人，可以继续回答提问、验收。
  • 也可以拒绝。拒绝后任务回到原负责人手里；原负责人的账号已停用时，任务由你保留并保持暂停。

个人运行环境的请求

个人运行环境只运行主人自己发起的工作。别人在你负责的任务上发评论，而接下来的工作要用到你的个人运行环境时，任务页会出现“某某请求在你的个人执行机上继续”，你可以「确认」或「拒绝」。确认后，这次工作才会在你的个人运行环境上运行。
