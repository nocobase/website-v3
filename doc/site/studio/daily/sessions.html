Studio · 日常使用

我的会话

按会话跟进工作。和 Agent 讨论想法、查看代码、拆成任务，这段会话会一直挂着它创建的任务和进展。

「我的任务」按任务跟进，「我的会话」按会话跟进。一段会话从讨论开始：你和 Agent 聊清楚一件事，让它拆成任务交给 Agent 团队；之后这段会话里一直挂着这些任务和它们的进度，你回到会话就能接着问“现在怎么样了”。

列表里的每段会话写明属于哪个项目、有几个任务。进度条一段代表一个任务：绿色已完成、紫色待验收、蓝色进行中、琥珀色阻塞中、灰色待规划。有任务等你处理时，右侧会显示“等你 1”。

我的 Agent 和 Agent 团队

会话有两种模式，在 Agent 面板右上角切换。两者的区别在于由谁驱动 Agent：

我的 Agent Agent 团队
是谁 你连接到 Studio 的 Claude Code、Codex 等 团队在「Agent 团队」里启用的 Agent
怎样运行 你选好电脑和目录，直接和它对话；它用那台电脑上的代码、工具和配置 由运行环境领取执行，运行环境可能是团队服务器，也可能是你自己的个人运行环境
需要准备 连接你的电脑（一次） 不需要
适合 结合本地代码讨论、拆分任务 没连接电脑时提问、查资料、拆分任务

两种模式的会话都列在「我的会话」里，只有你自己能看到。会话里的 Agent 以你的身份和权限在 Studio 里工作：建任务、发评论、改状态，做不了你做不了的事。

同一台电脑，两种用途

你的电脑可以作为个人运行环境加入 Agent 团队，替你执行任务；同时也可以连接为「我的 Agent」，让你在会话里直接和它对话。两者分别设置，互不影响。

连接你的电脑

使用「我的 Agent」之前，先把电脑连接到 Studio：

  1. 打开「我的会话」，点「连接你的电脑」。
  2. 复制页面上的配置指令，交给这台电脑上的编码工具（如 Claude Code、Codex）执行。它会安装 nb-studio 命令行、请你在浏览器里确认登录，并运行 nb-studio acp service install，让电脑开机后自动保持连接。
  3. 回到 Studio，确认这台电脑显示在线。
  • 支持 Codex、Claude Code、Gemini CLI、GitHub Copilot、Cursor、OpenCode 等编码工具；电脑可以是 macOS、Linux 或 Windows。
  • 默认允许 Agent 访问整个用户目录，可以在「我的电脑」里改成指定的目录。Agent 在这些目录里的权限，和你在自己终端里使用它时一样。
  • 配置指令里的安装链接 30 分钟内有效，过期后重新生成即可。

开始一段会话

  1. 在「我的会话」点「新会话」，或在任何页面按 ⌘ J（Windows 和 Linux 上是 Ctrl J）。
  2. 选择模式。「我的 Agent」需要选择电脑、这台电脑上的 Agent、工作的目录；「Agent 团队」选择团队里的一个 Agent。两种模式都可以指定会话所属的项目。
  3. 说说要做什么。可以一次说好几件事，也可以贴截图。

建议选你能用的最强模型，分析和拆解任务会更准确。

在任务页、项目页点「问 Agent」，会带上当前页面作为上下文开始会话。

把讨论变成任务

聊清楚之后，让 Agent 把讨论整理成任务，例如“把这三件事建成任务，放进供应商管理项目”。

  • 会话创建的任务挂在这段会话上，会话里显示它们的最新状态和进度条，等你处理的会标出来。
  • 点「开始执行」把任务交给 Agent 团队；「先不开始」则留在待规划。
  • 在输入框里用 # 可以提到已有任务，让 Agent 读它、在上面评论，或按你的要求修改。
  • 从任务页也能回到当初创建它的会话。

跟进会话

  • 会话列表可以按「等你确认」「进行中」筛选。Agent 请求权限、或者等你确认时，会话会标出来，并计入顶栏的提醒。
  • 在「Agent 团队」模式的会话里交出的任务，关键进展（运行结束、阻塞、待验收、失败、关闭、开出 PR）会以卡片的形式回到会话中，Agent 会总结并建议下一步。
  • 不再需要的会话可以归档，之后随时恢复。
