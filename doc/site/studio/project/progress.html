Studio · 管理项目

项目进展

每个项目的进度，以及完成的任务、周期时间、Agent 完成占比和单任务成本，都和上一周期对比。

仪表盘

「仪表盘」回答三个问题：交付进展如何、Agent 表现怎样、哪些工作卡住了。可以选择时间范围，每个数字都和上一周期对比。

  • 关键数字：完成任务、周期时间中位数、Agent 完成占比、单任务成本、运行成功率、返工率、人工介入率、排队等待中位数等。把鼠标移到数字上可以看到计算方式。
  • Agent 表现：每个 Agent 在本周期的工作情况。
  • 需要关注：当前卡住或逾期的事项。
  • 按项目：每个项目的进度和本周期的交付。

仪表盘只统计你有权限看到的项目和任务。

计划包含

  • 仪表盘的关键数字和计算方式
  • Agent 表现
  • 需要关注：卡住或逾期的事项
  • 按项目看进度和交付；合并了但还没上线的任务
  • 项目概览里的「已合并未发布」
