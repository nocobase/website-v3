Studio · 管理项目

Agent 工作负荷与模型用量

每个 Agent 在推进哪些任务、在等什么；各个模型用了多少、花了多少，都清晰可见。

Agent 队列

在「开发 › 任务」右上角切换到「Agent 队列」，可以看到整个 Agent 团队在做什么。每个 Agent 一条泳道：

区域 内容
正在执行 运行环境上正在跑的工作，已经跑了多久、最近在做什么。
接下来 排队中的任务和等待原因，例如“没有在线的运行环境”“并发已满”“被 PUR-12 阻塞”。
等待回复 在等人的事：失败的运行、提问、待验收，以及在等谁；轮到你的会高亮，点「去处理」直达。
已分配·空闲 分配给它、但现在没有动静的任务，写明原因，例如“在待规划中，不会自动开始”。

顶部一行汇总运行中、排队中、等你处理的数量，以及运行环境的忙碌情况。勾选「只看与我相关」，只显示你负责、创建或关注的任务。

计划包含

  • 「Agent 管理 › 用量」：每次运行的用量和费用
  • 设置模型价格：价格规则与订阅计费
  • 仪表盘里的单任务成本
  • Agent 队列：每个 Agent 一条泳道
  • 正在执行、接下来、等待回复、已分配·空闲
  • 只看与我相关
  • 排队的原因：没有在线的运行环境、并发已满、被其他任务阻塞
