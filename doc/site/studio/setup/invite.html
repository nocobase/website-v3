Studio · 搭建 Studio

邀请成员

第一个需求走通后，邀请同事加入 Studio，分配角色和项目。

第一个需求走通，说明 Studio、运行环境、Agent 和代码仓库都配好了，可以邀请同事加入。

邀请

  1. 打开「设置 › 成员」，点「邀请成员」。
  2. 填写同事的邮箱，每行一个，或者用逗号、空格分隔，一次最多 50 个。
  3. 「加入的项目」选上他们要参与的项目，被邀请人以成员身份加入这些项目。
  4. 点「发送邀请」。

每个邮箱会收到一封邀请邮件，打开链接、设置姓名和密码就加入了。链接 7 天内有效。

Studio 还没有配置邮件时，结果里会显示「邮件未发送」。点「复制邀请链接」，自己把链接发给同事即可。

角色

新成员加入时，自动获得「设置 › 常规」里设定的默认角色。Studio 内置三个角色：

角色 能做什么
成员 提出需求、跟进和验收自己相关的任务；在自己负责的项目里管理设置和知识库；接入个人运行环境
管理员 所有页面和所有设置：接入共享运行环境、启用 Agent、管理部署环境、Git 连接、组织的 API 密钥
所有者 和管理员一样，另外可以管理账号：修改资料、停用账号、重置密码

需要时，在「设置 › 成员」里调整某个人的角色，或者在「设置 › 角色」里定义新的角色，见 成员与角色。

同事加入之后

请同事按 加入团队 做一遍：连接自己的 Git 账号，把自己的电脑接入 Studio，然后就可以 提出需求 了。

完成的标志同事出现在「设置 › 成员」的列表里，状态是正常。
