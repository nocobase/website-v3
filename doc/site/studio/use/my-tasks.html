Studio · 日常使用

我的任务

每天从「我的任务」开始。各个项目里与你有关的任务汇成一张列表，等你处理的排在最前面。想按会话跟进，见「我的会话」。

哪些任务会出现在这里

「我的任务」列出你负责的任务和你自己执行的任务，每个任务只出现一次。你关注的任务也会出现在这里，不论负责人是谁。

侧边栏「我的任务」旁边的数字，是现在等你处理的事项数。

按“轮到谁”分组

从上到下依次是：

分组 里面是什么
关注 你关注的任务，排在最前面，并显示别人新增了多少条动态。
等你处理 现在需要你做决定的任务，等得最久的在前。
进行中 Agent 或其他人正在推进的任务。
等别人 待验收或阻塞中、但在等别人的任务，每行写明在等谁，例如“等李娜验收”。
待规划 还没开始的任务。
已完成 最近七天完成的任务，默认折叠。

已取消的任务不显示，需要时用状态筛选找出来。

什么情况算“等你处理”

标记 什么时候出现 去哪里处理
等你验收 你负责的任务进入待验收 验收
等你回复 你负责的任务因为一个问题进入阻塞中 回答提问
运行失败 Agent 的一次运行重试后仍然失败，等你决定怎么办 回答提问
等你确认方案 有一份关于这个任务的计划草稿等你确认 任务页
等你接手 有人把任务的负责人转给了你 回答提问

每一行都写明要你做什么。处理完一个任务后，它会在原位置停留，直到你切换到别的任务；页面底部会出现提示，可以撤销刚才的状态修改，或者直接跳到下一个等你处理的任务。

视图

右上角可以切换四种视图：

  • 分栏：左边列表，右边详情。「我的任务」默认用它，适合逐个处理。
  • 表格：按任务树展开，适合看子任务。
  • 看板：每个状态一列，拖动卡片即可改状态。
  • Agent 队列：每个 Agent 一条泳道，看它正在做什么、接下来做什么、在等谁。见 Agent 工作负荷与模型用量。

你上次选的视图会被记住。

快捷键

在列表里（不在输入框中时）：

按键 作用
J / K 或方向键 下一个 / 上一个任务
S 关注或取消关注
Enter 打开任务页
/ 搜索
Esc 回到列表

关注任务

点任务右上角的星标即可关注。关注的任务排在列表最前面，别人新增评论或改动时会显示条数。不是你负责的任务，也可以关注后在这里跟进。最多可以同时关注 100 个任务。

每天怎么用

  1. 打开「我的任务」，先处理“等你处理”分组：验收、回答问题、处理失败的运行。
  2. 看一眼“关注”分组里的新动态。
  3. 有新想法时，提出需求，交给 Agent 团队。

其余的事，Agent 团队会在运行环境上继续推进；需要你时，任务会回到“等你处理”。
