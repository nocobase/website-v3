## 收件箱和「我的任务」的分工

| | 放什么 |
| --- | --- |
| 「我的任务」 | 任务上等你做的决定：验收、回答提问、运行失败、接手任务。见 [我的任务](my-tasks.md)。 |
| 收件箱 | 同事的评论、@ 提及和指派；任务之外的系统事项，例如知识库的修改提议、运行环境需要升级的通知。 |

顶栏的收件箱图标打开收件箱。

## 收件箱的视图

| 视图 | 内容 |
| --- | --- |
| 全部 | 所有消息。 |
| 待我决定 | 需要你做决定的非任务事项，例如是否采纳一条知识库修改提议。 |
| 通知 | 只需要知道的消息。 |

在列表里可以用 <kbd>J</kbd> / <kbd>K</kbd> 上下切换。处理完的事项会自动结束；已读和删除只影响你自己的收件箱。

## 提醒

有新的事项等你时：

- 侧边栏「我的任务」「我的会话」旁边、顶栏和浏览器标签页的标题上会显示数量；
- 如果打开了提示音，会响一声。你正在看的那个任务或会话不会再提醒。

在「账号设置 › 偏好设置」里可以调整：

- **提示音**：开或关。
- **桌面通知**：默认关闭。开启后浏览器会请求通知权限；被浏览器拦截时，到浏览器的网站设置里允许通知。
- **推送通知**：让手机或另一台电脑在 Studio 页面没打开时也能收到提醒。每个浏览器需要单独订阅。

> [!NOTE] 在手机上订阅推送
> Android 上用 Chrome 打开 Studio 后直接订阅。iPhone 和 iPad 需要 iOS 16.4 或更高版本：先在 Safari 里用「分享 › 添加到主屏幕」，再从主屏幕的图标打开 Studio 订阅。推送需要 Studio 通过 HTTPS 访问，并由管理员完成推送配置。

## 订阅一个任务

任务页的「更多属性」里有「订阅通知」，列出会收到这个任务通知的人。点「订阅」或「取消订阅」，调整自己是否接收。

想把一个任务放在眼前，用关注星标：关注的任务排在「我的任务」最前面。
