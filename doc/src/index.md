- **[Core](core/index.md)** is the open-source foundation for building and running business systems. With Core alone, you can have your own agent build apps directly.
- **[Studio](studio/index.md)** is the workspace where people lead an agent team to build apps, available in the commercial editions. The apps it builds are also built on Core.

## About this documentation

- The documentation has three parts, which you switch between in the top bar: **Start** (introductions and terms shared by the whole site), **Core**, and **Studio**.
- Core uses a team task app to explain development, testing, and deployment. Studio uses a purchasing team scenario to explain how people lead an agent team.
- The documentation is written against the English interface. Interface names that ship with the product are shown in **bold**, and paths are written as **A › B**, for example **System settings › User management**.
- Every NocoBase 3 package is currently in beta, so APIs and interfaces may still change. The product is the source of truth.
- Pages shown in a lighter color in the left menu are not written yet.
