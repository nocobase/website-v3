---

管理员工靠组织、制度、流程和记录，管理 Agent 也一样。Studio 把团队的 Agent 组织成一支 Agent 团队，让它们按团队的方法和流程做事，记下每一次运行和决定，把需要判断的事交给对应的人。

文档按 Studio 的中文界面编写。界面名称写在「」里，路径写成「A › B」，例如「Agent 团队 › 运行环境」。文中的界面配图只画出正在讲的那一部分，实际界面以产品为准。
