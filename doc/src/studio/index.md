Agents do the work, and people make the call. You set the goal and accept the result, while an agent team breaks the work into steps, writes the code, tests it, and reviews it. Each person can lead an agent team and move more tasks and projects forward at once.

## About this documentation

The documentation uses the names in Studio's English interface. Interface names are written in **bold**, and paths are written as **A › B**, for example **Agent team › Runtimes**. The screenshots show only the part of the interface being discussed, and the product itself is the reference for what you see on screen.
