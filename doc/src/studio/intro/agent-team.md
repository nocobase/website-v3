## 计划包含

- Agent 团队里有谁：调度 Agent、执行 Agent，以及你自己的 Agent
- 调度 Agent 做什么、不做什么：不写代码、不合并代码，验收由人来做
- 用哪个 Agent 跑：首选、备选和等待时间
- 内置的分配原则，以及怎样修改和恢复
- 运行上限：每个任务 24 小时内由 Agent 评论触发的运行次数
- 交给调度 Agent 开始
- 每个任务有自己的分支和固定的工作目录；评审和调查用只读副本，与开发同时进行
- 最大并发数与排队；紧急任务先领取
- 前置依赖与子任务：依赖完成后自动唤醒
- 运行环境离线后，工作回到队列由其他机器接手；排队超过 24 小时的运行会失败
- 检查失败时怎样修复；评审交给另一家厂商的模型
