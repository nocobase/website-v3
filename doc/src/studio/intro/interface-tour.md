## 侧边栏

登录后，左侧是 Studio 的导航。最上面三项是每个人每天都会用的；下面按“开发”“Agent 团队”等分组。

::figure tour | Studio 的侧边栏；灰色的「质量」「发布」两组还在开发中

## 每个人常用的

| 位置 | 用来做什么 | 详见 |
| --- | --- | --- |
| 「我的任务」 | 按任务跟进，等你处理的排在最前面 | [我的任务](../daily/my-tasks.md) |
| 「我的会话」 | 按会话跟进，和我的 Agent 或 Agent 团队讨论、创建任务 | [我的会话](../daily/sessions.md) |
| 「仪表盘」 | 交付进展、Agent 表现、卡住的事项 | [跟进进展](../daily/follow-progress.md#仪表盘) |
| 「开发 › 任务」 | 团队的全部任务；可以切换到「Agent 队列」看 Agent 在做什么 | [跟进进展](../daily/follow-progress.md#agent-队列) |
| 「开发 › 知识库」 | 查阅和维护业务资料 | [知识库、项目记忆与技能](../daily/knowledge.md) |
| 顶栏的收件箱 | 同事的消息和任务之外的事项 | [收件箱与提醒](../daily/inbox.md) |

## 管理员和技术负责人常用的

| 位置 | 用来做什么 |
| --- | --- |
| 「开发 › 项目」 | 创建项目，设置代码仓库 |
| 「Agent 团队 › Agent」 | 启用 Agent、写明擅长什么；设置调度 Agent |
| 「Agent 团队 › 运行环境」 | 添加和管理团队服务器、成员电脑 |
| 「Agent 团队 › 技能」 | 查看内置的开发技能，按需补充团队的约定 |
| 「Agent 团队 › 用量」 | 查看每次运行的用量和费用，设置模型价格 |
| 「设置」 | 成员与角色、Git 连接、API 密钥、标签 |

## 随处可用的

- **新建任务**：在任务列表、项目页点「新建任务」，或按 <kbd>C</kbd>。见 [提出需求](../daily/raise-a-request.md)。
- **问 Agent**：在任务页、项目页打开 Agent 面板，自动带上当前页面作为上下文。任何页面都可以按 <kbd>⌘</kbd> <kbd>J</kbd>（Windows 和 Linux 上是 <kbd>Ctrl</kbd> <kbd>J</kbd>）打开面板。
