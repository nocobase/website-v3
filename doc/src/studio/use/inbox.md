## 收件箱和「我的任务」的分工

| | 放什么 |
| --- | --- |
| 「我的任务」 | 任务上等你做的决定：验收、回答提问、处理失败的运行、接手转给你的任务。这些都在任务页上处理，见 [我的任务](my-tasks.md) |
| 收件箱 | 同事的评论、@ 提及和指派；任务之外的事项，例如部署申请等你审批、部署的结果和失败、知识库的修改提议、运行环境的通知 |

顶栏的收件箱图标打开收件箱。

## 收件箱的视图

| 视图 | 内容 |
| --- | --- |
| 全部 | 所有消息 |
| 待我决定 | 需要你做决定的事项，例如批准一次部署、是否采纳一条知识库修改提议 |
| 通知 | 只需要知道的消息 |

在列表里可以用 <kbd>J</kbd> / <kbd>K</kbd> 上下切换。处理完的事项会自动结束；标为已读和删除只影响你自己的收件箱。

## 提醒

有新的事等你时：

- 侧边栏「我的任务」「我的会话」旁边、顶栏和浏览器标签页的标题上会显示数量；
- 打开了提示音时，会响一声。你正在看的那个任务或会话，不会再提醒。

在右上角账户菜单的「个人设置 › 偏好设置」里，「提醒」一栏可以调整：

- **提示音**：开或关。
- **桌面通知**：默认关闭。开启后浏览器会请求通知权限；被浏览器拦截时，到浏览器的网站设置里允许通知。
- **推送通知**：Studio 的页面没有打开时，手机或另一台电脑也能收到提醒。每台设备单独订阅，点「订阅此设备」。

> [!NOTE] 在手机上订阅推送
> Android 上用 Chrome 打开 Studio 后直接订阅。iPhone 和 iPad 需要 iOS 或 iPadOS 16.4 及以上：先在 Safari 的分享菜单里选「添加到主屏幕」，再从主屏幕打开 Studio 订阅。推送需要 Studio 通过 HTTPS 访问，并由管理员配置好推送。

## 订阅一个任务

任务页的「更多属性」里有「订阅通知」，列出会收到这个任务通知的人。点「订阅」或「取消订阅」，调整自己是否接收。

想把一个任务放在眼前，用关注星标：关注的任务排在「我的任务」最前面。
