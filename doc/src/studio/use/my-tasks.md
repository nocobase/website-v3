You don't have to go project by project, or terminal by terminal, to find out how things are going. The issues that concern you in every project come together in **My issues**. When an agent needs you to answer a question, accept a result, or deal with a failed run, the issue moves to the top. To follow work session by session instead, see [My sessions](sessions.md).

## Which issues show up here

**My issues** lists the issues you own and the ones you're working on yourself, each only once. Issues you follow show up here too, whoever owns them.

The number next to **My issues** in the sidebar is how many things are waiting for you right now, including confirmations waiting in your sessions and decisions outside issues.

::figure my-tasks-list | My issues is grouped by whose turn it is, and each row says what you need to do

## Grouped by whose turn it is

From top to bottom:

| Group | What's in it |
| --- | --- |
| Following | Issues you follow, at the very top, with the number of new updates from others. |
| Waiting for you | Issues that need your decision now, with the ones waiting longest first. |
| In progress | Issues that agents or other people are moving forward. |
| Waiting for others | Issues in review or blocked, but waiting on someone else. Each row says who, for example "Waiting for Li Na to accept". |
| Backlog | Issues that haven't started. |
| Done | Issues finished in the last seven days, collapsed by default. |

Cancelled issues aren't shown. Use the status filter to find them when you need to.

## What counts as waiting for you

| Label | When it appears | Where to handle it |
| --- | --- | --- |
| Needs your acceptance | An issue you own moves to In review | [Accept the result](accept.md) |
| Needs your reply | An issue you own is blocked on a question | [Answer the agents’ questions](answer.md#answer-a-question-on-a-blocked-issue) |
| Run failed | An agent's run still failed after retrying and is waiting for you to decide what to do | [Answer the agents’ questions](answer.md#failed-runs) |
| Needs plan approval | A draft plan for this issue is waiting for your approval | The issue page |
| Needs you to take over | Someone handed ownership of the issue to you | [Answer the agents’ questions](answer.md#take-over-an-issue-handed-to-you) |

Each row says what you need to do. Once you've handled an issue, it stays where it is until you move on to another one. A message at the bottom of the page lets you **Undo** the change or jump straight to the next issue waiting for you.

## Views

Switch between four views at the top right:

- **Split**: the list on the left and details on the right. **My issues** uses it by default, and it suits working through issues one by one.
- **Table**: expands the issue tree, good for looking at sub-issues.
- **Board**: one column per status. Drag a card to change its status.
- **Agent queue**: one lane per agent, showing what it's doing, what comes next, and who it's waiting for. See [Agent workload and model usage](../project/usage.md).

Studio remembers the view you used last.

## Keyboard shortcuts

In the list, when you're not typing in a field:

| Key | Action |
| --- | --- |
| <kbd>J</kbd> / <kbd>K</kbd> or the arrow keys | Next / previous issue |
| <kbd>S</kbd> | Follow or unfollow |
| <kbd>Enter</kbd> | Open the issue page |
| <kbd>/</kbd> | Search |
| <kbd>Esc</kbd> | Back to the list |

## Follow issues

Click the star at the top right of an issue to follow it. Followed issues stay at the top of the list and show how many comments or changes others have added. You can follow issues you don't own to keep track of them here. You can follow up to 100 issues at a time.

## A typical day

1. Open **My issues** and start with **Waiting for you**: accept results, answer questions, and deal with failed runs.
2. Glance at the new updates under **Following**.
3. When you have a new request, [make a request](raise-a-request.md) and hand it to the agent team.

The agent team keeps everything else moving on the runtimes. When it needs you, the issue comes back to **Waiting for you**.
