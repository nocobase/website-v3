## 计划包含

- 四层分工：权限声明由 Agent 写，角色分配和范围调整由管理员在「系统设置」里做
- 权限模型：页面、操作、数据范围
- 「系统设置 › 权限管理」：角色与权限、默认数据范围
- 共享规则和限制规则
- 检查权限结果：为什么某人能看到某条记录
- 业务 Agent 和人用同一套权限
- 验收：普通用户、直接访问地址、直接调用接口
