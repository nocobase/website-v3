Agent 完成执行，人只拍板：你交代目标、验收结果，而拆分步骤、写代码、测试和评审都由 Agent 团队完成。每个人都能带领一支 Agent 团队，同时推进更多任务和项目。

## 关于这份文档

文档按 Studio 的中文界面编写。界面名称写在「」里，路径写成「A › B」，例如「Agent 团队 › 运行环境」。文中的界面配图只画出正在讲的那一部分，实际界面以产品为准。
