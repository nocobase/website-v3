---
title: 接入个人运行环境
description: 把自己的一台机器接入 Studio，成为个人运行环境。它用你自己登录的编码工具和订阅，只执行代表你的工作。
---

共享运行环境由管理员接入，执行团队里所有人的工作。个人运行环境由成员自己接入，只执行代表你的工作：你负责的任务里调度 Agent 安排的每一步，以及你在「我的会话」里和团队 Agent 的对话。

接入个人运行环境，常见的原因有：

- 共享运行环境忙不过来，想让自己的任务推进得快一些。
- 你登录了团队还没有的编码工具或模型，想先用在自己的任务上。
- 想用自己的订阅和额度来跑自己的任务。

在「我的会话」里和你自己的 Agent 对话，是另一种连接，见 [连接自己的电脑](connect-computer.md)。

## 准备

准备的东西和共享运行环境一样：macOS 或 Linux，Windows 要在 WSL 的 Ubuntu 里运行；Node.js 24 或更高版本和 Git，装好并登录要用的编码工具，以及代码托管平台的命令行和 Chromium。逐项说明见 [接入共享运行环境](../setup/shared-runtimes.md#准备一台机器)。

> [!WARNING] 执行机不是安全边界
> Agent 在这台机器上以运行执行机的系统用户的身份工作，能读写这个用户能访问的一切，包括 SSH 密钥和其他凭证。个人运行环境也请用专用的系统用户、容器或虚拟机，不要直接用你日常工作的账户。

## 添加

1. 打开「Agent 管理 › 运行环境」，点「添加运行环境」。对话框里写明，这个运行环境是个人的。
2. 勾选这台机器上要用的编码工具，按机器的资源和你的额度设置最大并发数。
3. 点「生成安装命令」，选择这台机器的系统。
4. 把「提示词」交给这台机器上的编码工具，由它完成安装；也可以切到「手动安装」，自己运行命令。

命令里带有一次性凭证，只能用一次，几分钟内有效，过期了就重新生成。安装的细节和常见问题，与 [接入共享运行环境](../setup/shared-runtimes.md#在机器上安装) 相同。

## 确认接入成功

几秒钟后，它出现在运行环境列表里：「共享」一栏是「个人」，状态是「在线」，勾选的编码工具显示「已登录」。打开详情，能看到所有者是你。

这台机器上报的模型，如果团队已经启用了对应的 Agent，「Agent 管理 › Agent」的「在哪跑」一栏会把你的这一台算进去，例如「共享 1 · 个人 1」。

**完成的标志**：运行环境显示「个人」和「在线」，要用的编码工具显示「已登录」。

## 哪些工作会派到这里

- **你负责的任务**：调度 Agent 安排的设计、开发、测试和评审都代表任务负责人，可以派到你的个人运行环境。
- **你的会话**：你在「我的会话」里和团队 Agent 的对话。
- **只在个人运行环境上有的 Agent**：例如某个模型只在你的机器上登录了。调度 Agent 只会在你负责的任务里用它。别人的任务要等这样的 Agent 时，任务页的「现在」一行会写明，只有别人的个人运行环境在线。
- **带密钥的工作**：项目里勾选了「仅限共享运行环境」的变量，不会发到个人运行环境，用到它们的工作只由共享运行环境执行。其他变量会随工作发到接活的运行环境，见 [项目设置](../project/settings.md#agent-运行变量)。

别人在你负责的任务上发评论，接下来的工作要用到你的个人运行环境时，Studio 会先请你确认。任务页上会出现“某某请求在你的个人执行机上继续”：点「确认」，工作在你的运行环境上继续；点「拒绝」，就不执行。见 [回答 Agent 的提问](../use/answer.md#个人运行环境的请求)。

## 管理

- **修改**：在运行环境详情里修改名称和最大并发数，打开或关闭编码工具，给某个工具设置同时运行的上限。只有所有者能修改。
- **暂停**：在那台机器上运行 `nocobase-runner stop`，要恢复时运行 `nocobase-runner start`。执行机 150 秒没有联系 Studio 就显示离线，它手上的工作回到队列。
- **本机提供的变量**：只想留在这台机器上的值，用 `nocobase-runner env set NAME` 设置，Studio 里只显示名字。
- **共享给团队**：要让它执行所有人的工作，请管理员在详情里把使用范围改成「共享」。共享后，别人的工作也会在这台机器上执行，带上他们的变量和密钥，也能读到机器上的内容，确认没有问题再共享。
- **不再使用**：先在详情里吊销它的凭证，再删除，历史运行记录会保留。在那台机器上运行 `nocobase-runner uninstall`，移除执行机和它的后台服务。
