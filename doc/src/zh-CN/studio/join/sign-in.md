## 接受邀请

管理员邀请你之后，你会收到一封邀请邮件。Studio 还没有配置邮件时，管理员会直接把邀请链接发给你。链接 7 天内有效。

1. 打开邀请链接。页面上写着谁邀请了你，邮箱已经填好。
2. 填写姓名和密码，密码至少 8 个字符。
3. 点「创建账号并加入」。

加入后直接进入「我的任务」。管理员邀请时选了项目的，你已经是这些项目的成员。

- 这个邮箱已经有账号时，点「去登录」，用原来的账号登录后继续。
- 浏览器里已经登录了别的账号时，先退出，再接受邀请。
- 链接过期或被撤销时，页面上会写明，请邀请你的人重新发送。

## 登录

Studio 的地址由管理员告诉你，形如 `https://studio.example.com/main/`。在登录页用用户名或邮箱和密码登录。

登录页上有「忘记密码？」时，输入邮箱，按收到的链接设置新密码。没有这个入口，说明 Studio 还没有配置邮件，请所有者在「设置 › 成员」里为你重置密码。

## 个人设置

点右上角的头像，打开账户菜单：

- **个人设置**：资料、密码、偏好、API 密钥和 Git 账号。
- **在 agent 中使用 Studio**：把配置指令交给你的 Agent，让它通过命令行操作 Studio，见 [在本地 Coding Agent 里使用 Studio](local-agent.md)。
- **语言**、**主题**：直接切换界面语言和颜色模式。
- **退出登录**。

「个人设置」里有五页：

| 页面 | 能做什么 |
| --- | --- |
| 个人资料 | 修改显示名称和用户名。显示名称展示在任务和评论里。邮箱只能查看，要改请联系所有者 |
| 账号与安全 | 修改密码。保存后，其他设备上的登录会退出 |
| 偏好设置 | 界面语言、颜色模式和密度；提示音和桌面通知；为这台设备订阅推送；你的 Agent 提交代码时怎样署名 |
| API 密钥 | 创建自己的密钥，让脚本、CI 以你的身份调用 Studio，见 [API 密钥](../admin/api-keys.md) |
| Git | 连接你自己的代码托管平台账号，见下一节 |

偏好设置随账号保存，换一个浏览器也一样。推送按设备订阅，需要 Studio 通过 HTTPS 访问；iPhone 要先把 Studio 添加到主屏幕，再从主屏幕打开订阅，见 [通知与推送](../admin/notifications.md)。

提交署名默认跟随项目的设置。你的 Agent 总是以你的身份提交，你可以选择是否同时把 Agent 署名为共同作者。

## 连接自己的 Git 账号

打开「个人设置 › Git」，点「连接 GitHub」，GitLab、Gitee 同理。在代码托管平台上登录、确认授权后，回到 Studio 就显示已连接。

连接后，你的 Agent 推送代码、开 PR，你在 Studio 里合并，都以你自己的身份进行，代码托管平台上能看出是谁的工作。没有连接时，使用工作区的 Git 连接，例如以团队安装的 GitHub App 的身份推送和开 PR。建议团队里每位成员都连接自己的账号。

在浏览器里授权不方便时，点「其他方式」：

- **用验证码连接**：打开代码托管平台的页面，登录后输入 Studio 给出的验证码。
- **使用个人令牌**：粘贴你在代码托管平台上创建的令牌。Studio 先验证，再加密保存，之后不再显示。

哪些方式可用，由管理员在「设置 › 集成 › Git」里决定。页面显示「暂时无法连接个人账号」时，请管理员开放个人账号连接。令牌过期后，Studio 改回用工作区的连接，重新连接即可。
