## 任务页

不论从列表、看板还是链接打开，任务页都是同一个样子。

::figure req-now | 任务页的摘要：「现在」「接下来」、属性和关联的 PR

**顶部一行**：任务在列表里的位置、编号（点击复制链接）、所属项目；右边是状态、关注星标、「问 Agent」和更多操作。

**摘要**：

- **现在**：系统根据实际情况写出任务正在等什么，例如“Codex · GPT-5.5 正在工作，已 8 分钟，在 Server 02 上”“等待运行环境领取”“等 PR 的检查结果”“等周航验收”。这一行由系统生成，不来自任何人写的文字。
- **接下来**：调度 Agent 写下的下一步计划。
- **需要你**：任务在阻塞中或待验收、等你决定时出现，写明要你做什么，旁边就是处理按钮。见 [回答提问](../decisions/answer.md) 和 [验收](../decisions/accept.md)。
- **交付报告**：调度 Agent 交付验收时提交，之后一直保留，直到下一次交付替换它。

**属性**：优先级、负责人、执行者，以及「更多属性」里的标签、项目、开始和截止日期、订阅通知等。

**页签**：

| 页签 | 内容 |
| --- | --- |
| 动态 | 评论、交接、状态变化。默认「只看对话」，切到「全部」可以看到系统记录。 |
| 说明 | 任务描述。 |
| 子任务 | 子任务及其状态。 |
| 代码与部署 | 关联的 PR、检查结果和改动。 |
| 运行记录 | Agent 在这个任务上的每一次运行。 |

## 用评论和 Agent 沟通

在任务底部的输入框写评论。评论有两种：

- **评论**：所有人都能看到。它会唤醒你 @ 到的 Agent、你回复的那条评论的 Agent，以及任务的执行者（通常是调度 Agent）。有 Agent 正在运行时，评论会直接送到它那里。
- **备注**：只是给人看的记录，不会唤醒任何 Agent。

::figure composer | 评论会唤醒 Agent，备注只给人看

几个常见用法：

- 补充或修改要求：直接写评论，调度 Agent 会据此调整安排。
- 问某个 Agent 一个具体问题：在评论里 @ 它。它只回答你问的事，不会改任务状态。
- 回复某条评论：在那条评论下回复，讨论会留在同一个线程里。

## 问 Agent

任务页右上角的「问 Agent」会打开 Agent 面板，开始一段带着这个任务的会话。适合问“这个任务卡在哪”“这个 PR 改了哪些地方”这类问题。会话里的 Agent 以你的身份和权限工作，只做你让它做的事。见 [我的会话](../team/sessions.md)。

## 运行记录

「运行记录」页签列出这个任务上的每一次运行：哪个 Agent、在哪台运行环境上、第几次尝试、结果和用量。

::figure runs | 运行记录：可以查看过程和提示词，也可以停止正在进行的运行

- 「查看执行过程」：Agent 这次运行的完整过程。
- 「查看完整提示词」：Agent 这次收到的全部内容，便于判断它为什么这样做。
- 「停止」：停止正在进行的运行，已经做出的修改会保留。
- 「重试」：重新排队一次失败的运行。

## 接手任务

想自己来做，把执行者改成自己即可。已经排队的 Agent 工作会被撤回，正在进行的会被要求停止。之后想再交给 Agent，点「交给调度 Agent 开始」。

## Agent 队列

在「开发 › 任务」右上角切换到「Agent 队列」，可以看到整个 Agent 团队在做什么。每个 Agent 一条泳道：

| 区域 | 内容 |
| --- | --- |
| 正在执行 | 运行环境上正在跑的工作，已经跑了多久、最近在做什么。 |
| 接下来 | 排队中的任务和等待原因，例如“没有在线的运行环境”“并发已满”“被 PUR-12 阻塞”。 |
| 等待回复 | 在等人的事：失败的运行、提问、待验收，以及在等谁；轮到你的会高亮，点「去处理」直达。 |
| 已分配·空闲 | 分配给它、但现在没有动静的任务，写明原因，例如“在待规划中，不会自动开始”。 |

顶部一行汇总运行中、排队中、等你处理的数量，以及运行环境的忙碌情况。勾选「只看与我相关」，只显示你负责、创建或关注的任务。

::figure agent-queue | Agent 队列：每个 Agent 一条泳道，轮到你的事项高亮

## 仪表盘

「仪表盘」回答三个问题：交付进展如何、Agent 表现怎样、哪些工作卡住了。可以选择时间范围，每个数字都和上一周期对比。

- **关键数字**：完成任务、周期时间中位数、Agent 完成占比、单任务成本、运行成功率、返工率、人工介入率、排队等待中位数等。把鼠标移到数字上可以看到计算方式。
- **Agent 表现**：每个 Agent 在本周期的工作情况。
- **需要关注**：当前卡住或逾期的事项。
- **按项目**：每个项目的进度和本周期的交付。

仪表盘只统计你有权限看到的项目和任务。
