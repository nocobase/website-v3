Agent 团队在做什么、够不够用、花了多少，看两个地方：「Agent 队列」看工作负荷，「Agent 管理 › 用量」看用量和费用。

## Agent 队列

在「开发 › 任务」右上角切换到「Agent 队列」，可以看到整个 Agent 团队在做什么。每个 Agent 一条泳道：

| 区域 | 内容 |
| --- | --- |
| 正在执行 | 运行环境上正在做的工作，已经做了多久、最近在做什么 |
| 接下来 | 排队中的任务和等待原因，例如“没有在线的运行环境”“并发已满”“被 PUR-12 阻塞” |
| 等待回复 | 在等人的事：失败的运行、提问、待验收，以及在等谁；轮到你的会高亮，点「去处理」直达 |
| 已分配·空闲 | 分配给它、但现在没有动静的任务，写明原因，例如“在待规划中，不会自动开始” |

顶部一行汇总运行中、排队中、等你处理的数量，以及运行环境的忙碌情况。勾选「只看与我相关」，只显示你负责、创建或关注的任务。

::figure agent-queue | Agent 队列：每个 Agent 一条泳道，轮到你的事项高亮

经常看到“并发已满”或者排队很久，说明运行环境不够用：调高运行环境的最大并发数，或者再接入一台，见 [接入共享运行环境](../setup/shared-runtimes.md)。某个 Agent 一直空闲，可能是它的「擅长什么」写得太窄，调度 Agent 很少想到它，见 [启用 Agent](../setup/agents.md)。

## 用量

「Agent 管理 › 用量」列出 Agent 运行消耗的 token，以及按模型价格估算的费用：

- 选择日期范围，例如近 7 天、本月、上月；
- 按 Agent、唤醒人、对象（任务或会话）、模型、编码工具或日期汇总，也可以只看某个 Agent、某个人；
- 每一行有运行次数、时长、输入和输出的 token、缓存读写，以及估算费用；
- 「每日趋势」画出每天的费用或 token。

仪表盘上的“单任务成本”，也按这里的价格计算。知识库建索引、搜索等 Agent 运行之外的模型调用，单独列在「其他模型用量」里。

## 模型价格

费用按你设置的模型价格估算。在用量页点「设置价格」：

- 每个编码工具下，列出它的运行上报过的模型。为模型填写每百万 token 的输入、输出价格；也可以按规则给一批模型统一定价。
- 按月付费的编码工具，例如用订阅账号登录的 Claude Code，打开「包月/订阅（不计费）」，它的运行不计费用。
- 还没定价的模型，报表里的费用显示为“—”。

设置价格需要管理模型价格的权限，通常是管理员。
