Core 进度与待确认事项

现有 app-docs 已替换新版站点的 Core 内容，记录迁入范围与后续事项。

已完成的内容迁入

Core 使用 nocobase/app-docs 修订 5d8bdbe93bf63c6066013b121b189b3f8fdcad33 的全部文章，中英文各 22 篇：首页 1 篇、开始使用 4 篇、开发应用 11 篇、部署与运维 6 篇。原 Core 草稿和占位文章移除，能力、参考和未写的运维主题保留为不可点击的规划菜单。

迁入文章引用的 19 张真实英文截图和 1 个示例下载包；保留 Agent 提示词、手动实现代码、固定版本源码链接、历史示例说明和原验证范围。开始与 Studio 不更换内容体系，只修正失效的 Core 链接和全站首页对示例场景的说明。

新增中英文插件总览各 1 篇，Core 现为各 23 篇；列出 24 个主仓库插件、2 个商业仓库插件和 19 个示例插件，并注明是否内置及源码核对版本。

已确认的取舍

  • Core 内容以现有 app-docs 为准，不合并旧采购教程、能力草稿或插件档案。
  • 入门示例使用团队任务应用；Studio 继续使用采购团队场景。
  • 中文是写作基准，代码、示例应用和截图使用英文。
  • 使用 Agent 的提示词简短、自然；不使用 Agent 展示每一步的关键代码。
  • 新站仍使用现有静态构建器，不迁入 Fumadocs 框架。

能力内容退回待编写

用户认为能力总览、数据库、认证与用户、权限控制、文件管理的首版内容不合适，要求先退回待编写。中英文共 10 篇正文已从文章源目录移除，5 个菜单项均改为不可点击的待编写条目，不生成页面，也不参与翻页和 sitemap。能力菜单其余条目继续保持待编写，后续重新梳理内容再上线。

插件总览继续保留，Core 当前中英文各 23 篇。已有示例代码和图片资源未随文章下线删除。

扩展开发规划

按用户确认，在开发应用之后增加扩展开发，依次列出什么时候写插件、创建插件、插件的结构、发布插件、给插件写技能、向 UI 组件库贡献。中英文均显示为不可点击的待编写条目，尚不生成文章或加入 sitemap，现有文章数量不变。

后续事项

  1. 扩展开发、能力、参考及未编写的运维主题按已确认菜单逐篇补充，不恢复空文章。
  2. 示例源码仓库 app-tutorials 仍为私有；正式公开文档前需要确认读者获取完整源码的方式，迁移不改变仓库可见性。
  3. 各专题使用的示例版本和历史部署验证范围不同，后续升级按文章逐项验证，不能把迁移构建成功当作应用重新验收通过。
  4. 站点搜索、语法高亮、图片放大等阅读功能不属于本次内容迁移，后续单独决定。
  5. 正式发布沿用现有 CI 与 CDN 流程；本次 PR 不修改部署配置。
