### 🎉 新機能

- **[Agent]** Runner Agent の会話を、タスクへのリンク、キュー済みメッセージ、使用量とあわせて管理できるようになりました。会話履歴を保持したままエージェントを切り替えることもできます。 ([#11189](https://github.com/nocobase/nocobase/pull/11189))
- **[リリース管理]** リリースアーカイブをダウンロードできるようになりました。プレビュー環境とテスト環境は、それぞれの App 数とともに区別して表示されます。 ([#11190](https://github.com/nocobase/nocobase/pull/11190))
- **[アプリテンプレート]** テンプレートアプリケーションで、フォームと標準アクションの二重送信を防止するようにしました。安全なリトライと、カスタマイズ済みアプリケーション向けの連動したアップグレードにも対応しました。 ([#11192](https://github.com/nocobase/nocobase/pull/11192))
- **[クライアント]** アプリケーションテンプレートで、フォームの検証エラーの理由をフィールドの横に表示し、編集可能なエラー箇所へ自動的に移動し、送信に失敗しても入力内容を保持するようにしました。 ([#11193](https://github.com/nocobase/nocobase/pull/11193))

### 🚀 改善

- **[権限]** 標準の上部タブ、コンパクトなチェックボックスグループ、メニュールート、全体の付与状態フィルターを導入し、ロール権限を見渡しやすくしました。 ([#11201](https://github.com/nocobase/nocobase/pull/11201))

### 🐛 不具合修正

- **[アプリテンプレート]**
  - 削除によって無効になった一覧ページを復旧し、フィルター、並び順、詳細から戻る際のコンテキストを保持するようにしました。 ([#11186](https://github.com/nocobase/nocobase/pull/11186))
  - 詳細から戻ったときに、テンプレート一覧の並び順、ページサイズ、ソースタブが保持されるようにしました。カスタマイズ済みアプリケーション向けのソースアップグレード手順も文書化しました。 ([#11187](https://github.com/nocobase/nocobase/pull/11187))
- **[デモモード]** Users の設定 API で行った言語と外観の選択を、デモ訪問者のセッションごとに独立して保持するようにしました。通常のデプロイでの動作は変わりません。 ([#11191](https://github.com/nocobase/nocobase/pull/11191))
- **[Skills]** エージェントが公開せずに App ローカルのプラグインを開発できるようにし、プラグイン Skill の CLI テスト例を公開済みの npm パッケージで実行できるようにしました。 ([#11194](https://github.com/nocobase/nocobase/pull/11194))
- **[インターフェース]**
  - 設定アクションをコンパクトなアイコンボタンで表示し、ワークフローノードのタイトルが読みやすいようにしました。 ([#11195](https://github.com/nocobase/nocobase/pull/11195))
  - ファイルプレビューのダウンロードボタンを、ダイアログの右端ではなくファイル名の横に配置するようにしました。 ([#11196](https://github.com/nocobase/nocobase/pull/11196))
- **[Agent]**
  - 最終的な Runner Agent の選択をメッセージと一緒に確定するようにし、使われなかった選択に対して切り替え通知が表示されないようにしました。 ([#11198](https://github.com/nocobase/nocobase/pull/11198))
  - 対応するタスクが再開されたときに、タスクに紐づく会話の質問をクリアするようにしました。より新しい質問と未読の返信は保持されます。 ([#11203](https://github.com/nocobase/nocobase/pull/11203))
