### 🎉 New Features

- **[Agents]** Manage Runner Agent conversations with task links, queued messages and usage, and change agents while keeping conversation history ([#11189](https://github.com/nocobase/nocobase/pull/11189))
- **[Release management]** Download release archives and distinguish preview and test environments with their App counts ([#11190](https://github.com/nocobase/nocobase/pull/11190))
- **[App templates]** Prevent duplicate form and standard action submissions in template applications, with safe retries and coordinated upgrades for customized applications. ([#11192](https://github.com/nocobase/nocobase/pull/11192))
- **[Client]** Show form validation reasons beside fields, automatically locate editable errors, and preserve input after failed submissions in application templates. ([#11193](https://github.com/nocobase/nocobase/pull/11193))

### 🚀 Improvements

- **[Permissions]** Make role permissions easier to scan with standard top tabs, compact checkbox groups, menu routes and global grant-status filtering. ([#11201](https://github.com/nocobase/nocobase/pull/11201))

### 🐛 Bug Fixes

- **[App templates]**
  - Recover invalid list pages after deletions while preserving filters, ordering and detail-return context. ([#11186](https://github.com/nocobase/nocobase/pull/11186))
  - Preserve template list sorting, page sizes and source tabs when returning from details, with documented source upgrades for customized applications. ([#11187](https://github.com/nocobase/nocobase/pull/11187))
- **[Demo mode]** Keep language and appearance choices made through the Users preference API independent per demo visitor session while preserving ordinary deployment behavior. ([#11191](https://github.com/nocobase/nocobase/pull/11191))
- **[Skills]** Allow agents to develop App-local plugins without publication and run the plugin Skill's CLI testing example with published npm packages. ([#11194](https://github.com/nocobase/nocobase/pull/11194))
- **[Interface]**
  - Keep workflow node titles readable by displaying configuration actions as compact icon buttons. ([#11195](https://github.com/nocobase/nocobase/pull/11195))
  - Place the file preview download button beside the filename instead of at the right edge of the dialog. ([#11196](https://github.com/nocobase/nocobase/pull/11196))
- **[Agents]**
  - Confirm the final Runner Agent selection together with the message, avoiding switch notices for unused selections. ([#11198](https://github.com/nocobase/nocobase/pull/11198))
  - Clear a task-linked conversation question when the corresponding task resumes, while preserving newer questions and unread replies. ([#11203](https://github.com/nocobase/nocobase/pull/11203))
