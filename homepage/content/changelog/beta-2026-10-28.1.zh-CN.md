### 🎉 新特性

- **[Agent]** 支持带任务关联、排队消息和用量的 Runner Agent 对话，并可保留对话历史更换 Agent ([#11189](https://github.com/nocobase/nocobase/pull/11189))
- **[发布管理]** 支持下载发布版本压缩包，并区分预览和测试环境、查看各环境应用数量 ([#11190](https://github.com/nocobase/nocobase/pull/11190))
- **[应用模板]** 模板应用默认防止表单和标准动作重复提交，支持安全重试，并为定制应用提供协同升级能力。 ([#11192](https://github.com/nocobase/nocobase/pull/11192))
- **[客户端]** 应用模板在字段旁显示校验原因，自动定位可编辑错误，并在提交失败后保留输入。 ([#11193](https://github.com/nocobase/nocobase/pull/11193))

### 🚀 优化

- **[权限]** 角色权限改用标准顶部标签、紧凑复选框分组、菜单路由和全局授权状态筛选，便于浏览与配置。 ([#11201](https://github.com/nocobase/nocobase/pull/11201))

### 🐛 修复

- **[应用模板]**
  - 删除记录后自动修正无效列表页，并保留筛选、排序及详情返回上下文。 ([#11186](https://github.com/nocobase/nocobase/pull/11186))
  - 模板列表从详情返回时保留排序、每页条数和来源标签，并提供定制应用的源码升级说明。 ([#11187](https://github.com/nocobase/nocobase/pull/11187))
- **[演示模式]** 通过 Users 偏好 API 设置的语言和外观按演示访客会话独立保存，普通部署行为保持不变。 ([#11191](https://github.com/nocobase/nocobase/pull/11191))
- **[Skills]** 允许 Agent 开发无需发布的 App 本地插件，并修复插件 Skill 的 CLI 测试示例在公开 npm 包环境下的运行问题。 ([#11194](https://github.com/nocobase/nocobase/pull/11194))
- **[界面]**
  - 将工作流节点的配置操作显示为紧凑图标按钮，为节点标题保留可读空间。 ([#11195](https://github.com/nocobase/nocobase/pull/11195))
  - 将文件预览弹窗的下载按钮移至文件名右侧，避免与窗口右上角的关闭按钮错位。 ([#11196](https://github.com/nocobase/nocobase/pull/11196))
- **[Agent]**
  - 发送消息时统一确认最终执行机 Agent，避免为未使用的选择记录切换提示。 ([#11198](https://github.com/nocobase/nocobase/pull/11198))
  - 对应任务恢复后结清关联会话提问，同时保留更新的问题和未读回复。 ([#11203](https://github.com/nocobase/nocobase/pull/11203))
