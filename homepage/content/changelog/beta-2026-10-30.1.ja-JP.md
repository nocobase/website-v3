### 🎉 新機能

- **[同時実行制御]**
  - アプリケーション開発者が、再利用可能な同時実行 API とプロセス内バックエンドを使って、固定 TTL のクリティカルセクションを調整できるようになりました。待機のキャンセル、タイマー失敗時の安全な処理、期限内のシャットダウン、バックエンドの自動クリーンアップに対応しています。 ([#11209](https://github.com/nocobase/nocobase/pull/11209))
  - アプリケーションで名前付きのプロセスローカルな同時実行サービスを設定し、1 つのロックマネージャーを複数のプラグインで共有できるようになりました。 ([#11256](https://github.com/nocobase/nocobase/pull/11256))
- **[バックグラウンドジョブ]** Redis を使うバックグラウンドジョブとスケジュールジョブには、商用の Jobs Redis Server プラグインが必要になりました。Memory ジョブは引き続きこのプラグインなしで利用できます。 ([#11229](https://github.com/nocobase/nocobase/pull/11229))
- **[認証]** 独立した SMTP または Resend の送信元を使ってパスワード回復を設定できるようになりました。既存のカスタムコールバックと従来のメールチャネルはそのまま利用できます。 ([#11233](https://github.com/nocobase/nocobase/pull/11233))
- **[データベース]** データベースクエリで LOWER 式を使った、データベース間で移植可能な大文字・小文字を区別しないテキスト検索をサポートしました。 ([#11236](https://github.com/nocobase/nocobase/pull/11236))
- **[Agent]**
  - Runner の会話ごとに、サポートされている推論強度を選択して保持できるようになりました。 ([#11239](https://github.com/nocobase/nocobase/pull/11239))
  - Runner の会話でプロジェクトのリポジトリを使えるようにし、Agent を変更してもワークスペースを保持するようにしました。 ([#11244](https://github.com/nocobase/nocobase/pull/11244))

### 🚀 改善

- **[Agent]**
  - Agents 2 で従来の Agents ベクターコレクションを削除しました。移行ガイダンスを提供し、データは保持されます。モデルサービスと Knowledge のインデックス作成も引き続き利用できます。 ([#11216](https://github.com/nocobase/nocobase/pull/11216))
  - コンパクトなテンプレートメニューから Agent の説明を入力できるようになりました。元に戻す操作に対応し、既知のファミリーの新しいモデルは自動的に候補に表示されます。 ([#11249](https://github.com/nocobase/nocobase/pull/11249))
- **[プロジェクト]**
  - アプリケーションが独自のメッセージタイプで自動コメント通知を翻訳できるようにしました。非公開の出所情報は引き続き表示されません。 ([#11220](https://github.com/nocobase/nocobase/pull/11220))
  - アプリケーションが過去のタスクをすべて読み込まずに、完了済みタスクの履歴をページ単位で取得できるようにしました。 ([#11224](https://github.com/nocobase/nocobase/pull/11224))
  - タスクの詳細と進捗について、繰り返し発生していたデータベースリクエストと更新リクエストを減らしました。 ([#11225](https://github.com/nocobase/nocobase/pull/11225))
  - タスクカードを軽量なバッチで読み込み、ライブ更新中に無関係なタスク詳細が再読み込みされないようにしました。 ([#11240](https://github.com/nocobase/nocobase/pull/11240))
- **[Skills]** アプリケーション開発 Skills に同梱された、実行可能でテスト済みのサンプルから、一覧と編集の操作を学べるようになりました。 ([#11222](https://github.com/nocobase/nocobase/pull/11222))
- **[バックグラウンドジョブ]** Redis キューには、明示的に登録した商用 Server プラグインが必要になりました。プロセス内の Memory キューは引き続き Redis に依存せず利用できます。 ([#11227](https://github.com/nocobase/nocobase/pull/11227))
- **[アプリテンプレート]** 両方のテンプレートから未使用のクライアント拡張エントリファイルを削除し、新規アプリケーションをシンプルにしました。 ([#11228](https://github.com/nocobase/nocobase/pull/11228))

### 🐛 不具合修正

- **[アプリテンプレート]**
  - テンプレートの一覧で、データなし、フィルターに一致なし、アクセス拒否、リクエスト失敗を区別して表示するようにしました。わかりやすい復旧操作と、既存アプリケーション向けの検証済みソースアップグレード手順も用意しました。 ([#11188](https://github.com/nocobase/nocobase/pull/11188))
  - ユーザー編集ドロワーの開閉時に、誤解を招くローディング表示やテーブルの表示位置のずれが起きないようにしました。 ([#11218](https://github.com/nocobase/nocobase/pull/11218))
- **[Agent]**
  - 画面に戻ったときもアクティブなエージェントの会話の接続を維持し、復旧できない場合は保存済みの返信を同期し、完了が確認された後はブラウザ側の保留中のサブスクリプションをクリアするようにしました。 ([#11205](https://github.com/nocobase/nocobase/pull/11205))
  - 先頭の作業を実行できない場合でも、Runner が最大 150 件のキュー済み候補から実行可能な作業を見つけられるようにしました。 ([#11210](https://github.com/nocobase/nocobase/pull/11210))
  - 実行の詳細を初めて読み込んでいる間にステータスが変わっても、表示されるステータスが最新になるようにしました。 ([#11226](https://github.com/nocobase/nocobase/pull/11226))
  - ランタイムの実行を正確な総数とともに 20 件ずつ閲覧できるようにし、自分の会話を名前から開けるようにしました。ステータスとクォータのバッジの表示も統一しました。 ([#11238](https://github.com/nocobase/nocobase/pull/11238))
  - メッセージを既読にしたときに、会話の完了履歴が保持されるようにしました。 ([#11251](https://github.com/nocobase/nocobase/pull/11251))
  - 会話でサポートされている Agent の推論のデフォルト値を保持し、利用できない場合はツールのデフォルトにフォールバックし、手動の選択を適用できない場合はその理由を表示するようにしました。 ([#11255](https://github.com/nocobase/nocobase/pull/11255))
- **[リリース管理]** 生成された最初の管理者の認証情報を、保存されるか App が削除されるまで保持するようにしました。 ([#11219](https://github.com/nocobase/nocobase/pull/11219))
- **[Agent セッション]**
  - セッションページのツールバーをセッション一覧全体と揃え、サイドバーを折りたたんだり再度開いたりできるようにしました。 ([#11223](https://github.com/nocobase/nocobase/pull/11223))
  - エージェントへのメッセージに含まれる長いハッシュ、URL、スペースのない単語が、各行の先頭が切れることなくメッセージバブル内で折り返されるようになりました。 ([#11241](https://github.com/nocobase/nocobase/pull/11241))
- **[プロジェクト]** ファイル履歴が長いタスクでも、添付ファイルの証跡の読み込み量が一定に収まるようにしました。 ([#11246](https://github.com/nocobase/nocobase/pull/11246))
- **[デモモード]** 確定した日次デモリセットの失敗を安全に復旧し、成功済みの日次リセットを繰り返すことなく、キューにあるメールボックスのクリーンアップを進めるようにしました。 ([#11248](https://github.com/nocobase/nocobase/pull/11248))
- **[アプリ基盤]**
  - 重複した Settings グループを統合し、物理的な外部キーを論理的なリレーションフィールドとは分けて集計するようにしました。 ([#11253](https://github.com/nocobase/nocobase/pull/11253))
  - リクエストログで API トラフィックの送信元を識別できるようにしました。クエリコンテキストの長さは制限され、機密パラメーターは除外されます。 ([#11254](https://github.com/nocobase/nocobase/pull/11254))
- **[Skills]** 最初からフロントエンドとバックエンドをまとめて計画し、定型的な CRUD 開発を効率化し、定型的な設計承認で中断することなくアプリケーション機能全体を検証するようにしました。 ([#11260](https://github.com/nocobase/nocobase/pull/11260))
- **[権限]** 権限のデータ範囲の表示を操作とグループの間で揃え、セレクターの幅を統一し、レスポンシブなレイアウトにしました。 ([#11262](https://github.com/nocobase/nocobase/pull/11262))
