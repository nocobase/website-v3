### 🎉 New Features

- **[Concurrency]**
  - Application developers can coordinate fixed-TTL critical sections through a reusable concurrency API and in-process backend, with cancellable waits, safe timer-failure handling, deadline-safe shutdown and automatic backend cleanup. ([#11209](https://github.com/nocobase/nocobase/pull/11209))
  - Applications can configure named process-local concurrency services and share one lock manager across plugins. ([#11256](https://github.com/nocobase/nocobase/pull/11256))
- **[Background jobs]** Redis-backed background and scheduled jobs now require the commercial Jobs Redis Server plugin, while Memory jobs remain available without it. ([#11229](https://github.com/nocobase/nocobase/pull/11229))
- **[Authentication]** Configure password recovery with an independent SMTP or Resend sender while preserving existing custom callbacks and legacy email channels. ([#11233](https://github.com/nocobase/nocobase/pull/11233))
- **[Database]** Support portable case-insensitive text searches with a LOWER expression in database queries. ([#11236](https://github.com/nocobase/nocobase/pull/11236))
- **[Agents]**
  - Choose and retain a supported reasoning effort for each Runner conversation. ([#11239](https://github.com/nocobase/nocobase/pull/11239))
  - Allow Runner conversations to use project repositories and preserve their workspace when changing Agents. ([#11244](https://github.com/nocobase/nocobase/pull/11244))

### 🚀 Improvements

- **[Agents]**
  - Remove legacy Agents vector collections in Agents 2, with migration guidance and retained data, while preserving model services and Knowledge indexing. ([#11216](https://github.com/nocobase/nocobase/pull/11216))
  - Fill Agent descriptions from a compact template menu with Undo, including automatic suggestions for newer models in known families. ([#11249](https://github.com/nocobase/nocobase/pull/11249))
- **[Projects]**
  - Allow applications to translate automatic comment notices using their own message types while keeping private provenance hidden. ([#11220](https://github.com/nocobase/nocobase/pull/11220))
  - Allow applications to page completed task history without loading every historical task. ([#11224](https://github.com/nocobase/nocobase/pull/11224))
  - Reduce repeated database and refresh requests for task details and progress. ([#11225](https://github.com/nocobase/nocobase/pull/11225))
  - Load issue cards in lightweight batches and keep unrelated task details from reloading during live updates. ([#11240](https://github.com/nocobase/nocobase/pull/11240))
- **[Skills]** Learn list and edit interactions from a runnable, tested example included with the application development Skills. ([#11222](https://github.com/nocobase/nocobase/pull/11222))
- **[Background jobs]** Redis queues now require an explicitly registered commercial Server plugin, while in-process Memory queues remain available without Redis dependencies. ([#11227](https://github.com/nocobase/nocobase/pull/11227))
- **[App templates]** Simplify new applications by removing unused client extension entry files from both templates. ([#11228](https://github.com/nocobase/nocobase/pull/11228))
