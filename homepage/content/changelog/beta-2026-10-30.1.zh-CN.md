### 🎉 新特性

- **[并发控制]**
  - 应用开发者可以通过可复用的并发 API 和进程内后端协调固定租期的临界区，支持取消等待、受控的定时器故障处理、准确的关闭超时和自动后端清理。 ([#11209](https://github.com/nocobase/nocobase/pull/11209))
  - 应用可以配置具名的单进程并发服务，让多个插件共享同一个锁管理器。 ([#11256](https://github.com/nocobase/nocobase/pull/11256))
- **[后台任务]** Redis 后台任务和定时任务现需安装商业 Jobs Redis Server 插件，Memory 任务仍可独立使用。 ([#11229](https://github.com/nocobase/nocobase/pull/11229))
- **[认证]** 找回密码支持独立配置 SMTP 或 Resend 发件服务，同时兼容已有自定义函数与旧邮件渠道。 ([#11233](https://github.com/nocobase/nocobase/pull/11233))
- **[数据库]** 数据库查询支持用 LOWER 表达式进行可移植的不区分大小写文本搜索。 ([#11236](https://github.com/nocobase/nocobase/pull/11236))
- **[Agent]**
  - 为每个执行机 Agent 对话选择并保存模型支持的推理强度。 ([#11239](https://github.com/nocobase/nocobase/pull/11239))
  - 支持执行机对话使用项目仓库，并在更换 Agent 时保留工作目录。 ([#11244](https://github.com/nocobase/nocobase/pull/11244))

### 🚀 优化

- **[Agent]**
  - Agents 2 移除旧向量集合并提供迁移指引，保留已有数据、模型服务和 Knowledge 独立索引。 ([#11216](https://github.com/nocobase/nocobase/pull/11216))
  - 添加或编辑 Agent 时可从小下拉填写「擅长什么」并一步撤销，已知系列的新型号也能自动预填。 ([#11249](https://github.com/nocobase/nocobase/pull/11249))
- **[项目]**
  - 应用可自定义消息类型来翻译自动评论提示，同时隐藏内部追溯信息。 ([#11220](https://github.com/nocobase/nocobase/pull/11220))
  - 支持应用在数据库中分页已完成任务，无须加载全部历史任务。 ([#11224](https://github.com/nocobase/nocobase/pull/11224))
  - 减少任务详情和进度的重复数据库读取与刷新请求。 ([#11225](https://github.com/nocobase/nocobase/pull/11225))
  - 任务卡片改用轻量批量读取，实时更新时不再重读无关任务详情。 ([#11240](https://github.com/nocobase/nocobase/pull/11240))
- **[Skills]** 应用开发 Skills 提供可运行并持续测试的列表编辑示例。 ([#11222](https://github.com/nocobase/nocobase/pull/11222))
- **[后台任务]** Redis 队列现在需要显式注册商业服务端插件，进程内 Memory 队列仍可在不依赖 Redis 的情况下使用。 ([#11227](https://github.com/nocobase/nocobase/pull/11227))
- **[应用模板]** 精简默认模板和示例模板，移除未使用的客户端扩展入口文件。 ([#11228](https://github.com/nocobase/nocobase/pull/11228))

### 🐛 修复

- **[应用模板]**
  - 模板列表区分暂无数据、筛选无结果、无权限和请求失败，提供明确恢复操作，并支持旧应用通过完整源码升级获得同样能力。 ([#11188](https://github.com/nocobase/nocobase/pull/11188))
  - 修复打开或关闭用户编辑抽屉时加载提示误显、闪烁和表格跳动的问题。 ([#11218](https://github.com/nocobase/nocobase/pull/11218))
- **[Agent]**
  - 返回执行中的 Agent 对话时复用连接，无法恢复时同步已保存回复，并在确认结束后清理仍等待中的浏览器订阅。 ([#11205](https://github.com/nocobase/nocobase/pull/11205))
  - 当前面的任务不适配时，执行机可在最多 150 个排队候选中继续查找可执行任务。 ([#11210](https://github.com/nocobase/nocobase/pull/11210))
  - 运行详情首次加载期间状态发生变化时，及时显示最新运行状态。 ([#11226](https://github.com/nocobase/nocobase/pull/11226))
  - 执行机记录支持每页二十条翻页和准确总数，可按名称进入自己的对话，并统一状态与额度标签。 ([#11238](https://github.com/nocobase/nocobase/pull/11238))
  - 标记已读时保留会话收尾历史读取。 ([#11251](https://github.com/nocobase/nocobase/pull/11251))
  - 对话保留受支持的 Agent 默认推理强度，不可用时使用工具默认值，并说明手选强度未能应用的情况。 ([#11255](https://github.com/nocobase/nocobase/pull/11255))
- **[发布管理]** 生成的初始管理员凭据保留到手动保存或应用删除为止。 ([#11219](https://github.com/nocobase/nocobase/pull/11219))
- **[Agent 会话]**
  - 统一会话页侧栏工具区的布局，并支持收起和展开侧栏。 ([#11223](https://github.com/nocobase/nocobase/pull/11223))
  - 发给 Agent 的消息中含长哈希、URL 或无空格英文时，现在会在气泡内换行，不再裁掉每行开头。 ([#11241](https://github.com/nocobase/nocobase/pull/11241))
- **[项目]** 限制长附件历史任务的证据读取量。 ([#11246](https://github.com/nocobase/nocobase/pull/11246))
- **[演示模式]** 安全恢复已结束的每日演示重置失败并推进待处理邮箱清理，避免重复执行已成功的每日重置。 ([#11248](https://github.com/nocobase/nocobase/pull/11248))
- **[应用基础]**
  - 合并重复的设置分组，并将物理外键与逻辑关联字段分开统计。 ([#11253](https://github.com/nocobase/nocobase/pull/11253))
  - 请求日志可识别 API 调用来源，并限制查询参数长度及排除敏感参数。 ([#11254](https://github.com/nocobase/nocobase/pull/11254))
- **[Skills]** 在开发开始时统一规划前后端，简化常规 CRUD 开发，并在无需常规设计审批停顿的情况下验证完整应用功能。 ([#11260](https://github.com/nocobase/nocobase/pull/11260))
- **[权限]** 统一权限数据范围在操作与分组间的对齐、下拉框宽度及响应式布局。 ([#11262](https://github.com/nocobase/nocobase/pull/11262))
