### 🚀 Improvements

- **[Agents]** Applications can order conversation-linked work by its latest update without additional requests. ([#11283](https://github.com/nocobase/nocobase/pull/11283))
- **[Users]** Invited users can choose an optional username and correct conflicts without losing their form. ([#11289](https://github.com/nocobase/nocobase/pull/11289))

### 🐛 Bug Fixes

- **[Agents]**
  - Explain exhausted tool quota and known reset times for queued runs instead of reporting unavailable tools. ([#11279](https://github.com/nocobase/nocobase/pull/11279))
  - Continue unreceived queued messages after stopping a Runner turn without creating duplicate messages. ([#11282](https://github.com/nocobase/nocobase/pull/11282))
- **[Projects]** Show why a saved comment did not start work, including when the comment run limit was reached. ([#11280](https://github.com/nocobase/nocobase/pull/11280))
- **[Agent sessions]** Press Enter for new lines on phones and use the send button to submit personal agent messages. ([#11281](https://github.com/nocobase/nocobase/pull/11281))
- **[App foundation]** Restore evidence-backed data model associations through guarded service factories in App Foundation. ([#11287](https://github.com/nocobase/nocobase/pull/11287))
