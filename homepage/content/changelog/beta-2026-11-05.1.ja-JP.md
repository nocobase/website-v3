### 🎉 新機能

- **[Agent ランナー]**
  - 実行時に、提供された認証情報で公式の Gitea CLI を使えるようになりました。 ([#11313](https://github.com/nocobase/nocobase/pull/11313))
  - ACP を通じて、実行マシン上で DeepSeek Harness をコーディングツールとして実行できるようになりました。 ([#11314](https://github.com/nocobase/nocobase/pull/11314))
- **[通知]** 登録済みの通知シナリオと、安全な合成コンテンツのプレビューを、統合された読み取り専用のテンプレート一覧で表示するようにしました。 ([#11331](https://github.com/nocobase/nocobase/pull/11331))
- **[ユーザー]** ユーザーが選択した言語をブラウザーやデバイスをまたいで保持し、バックグラウンドタスクがユーザー ID から優先言語を取得できるようにしました。 ([#11332](https://github.com/nocobase/nocobase/pull/11332))
- **[アプリテンプレート]** テンプレートから作成したアプリケーションでは、管理機能が 1 つの System settings 項目にまとめられました。開くとカテゴリー別のカードが並ぶホームページが表示され、各モジュール内はタブで切り替えられます。 ([#11333](https://github.com/nocobase/nocobase/pull/11333))

### 🚀 改善

- **[アプリテンプレート]** Default と Examples のサイドバーとサインイン画面のスローガンを「AI + NocoBase」と「Build reliable business systems」に統一し、Default のフッターからテンプレート名を削除しました。バージョンは引き続き表示されます。 ([#11321](https://github.com/nocobase/nocobase/pull/11321))
- **[Agent セッション]**
  - My Agent のセッション詳細で、使用量を Runner の会話と同じように行で表示するようにしました。 ([#11329](https://github.com/nocobase/nocobase/pull/11329))
  - Runner Agent と My Agent のセッション行から、補助的なエージェント、ランタイム、プロジェクトのラベルを削除してシンプルにしました。 ([#11330](https://github.com/nocobase/nocobase/pull/11330))
  - セッション詳細で、リンクされたタスクのタイトルを全幅で表示し、その下の行にキーとステータスを表示するようにしました。 ([#11335](https://github.com/nocobase/nocobase/pull/11335))
- **[Agent]** ランタイムドロワーの概要、ワークスペース、実行の各テーブルで、短い列ではなくツールのクォータ、ディレクトリ、タスクに幅を割り当てるようにしました。サイズ、種類、エージェント名が途中で切れなくなりました。 ([#11336](https://github.com/nocobase/nocobase/pull/11336))

### 🐛 不具合修正

- **[デモモード]** 現在のアカウントと遷移先 URL を維持したまま、保護されたデモリンクを自動的に開くようにしました。 ([#11319](https://github.com/nocobase/nocobase/pull/11319))
- **[Agent]** 復元した会話をアーカイブ済み一覧から自動的に削除するようにしました。 ([#11320](https://github.com/nocobase/nocobase/pull/11320))
- **[認証]** 登録時に正確なフィードバックを表示し、新しいアカウントはデフォルトで自動的にサインインするようにしました。次の手順を案内できない設定については警告を表示します。 ([#11322](https://github.com/nocobase/nocobase/pull/11322))
- **[サーバー]** リクエストの到着待ち時間を 5 分から 10 分に延ばし、低速な回線での大きなアップロードが HTTP 408 で中断されないようにしました。 ([#11323](https://github.com/nocobase/nocobase/pull/11323))
- **[CLI]** CLI のアップグレード後に、実行中のバックグラウンドのエージェント接続を再起動するようにし、エージェント設定を読み込めない場合は復旧手順を表示するようにしました。 ([#11334](https://github.com/nocobase/nocobase/pull/11334))
