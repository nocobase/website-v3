### 🎉 New Features

- **[Agent runner]**
  - Let runs use the official Gitea CLI with their supplied credentials. ([#11313](https://github.com/nocobase/nocobase/pull/11313))
  - Run DeepSeek Harness as a coding tool on execution machines through ACP. ([#11314](https://github.com/nocobase/nocobase/pull/11314))
- **[Notifications]** Show registered notification scenarios and safe synthetic content previews in a unified read-only template directory. ([#11331](https://github.com/nocobase/nocobase/pull/11331))
- **[Users]** Keep users' selected language across browsers and devices, and let background tasks resolve their preferred language by user ID. ([#11332](https://github.com/nocobase/nocobase/pull/11332))
- **[App templates]** Applications built from the templates show administration as one System settings entry that opens a home page of cards by category, with tabs inside each module. ([#11333](https://github.com/nocobase/nocobase/pull/11333))

### 🚀 Improvements

- **[App templates]** Unify the Default and Examples sidebar and sign-in slogans as “AI + NocoBase” and “Build reliable business systems”, and remove the template name from the Default footer while keeping its version. ([#11321](https://github.com/nocobase/nocobase/pull/11321))
- **[Agent sessions]**
  - Show usage in My Agent's session details as rows, the same way as runner conversations. ([#11329](https://github.com/nocobase/nocobase/pull/11329))
  - Simplify Runner Agent and My Agent session rows by removing secondary agent, runtime and project labels. ([#11330](https://github.com/nocobase/nocobase/pull/11330))
  - Show a linked task's full-width title in session details, with its key and status on the line below. ([#11335](https://github.com/nocobase/nocobase/pull/11335))
- **[Agents]** The runtime drawer's overview, workspaces and runs tables give their width to tool quotas, directories and issues instead of short columns, so sizes, types and agent names are no longer cut off. ([#11336](https://github.com/nocobase/nocobase/pull/11336))

### 🐛 Bug Fixes

- **[Demo mode]** Open protected demo links automatically while keeping the current account and destination URL. ([#11319](https://github.com/nocobase/nocobase/pull/11319))
- **[Agents]** Remove restored conversations from the archived list automatically. ([#11320](https://github.com/nocobase/nocobase/pull/11320))
- **[Authentication]** Give accurate registration feedback, sign in new accounts by default, and warn about configurations that cannot explain the next step. ([#11322](https://github.com/nocobase/nocobase/pull/11322))
- **[Server]** Give a request ten minutes to arrive instead of five, so a large upload over a slow link is no longer cut off with HTTP 408. ([#11323](https://github.com/nocobase/nocobase/pull/11323))
- **[CLI]** Restart running background agent connections after CLI upgrades and provide recovery steps when agent settings cannot load. ([#11334](https://github.com/nocobase/nocobase/pull/11334))
