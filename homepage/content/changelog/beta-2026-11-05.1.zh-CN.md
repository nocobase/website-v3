### 🎉 新特性

- **[Agent 运行器]**
  - 支持运行使用所提供凭据调用官方 Gitea CLI。 ([#11313](https://github.com/nocobase/nocobase/pull/11313))
  - 执行机现在可以通过 ACP 使用 DeepSeek Harness 作为编码工具。 ([#11314](https://github.com/nocobase/nocobase/pull/11314))
- **[通知]** 在统一的只读通知模板目录中展示已登记通知场景并提供安全的合成内容预览。 ([#11331](https://github.com/nocobase/nocobase/pull/11331))
- **[用户]** 跨浏览器和设备保留用户选择的语言，并支持后台任务按用户 ID 解析其偏好语言。 ([#11332](https://github.com/nocobase/nocobase/pull/11332))
- **[应用模板]** 基于模板搭建的应用将管理功能统一为一个“系统设置”入口，打开后按分类展示功能卡片，模块内用标签页切换。 ([#11333](https://github.com/nocobase/nocobase/pull/11333))

### 🚀 优化

- **[应用模板]** 将 Default 与 Examples 侧栏和登录页标语统一为“AI + NocoBase”和“Build reliable business systems”，并去掉 Default 页脚模板名称、保留版本号。 ([#11321](https://github.com/nocobase/nocobase/pull/11321))
- **[Agent 会话]**
  - My Agent 会话详情中的用量改为逐行显示，与 Runner 对话一致。 ([#11329](https://github.com/nocobase/nocobase/pull/11329))
  - 精简 Runner Agent 与 My Agent 会话行，移除多余的 Agent、运行环境和项目名称。 ([#11330](https://github.com/nocobase/nocobase/pull/11330))
  - 会话详情中关联任务的标题独占首行，编号和状态放在第二行。 ([#11335](https://github.com/nocobase/nocobase/pull/11335))
- **[Agent]** 运行环境抽屉中概览、工作目录和运行记录表格的宽度优先留给额度、目录和任务，大小、类型和 Agent 名称不再被截断。 ([#11336](https://github.com/nocobase/nocobase/pull/11336))

### 🐛 修复

- **[演示模式]** 直接打开演示模式业务链接时自动登录，并保留已有账号和目标地址。 ([#11319](https://github.com/nocobase/nocobase/pull/11319))
- **[Agent]** 恢复会话后自动从已归档列表移除。 ([#11320](https://github.com/nocobase/nocobase/pull/11320))
- **[认证]** 准确反馈注册请求结果，默认让新账号自动登录，并对无法提供后续指引的配置发出警告。 ([#11322](https://github.com/nocobase/nocobase/pull/11322))
- **[服务端]** 请求的接收时限由 5 分钟延长到 10 分钟，慢速网络下上传大文件不再因 HTTP 408 中断。 ([#11323](https://github.com/nocobase/nocobase/pull/11323))
- **[命令行]** 命令行升级后重启运行中的后台智能体连接，并在智能体设置无法加载时提供恢复操作提示。 ([#11334](https://github.com/nocobase/nocobase/pull/11334))
