### 🎉 新機能

- **[Agent]** クォータの上限に達した作業を元の Runner 上に保持し、クォータが回復したら元のセッションを再開するようになりました。 ([#11372](https://github.com/nocobase/nocobase/pull/11372))
- **[多言語]** Agent、プロジェクト、リリース、ナレッジなどのコアプラグインにロシア語と韓国語を追加し、他の言語で誤訳されていた「issue」や「executor」などの用語を修正しました。 ([#11379](https://github.com/nocobase/nocobase/pull/11379))
- **[アプリ基盤]** System settings でアプリケーションの機能と拡張を確認し、その設定を調べられるようになりました。データベースの閲覧とあわせて Agent のセットアップガイダンスも利用できます。 ([#11383](https://github.com/nocobase/nocobase/pull/11383))

### 🚀 改善

- **[認証]** パスワード回復を auth.passwordReset.mailer で設定するようにしました。既存の auth.email.mailer の参照は、そのまま新しいフィールドに移してください。 ([#11346](https://github.com/nocobase/nocobase/pull/11346))
- **[権限]** 権限チェックとチケットの自動クローズ時に、冗長なデータベース読み込みを減らしました。 ([#11357](https://github.com/nocobase/nocobase/pull/11357))
- **[Agent]**
  - 実行履歴のエージェントフィルターで、その対象で実行されたエージェントだけを一覧表示できるようになりました。削除済みのエージェントも含まれます。 ([#11367](https://github.com/nocobase/nocobase/pull/11367))
  - ランタイムの所有者と管理者が、判明しているリセット時刻より前にクォータのマークを解除できるようになりました。また、同じクォータ期間で残量が再び報告されると、マークは自動的に解除されます。 ([#11369](https://github.com/nocobase/nocobase/pull/11369))
  - アプリケーションが独立したエージェントセッションで固定の指示を先頭に置けるようにし、プロンプトキャッシュを再利用しやすくしました。 ([#11371](https://github.com/nocobase/nocobase/pull/11371))
  - キュー済みのエージェント実行を、その実行のコーディングツールに対する各 Runner の上限に比例して振り分けるようにしました。空きの多い Runner が次の実行を先に引き受けます。 ([#11388](https://github.com/nocobase/nocobase/pull/11388))
- **[リリース管理]**
  - 環境ページで、共有アプリホストをそれぞれ 1 回だけ容量カードとして表示し、実行中のアプリへリンクするようにしました。アプリ一覧では各アプリのランタイム状態とその理由を表示し、状態で絞り込めます。アプリのページでは、ホストがそのアプリに影響する場合にのみホストについて表示します。 ([#11380](https://github.com/nocobase/nocobase/pull/11380))
  - アプリは環境のページで一覧表示・作成するようになり、各アプリのランタイム状態と状態フィルターを表示します。共有ホストのカードからは、環境ごとの実行中のアプリへリンクします。 ([#11385](https://github.com/nocobase/nocobase/pull/11385))
- **[プロジェクト]** 関連するタスクのアクティビティでは、依存関係と呼ぶのではなく、両方のタスクに「関連を追加しました」または「関連を削除しました」と表示するようにしました。 ([#11389](https://github.com/nocobase/nocobase/pull/11389))
- **[リアルタイム更新]** アプリケーションのリアルタイムブローカーを `realtime.broker` で設定するようにしました。インメモリのデフォルトは維持され、従来の設定パスは移行ガイダンスとともに報告されます。 ([#11392](https://github.com/nocobase/nocobase/pull/11392))
- **[サーバー]** Concurrency、Jobs、Queue の設定を `backends` に統一しました。従来の設定や混在した設定は、黙ってローカル実行にフォールバックするのではなく、移行ガイダンスとともに拒否します。 ([#11393](https://github.com/nocobase/nocobase/pull/11393))

### 🐛 不具合修正

- **[データベース]** null の並び順とページネーションを維持したまま、NULL を許容しないフィールドのインデックスを使ったソートを改善しました。 ([#11356](https://github.com/nocobase/nocobase/pull/11356))
- **[アプリホスティング]**
  - 一時的にヒープ使用量が増えてもプレビューの受け入れを安定させ、Host のローテーションの待機時間の上限は維持するようにしました。 ([#11359](https://github.com/nocobase/nocobase/pull/11359))
  - アーカイブ処理量の上限、リアルタイムのメモリに基づく受け入れ、処理中のリクエストとデプロイを保護するリサイクルにより、共有アプリケーション Host の応答性を維持するようにしました。 ([#11373](https://github.com/nocobase/nocobase/pull/11373))
- **[Agent]**
  - 拒否されたチャットメッセージを復旧用に保持し、会話で問題が起きたときに一貫した次の手順を提示するようにしました。 ([#11361](https://github.com/nocobase/nocobase/pull/11361))
  - Agent の起動前に、一時的なリポジトリアクセスの問題をリトライし、準備が復旧できない場合は実際のエラーを表示するようにしました。 ([#11374](https://github.com/nocobase/nocobase/pull/11374))
  - 読み取り専用の作業と書き込み可能な作業を切り替えるときは新しいエージェントセッションを開始し、既存の書き込み可能なセッションは引き続き再利用できるようにしました。 ([#11377](https://github.com/nocobase/nocobase/pull/11377))
  - 接続の切断で中断された会話が、アイドル状態になって更新されると復旧するようにしました。 ([#11381](https://github.com/nocobase/nocobase/pull/11381))
- **[アプリテンプレート]**
  - 新しく生成された Examples アプリケーションから、フローティングの注釈ツールバーを削除しました。 ([#11366](https://github.com/nocobase/nocobase/pull/11366))
  - 英語以外の言語のアプリケーションで、起動中に「Loading application…」が英語で表示されないようにしました。 ([#11376](https://github.com/nocobase/nocobase/pull/11376))
- **[リリース管理]** ページのアクションを表示したまま、リリースページの説明が利用可能な幅を使えるようにしました。 ([#11368](https://github.com/nocobase/nocobase/pull/11368))
- **[Skills]** UI コンポーネントチェッカーが、ネイティブおよび shadcn の Input による日付フィールドを検出するようになりました。また、Examples の勤務カレンダーでは、ブラウザーネイティブの日付ピッカーではなくカレンダーから休日を選ぶようにしました。 ([#11378](https://github.com/nocobase/nocobase/pull/11378))
- **[Agent ランナー]** 予期しない終了の後に Runner サービスを自動的に復旧するようにしました。明示的に停止したサービスは停止したままにし、更新後の再起動に失敗した場合は報告します。 ([#11384](https://github.com/nocobase/nocobase/pull/11384))
