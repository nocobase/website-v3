### 🎉 New Features

- **[Agents]** Preserve quota-limited work on its original Runner and resume the original session when quota recovers. ([#11372](https://github.com/nocobase/nocobase/pull/11372))
- **[Languages]** Add Russian and Korean to the agents, projects, releases, knowledge and other core plugins, and correct mistranslated terms such as "issue" and "executor" in their other languages. ([#11379](https://github.com/nocobase/nocobase/pull/11379))
- **[App foundation]** Discover application features and extensions in System settings, inspect their configuration, and use Agent setup guidance alongside database browsing. ([#11383](https://github.com/nocobase/nocobase/pull/11383))

### 🚀 Improvements

- **[Authentication]** Configure password recovery through auth.passwordReset.mailer; move existing auth.email.mailer references directly to the new field. ([#11346](https://github.com/nocobase/nocobase/pull/11346))
- **[Permissions]** Reduce redundant database reads during permission checks and automatic ticket closure. ([#11357](https://github.com/nocobase/nocobase/pull/11357))
- **[Agents]**
  - A run history's agent filter can list only the agents that ran on that subject, including removed ones. ([#11367](https://github.com/nocobase/nocobase/pull/11367))
  - Runtime owners and administrators can clear a quota mark before its known reset time, and a mark lifts by itself when the same quota window reports quota left again. ([#11369](https://github.com/nocobase/nocobase/pull/11369))
  - Allow applications to keep fixed instructions first in independent agent sessions for better prompt cache reuse. ([#11371](https://github.com/nocobase/nocobase/pull/11371))
  - Share queued agent runs between runners in proportion to each runner's limit for the run's coding tool, so idler runners take the next run first. ([#11388](https://github.com/nocobase/nocobase/pull/11388))
- **[Release management]**
  - Show each shared app host once on the environments page as a capacity card linking to its running apps; the apps list shows each app's runtime state with why and filters by it, and an app's page mentions the host only when it affects that app. ([#11380](https://github.com/nocobase/nocobase/pull/11380))
  - Apps are listed and created on their environment's page, with each app's runtime state and a state filter; a shared host's card links to each environment's running apps. ([#11385](https://github.com/nocobase/nocobase/pull/11385))
- **[Projects]** Issue activity says "added a relation to" or "removed the relation to" for related issues, on both issues, instead of calling them dependencies. ([#11389](https://github.com/nocobase/nocobase/pull/11389))
- **[Realtime updates]** Configure application realtime brokers under `realtime.broker`, preserving the in-memory default and reporting legacy configuration paths with migration guidance. ([#11392](https://github.com/nocobase/nocobase/pull/11392))
- **[Server]** Standardize Concurrency, Jobs and Queue settings under `backends` and reject legacy or mixed configuration with migration guidance instead of silently falling back to local execution. ([#11393](https://github.com/nocobase/nocobase/pull/11393))

### 🐛 Bug Fixes

- **[Database]** Improve indexed sorting of non-nullable fields while preserving null ordering and pagination. ([#11356](https://github.com/nocobase/nocobase/pull/11356))
- **[App host]**
  - Keep preview admission stable when transient heap usage rises while preserving bounded Host rotation. ([#11359](https://github.com/nocobase/nocobase/pull/11359))
  - Keep shared application Hosts responsive with bounded archive work, live memory admission and recycling that protects active requests and deployments. ([#11373](https://github.com/nocobase/nocobase/pull/11373))
- **[Agents]**
  - Preserve refused chat messages for recovery and present a consistent next step for conversation problems. ([#11361](https://github.com/nocobase/nocobase/pull/11361))
  - Retry temporary repository access problems before starting an Agent and show the actual failure when preparation cannot recover. ([#11374](https://github.com/nocobase/nocobase/pull/11374))
  - Start a fresh agent session when switching between read-only and writable work, while keeping existing writable sessions reusable. ([#11377](https://github.com/nocobase/nocobase/pull/11377))
  - A conversation interrupted by a dropped connection recovers once it is idle and refreshed. ([#11381](https://github.com/nocobase/nocobase/pull/11381))
- **[App templates]**
  - Remove the floating annotation toolbar from newly generated Examples applications. ([#11366](https://github.com/nocobase/nocobase/pull/11366))
  - Applications in a language other than English no longer show "Loading application…" in English while they start. ([#11376](https://github.com/nocobase/nocobase/pull/11376))
- **[Release management]** Let release page descriptions use the available width while keeping page actions visible. ([#11368](https://github.com/nocobase/nocobase/pull/11368))
- **[Skills]** The UI component checker now flags native and shadcn Input date fields, and the Examples work calendar picks holiday dates from a calendar instead of the browser's native date picker. ([#11378](https://github.com/nocobase/nocobase/pull/11378))
- **[Agent runner]** Automatically recover runner services after unexpected termination while keeping explicit stops stopped and reporting failed update restarts. ([#11384](https://github.com/nocobase/nocobase/pull/11384))
