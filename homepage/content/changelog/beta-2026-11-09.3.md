### 🎉 New Features

- **[Skills]** Add Agent Skills for configuring and verifying multi-instance applications and shared Redis backends. ([#11397](https://github.com/nocobase/nocobase/pull/11397))
- **[App foundation]** Add a `foundation.scanOnStart` setting that stops App Foundation from scanning at application start, and turn it off for test applications so tests start and close faster. ([#11403](https://github.com/nocobase/nocobase/pull/11403))

### 🚀 Improvements

- **[App templates]** Improve Database explorer browsing and mobile page spacing, and move Features and extensions into System settings with configurable access permissions. ([#11386](https://github.com/nocobase/nocobase/pull/11386))
