### 🎉 New Features

- **[Agents]** People can choose whether their runs go to their personal runners or to shared runners first; the other kind still takes a run about a second later when the preferred kind cannot. ([#11408](https://github.com/nocobase/nocobase/pull/11408))
- **[Agent runner]** Runners install `@nocobase/*` packages from the default registry and use NocoBase's private registry, with the token the application keeps, only when a project declares it or a package is missing elsewhere. ([#11415](https://github.com/nocobase/nocobase/pull/11415))
- **[App templates]** After a create, edit or delete, related lists, details, cards and counts in template applications show the new data the next time they are visible. ([#11417](https://github.com/nocobase/nocobase/pull/11417))
- **[Server]**
  - Support coordinated database tasks across multiple named connections, scoped module CLI registration and reliable cleanup of stopped deployments. ([#11418](https://github.com/nocobase/nocobase/pull/11418))
  - Support required database preparation hooks and report preparation failures, with fresh runs resetting every selected database before any migration or Seed begins. ([#11456](https://github.com/nocobase/nocobase/pull/11456))

### 🚀 Improvements

- **[Notifications]** Notification templates open in a drawer with a shareable address, are grouped by category with a compact filter bar, show translated names instead of technical identifiers, and preview in the interface language. ([#11462](https://github.com/nocobase/nocobase/pull/11462))
- **[CLI]** Support scoped portal packages in App CLI registration and package management. ([#11464](https://github.com/nocobase/nocobase/pull/11464))
- **[Create app]** Create multi-portal applications with a template alias and guidance for authenticated commercial registry access. ([#11466](https://github.com/nocobase/nocobase/pull/11466))

### 🐛 Bug Fixes

- **[Interface]**
  - Keep the agent chat panel's input above the soft keyboard on phones. ([#11409](https://github.com/nocobase/nocobase/pull/11409))
  - The notification logs block installs with `shadcn add` again, gives the source column the space, formats dates in the application language, follows the theme's status colors, can hide its own heading when used as a tab, and adds Korean and Russian. ([#11459](https://github.com/nocobase/nocobase/pull/11459))
- **[Agents]** Let agents confirm whether their current run starts an independent tool session before reviewing a change. ([#11416](https://github.com/nocobase/nocobase/pull/11416))
- **[App templates]** Keep the application's tab icon visible when the browser or system uses a dark theme. ([#11463](https://github.com/nocobase/nocobase/pull/11463))
