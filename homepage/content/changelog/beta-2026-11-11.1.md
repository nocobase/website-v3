### 🎉 New Features

- **[Agents]** Show Claude quota windows and let runtime owners pause new work at a chosen usage threshold ([#11483](https://github.com/nocobase/nocobase/pull/11483))

### 🚀 Improvements

- **[Skills]** Applications built with the development Skill now get phone-ready pages on first delivery, and the templates' data table can show records as cards on phones. ([#11402](https://github.com/nocobase/nocobase/pull/11402))
- **[Files]** Configure attachment upload limits per storage disk, with consistent size hints and validation for tasks, comments and Agent conversations. ([#11460](https://github.com/nocobase/nocobase/pull/11460))
- **[Knowledge base]** Applications can turn off knowledge semantic indexing, which removes its settings, routes and permission; the Knowledge indexing permission is now translated and grouped. ([#11471](https://github.com/nocobase/nocobase/pull/11471))
- **[Interface]** The UI Library's issue table shows statuses as shapes, an agent owner's avatar and the project, and can add columns, group rows and a compact phone layout. ([#11478](https://github.com/nocobase/nocobase/pull/11478))

### 🐛 Bug Fixes

- **[Agents]**
  - Hide agent runs and transcripts when their subjects are not visible to the reader. ([#11470](https://github.com/nocobase/nocobase/pull/11470))
  - A message sent while an agent is still answering joins its queue instead of being refused as busy, and a run that fails while being prepared shows why without reloading. ([#11481](https://github.com/nocobase/nocobase/pull/11481))
- **[Agent runner]** Read native Claude user settings during model discovery and user, project and local settings during conversations so configured providers and model aliases work in the runner. ([#11480](https://github.com/nocobase/nocobase/pull/11480))
- **[Demo mode]** Keep a demo visitor's language choice in their own browser instead of saving it to the shared demo account. ([#11486](https://github.com/nocobase/nocobase/pull/11486))
