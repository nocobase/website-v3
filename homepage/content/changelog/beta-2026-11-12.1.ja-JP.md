### 🎉 新機能

- **[サーバー]** プラグインが、アプリケーションの ID プロバイダーを置き換えずに、アプリケーションローカルな ID 生成を提供できるようになりました。同期的な生成と、解決済みのサービス参照はそのまま維持されます。 ([#11489](https://github.com/nocobase/nocobase/pull/11489))
- **[アプリ作成]** ルートの Main アプリケーション、個別にデプロイされる子アプリケーション、同期された開発・マイグレーション・デプロイ用の Skills を備えたマルチアプリプロジェクトを作成できるようになりました。 ([#11497](https://github.com/nocobase/nocobase/pull/11497))

### 🚀 改善

- **[ユーザー]** 招待メールは、招待時に選んだ 1 つの言語で作成されるようになりました。件名と有効期限もその言語で表示され、サインアップページもその言語で開きます。 ([#11482](https://github.com/nocobase/nocobase/pull/11482))
- **[Skills]** 新規ページとテンプレートページのテーブル行アクションを、行末の統一された「⋮」メニューにまとめました。アクション列の見出しと固定列はなくなりました。 ([#11484](https://github.com/nocobase/nocobase/pull/11484))
- **[Agent]** ランタイム一覧に、各コーディングツールのクォータ使用量と、使い切ったクォータがリセットされる時刻を表示するようにしました。バージョン列には Latest または Upgradable のみを表示します。 ([#11494](https://github.com/nocobase/nocobase/pull/11494))
- **[プロジェクト]**
  - 大規模なプロジェクトのバックログのうち一部だけを担当しているユーザーについて、タスクのリマインダーの更新を速くしました。 ([#11502](https://github.com/nocobase/nocobase/pull/11502))
  - 表示される親のコンテキストと依存関係の件数を維持したまま、プロジェクトタスクのグループ化処理を減らしました。 ([#11503](https://github.com/nocobase/nocobase/pull/11503))
- **[ナレッジベース]** ドキュメントの表示範囲とアーカイブ件数を維持したまま、より少ないクエリでナレッジスペースのディレクトリを読み込むようにしました。 ([#11506](https://github.com/nocobase/nocobase/pull/11506))
- **[アプリテンプレート]** Main のみのマルチアプリテンプレートとシナリオ用 Skills を Pro に移し、子アプリケーションはデプロイアーカイブで提供するようにしました。 ([#11511](https://github.com/nocobase/nocobase/pull/11511))

### 🐛 不具合修正

- **[デモモード]** System settings でカテゴリーとモジュールが同じパスの下にネストされているアプリケーションに Demo Mode を登録すると、アプリケーションが空白になる問題を修正しました。 ([#11455](https://github.com/nocobase/nocobase/pull/11455))
- **[メール]** IMAP の同期と添付ファイルのダウンロードを高速化し、検証中にメールボックスが変更されても処理を続けられるようにしました。 ([#11490](https://github.com/nocobase/nocobase/pull/11490))
- **[Agent]** ランタイムのクォータ設定と空の状態の表示をわかりやすくし、閲覧者にもしきい値が見えるようにし、クォータ期間を読みやすい単位で表示するようにしました。 ([#11493](https://github.com/nocobase/nocobase/pull/11493))
- **[ユーザー]** 自動サインインがオフの状態で登録した後、登録ページに空のフォームではなく、申請が送信されたことを表示するようにしました。 ([#11495](https://github.com/nocobase/nocobase/pull/11495))
- **[CLI]** 無関係なサンプルアプリケーションをコンパイルせずにアプリケーションをビルドするようにし、コンパイラーのデフォルトのヒープサイズを拡大しました。 ([#11508](https://github.com/nocobase/nocobase/pull/11508))
- **[アプリ作成]** スコープ付きの NocoBase レジストリを選択できるようにしました。従来の --registry オプションは、移行ガイダンスとともに引き続き利用できます。 ([#11512](https://github.com/nocobase/nocobase/pull/11512))
