### 🎉 新特性

- **[质量]** {{edition:enterprise}} 展示项目场景覆盖率与全量回归结果，支持通过自然语言发起质量计划，并提供更清晰的分析和质量报告。
- **[项目记忆]** Agent 会把学到的经验作为项目记忆保存在各仓库中，随 PR 一起评审，并在新的「项目记忆」页面展示；知识库只保存人自己写和上传的内容，Agent 只读。
- **[知识库]** 上传者或任务负责人确认后，可将任务原始附件存入知识库，不发通知、不打断任务。

### 🚀 优化

- **[Agent]** 统一 Agent 侧边面板的本机与 Runner Agent 模式，支持查看附带上下文，并通过对话新建任务、按需切换手动填写。

### 🐛 修复

- **[Git]**
  - 部署在子路径下的 GitLab（如 `https://host/gitlab`）现在可用于连接、合并请求链接、登录授权和智能体的 `glab`。
  - 修复安装在个人账号上的 GitHub App 新建项目仓库失败的问题，并提供明确的权限和访问失败提示。
- **[Agent]**
  - 明确提示缺少的项目经理配置并提供权限允许的入口；新建项目成功后，初始化任务可阻塞等待配置完成。
  - 手动停止 Agent 运行后阻塞任务，等待人的新指示再继续。
