### 🎉 新機能

- **[Agent]** Runtimes list available models by tool instead of creating an agent for every one reported, and let an administrator create one, clean up unused discoveries, and see clearer error reasons.

### 🚀 改善

- **[品質]** {{edition:enterprise}} Create and discuss quality plans in My Agent, follow native analysis and execution, and inspect clear coverage and quality reports with reliable result archiving.

### 🐛 不具合修正

- **[品質]** {{edition:enterprise}}
  - Continue quality testing automatically after preflight approval, with explicit pause and resume when execution should wait.
  - Keep quality plans aligned with native task progress using six clear states, and check current business requirements before reusing old map expectations.
- **[プロジェクトメモリー]** Agents write project memories in the language the repository's rules set, or English when there are none, instead of following the task's language.
