### 🎉 New Features

- **[Agents]** Runtimes list available models by tool instead of creating an agent for every one reported, and let an administrator create one, clean up unused discoveries, and see clearer error reasons.

### 🚀 Improvements

- **[Quality]** {{edition:enterprise}} Create and discuss quality plans in My Agent, follow native analysis and execution, and inspect clear coverage and quality reports with reliable result archiving.

### 🐛 Bug Fixes

- **[Quality]** {{edition:enterprise}}
  - Continue quality testing automatically after preflight approval, with explicit pause and resume when execution should wait.
  - Keep quality plans aligned with native task progress using six clear states, and check current business requirements before reusing old map expectations.
- **[Project memory]** Agents write project memories in the language the repository's rules set, or English when there are none, instead of following the task's language.
