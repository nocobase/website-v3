### 🎉 新特性

- **[Agent]** 运行环境按工具列出可用模型，不再为每个上报的模型建 Agent；管理员可以手动创建、清理无用发现项，并看到更清楚的检测失败原因。

### 🚀 优化

- **[质量]** {{edition:enterprise}} 通过我的 Agent 创建和讨论质量计划，沿用原生分析与执行流程，查看清晰的覆盖分析、质量报告及准确归档的验证结果。

### 🐛 修复

- **[质量]** {{edition:enterprise}}
  - 前置分析审核通过后自动继续测试，明确暂不执行时可暂停并在之后恢复。
  - 质量计划统一为六种状态并跟随原生任务变化，生成计划前核对当前业务要求，避免沿用过时的功能地图预期。
- **[项目记忆]** Agent 写项目记忆时按仓库规定的语言书写，仓库没有规定时用英文，不再跟随任务的语言。
