### 🎉 新特性

- **[我的会话]** 在我的会话中管理 Runner Agent 对话和关联任务，并在输入框中保留历史更换 Agent
- **[发布]** 接入现有 CI，在统一发布页查看项目预览、测试环境和生产版本，并获取部署指引

### 🚀 优化

- **[任务]** 任务表格中将执行人列替换为项目列，显示任务所属项目名称。
- **[Agent]** 将界面上的「项目经理」统一改为「调度 Agent」，升级时保留自定义名称。
- **[Studio]**
  - 隔离演示访问者的语言和主题偏好，并统一拦截演示环境不支持的操作。
  - 优化演示项目的中英文任务、简短标签和会话安排，并使用内置团队角色。

### 🐛 修复

- **[发布]**
  - 修复发布流水线加载失败和预览标题与其他列重叠的问题
  - 发布列表中的长项目名现在会省略显示，尚未上线的版本也会清楚标记。
- **[我的会话]**
  - 执行机回复提醒归入「我的会话」，不再重复进入收件箱。
  - 通过回复区的呼吸圆点和醒目稳定的发送与停止按钮显示 Runner 工作状态。
  - 删除打开的当前或归档会话后，我的会话将停留在新会话入口。
  - 关联任务恢复执行后结清会话中的对应提问，保持会话等待标记和计数一致。
  - 避免重复播报委派任务的等待卡片，同时保留新 PR 的通知。
  - 在 Runner 当前回复中统一显示恢复状态，提供清晰的重新连接和刷新操作，并适配窄屏。
- **[Agent]**
  - 发送消息时才确认对话 Agent 切换，只为最终选择记录一条提示。
  - 执行机对话中的 Agent 现在可以代主人关注和取消关注任务。
- **[文件]** Markdown 附件预览正文使用居中舒适阅读宽度和更大的正文字号。
- **[任务]**
  - 任务列表的已完成分组显示全部已完成任务，并可分页加载更早的任务。
  - 减少 Lead Agent 重复评论，在任务对话中折叠内部交接，同时保留人的请求和交付报告。
