### 🎉 新特性

- **[发布]** 按仓库 tag 判断任务发布状态，并在仓库设置中配置版本线。

### 🚀 优化

- **[任务]**
  - 在数据库中分页读取已完成任务历史，并保留准确的分组和数量。
  - 减少浏览器多标签页中任务和提醒的重复请求。
- **[质量]** {{edition:enterprise}} 统一对话式质量计划、多轮报告、质量跟进与定时执行，完善列表分页和独立测试环境指引。
- **[发布]** 默认折叠还没有版本的项目并记住展开偏好，精简项目列表，将版本号和待发布任务数量放在同一行。

### 🐛 修复

- **[预览]** 预览卡片直接显示初始管理员账号和密码，生成的密码保留到手动清除或应用删除。
- **[任务]** 「仅对话」保留执行和评审 Agent 的结论及运行记录，并独立折叠 Lead Agent 的交接。
- **[发布]**
  - 项目发布以主仓库为准，并在版本读取期间显示加载状态。
  - 支持分叉 tag 与可编辑默认分支比较，并可在没有测试环境时选择分支最新提交或手动提交发布。
  - 将部署指引移到测试栏，并精简测试环境空状态。
