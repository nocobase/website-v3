### 🎉 新特性

- **[Agent]** 在执行机 Agent 对话中选择并保存推理强度，并查看每轮对话使用的强度。

### 🚀 优化

- **[任务]** 任务卡片改用轻量批量读取，实时更新只刷新相关任务。

### 🐛 修复

- **[发布]** 将上传的应用构建包统一称为制品，并保留“版本”指代 Git tag。
- **[质量]** {{edition:enterprise}}
  - 修复质量页面刷新和短暂读取失败时的闪动，并保留报告分页及折叠状态。
  - 按完整、部分和缺失断言映射展示已有测试覆盖率，并保留历史报告证据。
  - 统一质量缺陷登记方式，确保缺陷正确关联计划并接续我的 Agent 讨论。
  - 质量跟进按来源计划展示实际发现轮次，避免同轮多个检查点重复计数，并支持分页查看。
- **[我的会话]** “我的 Agent”消息中含长哈希、URL 或无空格英文时，现在会在气泡内换行，不再裁掉每行开头。
- **[项目]** 未关联仓库的卡片改为提示先关联 Git 连接，不再显示未生效的检查方式。
- **[预览]** 演示数据中检查已通过的 PR 现在有可直接打开的预览，不再显示“等待检查通过”。
- **[任务]** 任务表格变窄时保留任务标题，标签和 Agent 状态不再与状态列重叠。
