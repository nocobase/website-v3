### 🎉 新特性

- **[质量]** {{edition:enterprise}} 保留 Bug 复现截图，并在质量跟进抽屉直接展示精确关联的图片。
- **[Agent]** 执行机对话可选择项目代码，更换 Agent 时保留本地工作，无法应用推理设置时使用工具默认值并给出明确说明。

### 🚀 优化

- **[任务]**
  - 减少任务进度和预览状态加载时的重复读取。
  - 减少任务详情和分组子项的读取查询，并保持关联快照和继续运行提示即时更新。
  - 统一英文界面的 issue 术语。
- **[Studio]** 演示环境中每个账号的“我的任务”都有 Agent 正在处理的任务，“我的会话”也包含 Runner Agent 会话。
- **[部署]** Redis Jobs 现在需要商业插件 `@nocobase/app-plugin-jobs-redis` 并显式声明 `adapter: redis`，且必须移除所有生效的 `agents.vectors` 配置，否则应用无法启动。
- **[我的会话]** 减少执行机会话更新时的网络请求，并在打开归档时才读取归档会话。
- **[Agent]** Runner 对话仅在任务受阻、等待验收或交出任务运行彻底失败时发送通知。
- **[运行环境]** 演示站点的运行环境显示为在线，Agent 也相应显示为可用。
- **[质量]** {{edition:enterprise}}
  - 质量计划详情页以计划标题开头，不再显示列表页的标题和项目选择器。
  - 质量计划的设置从页头按钮移到计划的「设置」标签页，布局与项目设置一致。
  - 质量计划列表点击整行即可进入计划详情，不再单独显示「查看」操作列。

### 🐛 修复

- **[Agent]**
  - 执行机运行记录支持翻页、准确总数和对话名称，并统一状态与额度标签的尺寸和间距。
  - 自动会话附件随页面标题更新。
  - 仅在执行机准备项目工作区时显示准备代码，复用工作区时显示启动 Agent。
- **[我的会话]**
  - 手机对话统一使用展开任务列表和整屏详情，导航靠左、编号与操作靠右，并可直接返回保留草稿的原对话。
  - 关联任务完成或取消后，自动结清会话中对应的旧确认。
  - 让 Runner 对话控件相邻排列，避免手机上的 Agent、项目选择框与其他按钮重叠。
  - 窗口较窄时优先显示会话列表而不是详情，Runner Agent 和 My Agent 的表现保持一致。
- **[任务]**
  - 减少任务、发布和会话的重复请求，并保持打开的讨论已读及任务切换稳定。
  - 修复窄屏下执行机长报错撑宽任务详情的问题。
- **[质量]** {{edition:enterprise}} 支持通过 Runner Agent 创建和讨论质量计划，并在 Runner Agent 与 My Agent 之间选择可用 Agent 和回落。
- **[Studio]** 在异步更新时保留项目选择、及时显示撤销后的任务状态、保持展开的对话、任务分页的点击、Runner 回复结束后的发送按钮、输入框的项目列表和评论定位，删除的任务不再阻塞 Agent 工作，并保留启动截止行为。
