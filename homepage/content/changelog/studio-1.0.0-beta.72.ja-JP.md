### 🚀 改善

- **[品質]** {{edition:enterprise}}
  - Quality plan reports now show Download detailed report and View issue at the top right, beside Retest.
  - Quality plan, follow-up and standard pages now use the same header, toolbar, table and pagination layout as the project and member pages.
  - Quality plan pages now open on the Report tab and use the same header, tabs and Ask Agent button style as project pages.
  - Quality pages now use the same headers, status tags and list styles as project pages, and plan objectives no longer show Markdown symbols in the list.
  - A quality plan's goal and report are laid out like a project's overview, and the goal shows its Markdown formatted.
  - A quality follow-up's detail shows its task number, project and status the way a task page does.

### 🐛 不具合修正

- **[品質]** {{edition:enterprise}} Ask before leaving a quality plan's settings with unsaved changes, and hide the unused list toolbar on old historical result links.
