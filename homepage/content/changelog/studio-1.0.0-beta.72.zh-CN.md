### 🚀 优化

- **[质量]** {{edition:enterprise}}
  - 质量计划报告页的「下载详细报告」和「查看任务」按钮移到报告右上方，与「再次测试」并列。
  - 质量计划、质量跟进和验收标准页面的页头、工具栏、表格和分页与项目、成员页面保持一致。
  - 质量计划详情改为默认打开「报告」标签，页头、标签页和「与 Agent 讨论」按钮样式与项目详情一致。
  - 质量模块页面的页头、状态标签和列表样式与项目页面保持一致，计划列表中的目标不再显示 Markdown 符号。
  - 质量计划的目标和报告改为与项目概览一致的卡片样式，目标中的 Markdown 正常渲染。
  - 质量后续事项的详情抽屉按任务详情的方式显示任务编号、项目和状态。

### 🐛 修复

- **[质量]** {{edition:enterprise}} 质量计划设置有未保存修改时，离开前先确认；旧的历史结果链接不再显示无用的列表工具栏。
