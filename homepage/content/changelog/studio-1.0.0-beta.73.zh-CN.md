### 🎉 新特性

- **[部署]** 找回密码、成员邀请和邮件通知可使用同一份发件配置。
- **[成员和角色]** 接受邀请时可选填写用户名，并可用它登录。
- **[Agent]** 执行机支持使用 DeepSeek Harness 作为编码工具。

### 🚀 优化

- **[质量]** {{edition:enterprise}}
  - 质量计划的「后续任务」改用任务列表展示，按状态分组，支持搜索、筛选和排序，标题旁显示类型标签。
  - 测试规范改为与成员页一致的可搜索列表，项目规范可在弹窗中新建、编辑和删除。
  - 质量跟进页改用与项目任务相同的任务列表展示，按状态分组，并显示跟进类型和来源计划。
  - 「质量跟进」更名为「质量任务」，「验收标准」更名为「测试规范」，质量任务详情不再显示内部模板字样。
  - 质量计划与报告默认执行三个检查维度，并为 NocoBase 3 项目提供测试目录建议。
  - 下线测试规范模块，质量计划按已确认目标和内置检查维度执行。
  - 质量任务直接进入原生任务详情，并隐藏已删除或无权查看的任务。
  - 质量讨论使用原生 Agent 草稿，由用户主动发送消息。
  - 将测试计划任务入口文案改为“查看进展”。
  - 质量计划目标在单张卡片中完整展开，并省略没有内容的可选章节。
  - 质量报告检查点随所属测试任务阶段显示状态，并统一状态标签配色。
  - 通过原始 Markdown 附件预览质量报告并直接下载。
  - 在开发分组中直接进入质量，旧质量任务链接自动跳转到对应计划或原生任务。
  - 支持使用原生任务权限和执行流程创建无项目质量计划。
  - 质量报告概览按通过率、覆盖率、复用、后续任务顺序展示。
  - 在质量计划页头显示测试总轮次和最新测试任务负责人。
  - 隐藏质量计划后续任务的项目列，为任务标题腾出更多空间。
  - 隐藏完整报告尚未提交的提示，报告可用时显示“查看完整报告”入口。
- **[我的会话]**
  - 页面和 Agent 面板统一对话头部与详情，普通入口先开列表，任务入口仍直开对话。
  - 说明执行机对话的等待原因，选好新 Agent 后再撤回重发，并统一输入框提示。
  - 我的会话和侧边 Agent 面板的样子和交互保持一致，并根据可用宽度自动调整布局。
- **[任务]** 在任务详情和列表中显示正在等待完成的前置任务。

### 🐛 修复

- **[质量]** {{edition:enterprise}}
  - 质量测试登记的缺陷和待确认任务，说明顶部不再显示内部标记。
  - 质量计划的列表项正确显示格式，内置测试规范随界面语言显示，无权限者打开新建链接时直接看到无权限提示，不再在保存时才被拒绝。
  - 键入或粘贴验收标准标题时，完整保留超过建议 200 字符的内容。
  - 质量计划和验收标准的并发修改统一返回 HTTP 409，便于调用方识别版本冲突。
  - 阻止已删除的质量计划启动、再次测试或修改，并在详情中标明已删除。
  - 当前质量计划轮次未结束时，禁止再次启动测试轮次。
  - 将仅保存的质量计划显示为“未开始”，并提供开始测试与恢复已删除计划的操作。
  - 质量任务详情中无证据、说明或来源计划时隐藏对应区块。
  - 质量计划保留清晰格式并区分各段含义，同时继续省略没有内容的可选章节。
- **[任务]**
  - 删除任务成功后关闭确认框，并刷新任务列表、计数和选中详情。
  - 操作或实时更新后，任务立即移动到当前分组，并保持选中任务的详情打开。
  - 打开新建任务后，在我的任务中搜索时保持搜索框焦点。
- **[我的会话]**
  - 显示 Agent 额度用完及恢复时间，支持切换可用 Agent，并提供清晰的切换执行机入口。
  - 手机端 Runner 与我的 Agent 会话中按回车换行，点击发送按钮发送消息。
- **[发布]** 在发布列表中悬停项目名可查看完整名称。
- **[Agent]**
  - 明确提示 Agent 评论限流，继续时只启动最新暂存，并在人的新指示后丢弃旧派工。
  - 允许 Agent 运行按执行人权限使用命令，同时保留人工决定边界并保护当前运行的评论归属。
- **[团队对话]** Runner 安静运行时显示活动时间，停止并续接对话时排队消息只保留一条。
- **[Git]** 避免仓库名大小写不同导致任务重复关联同一 PR，并显示代码平台返回的仓库名称。
