### 🎉 新特性

- **[授权]** {{edition:professional}} Studio 需要授权 Key 才能使用：在授权弹窗或「设置 › 授权」里粘贴 Key，授权页显示授权公司和可用的版本更新。
- **[质量]** {{edition:enterprise}}
  - 浏览项目质量与发布摘要、打开分类计划，并追溯质量证据的原始报告。
  - 支持准备内置质量计划，并从可编辑模板创建自定义计划。
  - 展示报告执行时间、未覆盖需求及有来源依据的项目质量事实。
  - 新项目自动为每日测试和发布测试开启定时；没有可测范围时记为「无测试范围」，不派 Agent，也不进待验收。
  - 按项目维度和原生任务组织质量测试，提供可读证据报告、实时进度与关联后续任务。
- **[Agent]**
  - 在我的会话和 Agent 面板中，将 Runner 对话以只读快照分享给指定用户。
  - Agent 额度用完时保留进度并阻塞任务，恢复后续跑原会话，也可主动更换 Agent 或执行机接手。
- **[多语言]** Studio 新增繁体中文、日语、西班牙语、法语、德语、葡萄牙语、印尼语、越南语、俄语和韩语界面，语言菜单以各语言自己的写法显示名称。

### 🚀 优化

- **[质量]** {{edition:enterprise}}
  - 补充功能与专题质量模板及对应测试方法。
  - 同一测试计划可在之前的轮次仍进行时启动独立的新轮次。
  - 跨质量计划复用已确认问题并保留取消决定，后续任务按计划显示来源。
  - 允许质量 Agent 判断不完整的测试材料，并在模板变化后保留计划访问与分类。
  - 在统一质量工作区查看项目和全部计划的真实测试结果，内置计划首次使用时才创建，并保留后续配置与报告历史。
  - 专题测试按权限、性能、安全、UX、浏览器兼容的顺序显示。
  - 测试首页展示各项目每日测试的最近结果，以及进行中、待验收、阻塞的测试轮次数，并逐行加载项目概况。
  - 每轮质量测试归触发它的人负责，定时轮次沿用上一轮负责人，计划详情显示每轮负责人。
  - 大型项目的质量首页和项目质量页打开更快。
  - 项目质量页简化为内置计划与自定义计划，顶部显示每日测试与发布质量，列表不再放操作按钮，计划详情页提供首次测试引导。
  - 测试通过但缺少自动化保障时不再自动创建补自动化任务，报告结论用一句话说明缺少自动化保障的检查点数量。
- **[Agent]**
  - Runner 对话详情中的关联任务改为与 My Agent 相同的样式。
  - Lead 和独立评审使用带有界交接信息的新会话，每个派工步骤结束仅唤醒 Lead 一次。
  - 允许任务和对话 Agent 在所代表用户的应用权限范围内上传构建制品，并在排查日志中记录运行身份。
  - 将 Lead 和独立评审新会话的固定指令前置，提高提示缓存复用机会。
  - 有空闲运行环境时发消息不再闪现等待提示；运行环境额度用完时，对话除了改选 Agent，也可以更换运行环境。
- **[我的会话]**
  - 统一会话列表行样式，并为 Runner Agent 的每个任务显示独立状态分段。
  - Agent 在会话中创建的任务只在会话的任务列表卡片中显示一次，不再在回复下方重复显示。
  - Runner 对话不再为关联任务的进展插入卡片或自动唤醒 Agent。
  - Runner Agent 会话列表的项目筛选改为与 My Agent 相同的紧凑菜单，并与状态筛选位于同一行。
  - 「我的会话」和 Agent 面板只显示 Runner Agent；My Agent 已隐藏，原有链接会打开 Runner 会话。
- **[预览]** 显示预览部署的排队与取消状态，取消后停止忙碌且不再自动重试。
- **[任务]** 任务有多个 PR 时，「需要你」只显示项目经理请你合并的那一个，按钮写明仓库与编号。
- **[运行环境]** 执行机所有者和管理员可以清除已知重置时间的额度标记，同一窗口上报额度恢复后标记自动解除，对应提醒同时撤销；提醒说明可提前清除标记。
- **[发布]** 托管环境页为每个共享应用宿主显示一张容量卡片，可按环境查看运行中的应用；应用改在环境详情页查看和创建，并显示运行状态。

### 🐛 修复

- **[评论]**
  - 修复回复中粘贴链接后继续输入文字或空格仍被包含在链接中的问题。
  - 手机上在任务的评论框或回复框按回车会换行，点发送按钮才发出。
- **[Agent]**
  - Runner Agent 创建的任务会停在待办，由人手动启动。
  - 保留并重发因运行环境不兼容而被拒的问题，并在全页、面板和手机上统一显示对话问题的下一步。
  - GitHub 临时故障时自动恢复 Agent 准备，并在任务运行和 Runner 会话中显示清晰的仓库访问与恢复提示。
  - Agent 在只读与可写工作间切换时开启新会话，同时保留已有可写会话的复用。
  - 实现步骤完成验证与交接后释放运行名额，远程 CI 继续异步执行，并保留各来源验证及最终验收要求。
  - 连接中断后，对话提示会说明发生了什么；点「刷新」会显示进度，对话同步后提示消失；可能仍会送达的消息不会被放回输入框导致重复发送。
- **[我的会话]**
  - Runner 对话的 Agent 只在你明确要求时才改代码，否则先建议建任务来做。
  - 会话运行准备失败并重试时，现在会如实说明，不再提示在等待空闲运行环境；最终失败时会显示具体原因。
  - 将文件拖放到会话输入框后，「松开即可添加文件」遮罩会随即消失。
- **[API 密钥]** API 密钥表格不再被撑破：过长的名称、描述和权限会截断显示，悬停可查看全文。
- **[预览]**
  - 后台 Studio 预览停止轮询以释放容量，返回页面时补齐待处理信息。
  - PR 是否部署预览环境改由任务的「不需要预览环境」开关决定，下次 CI 运行即生效；任务页会显示未发布预览的实际原因。
  - 预览共享托管服务重启时返回可重试响应，并说明预览为何等待启动。
- **[多语言]** 刷新、跨浏览器和切换账户时保持语言偏好一致。
- **[发布]**
  - 从发布通知打开版本时默认筛选通知所属项目的任务，支持切换全部有权查看的项目，并区分历史通知数量与当前数量。
  - 托管环境说明换行时保持“部署指引”链接完整显示。
- **[质量]** {{edition:enterprise}}
  - 项目测试计划摘要最多显示两行，鼠标悬停可查看全文，避免长目标撑高列表。
  - 在手机和平板上以清晰的卡片显示质量测试计划，不再出现表格文字重叠。
  - 修复 PostgreSQL 环境升级质量功能后 Studio 无法启动的问题
- **[任务]**
  - 在较窄的任务预览中，进度说明不再被挤成竖排，开始与交接按钮改为显示在其下方。
  - 任务详情显示筛选范围内的完整总数，支持跨页访问全部任务，并展开导航选中的折叠分组。
  - 任务运行记录的 Agent 筛选只列出在该任务上运行过的 Agent，已删除的 Agent 仍显示原名。
  - 在任务评论和回复的 @ 候选中将 Lead Agent 固定排第一，并允许发送对它的提及。
  - 手机上任务标题栏的关注星标与旁边图标按钮一致，「需要你」的按钮在自身行内滑动，不再撑宽页面。
  - 在任务的其他标签页发送评论或点击「回复」后，会自动切回「动态」并显示该评论或回复框。
  - 任务动态中添加或移除关联时，双方任务都显示「添加了关联」「移除了关联」，不再显示为「添加了依赖」。
- **[提醒]**
  - 回到可见页面时，提醒计数只刷新一次。
  - Studio 标签页在后台时也能及时发现新的等待事项和提及，弹出桌面通知并播放提示音；偏好设置会说明当前浏览器无法使用桌面通知的原因。
- **[界面]** 修复侧栏折叠后，设置中「返回」「标签」等被分组标题遮挡的图标难以点击的问题。
- **[技能]** 内置开发规范要求只停止本次运行启动的进程，避免误停 Runner。
