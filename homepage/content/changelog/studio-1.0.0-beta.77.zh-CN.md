### 🎉 新特性

- **[质量]** {{edition:enterprise}} EE 角色和 API 密钥可独立控制质量测试的查看、发起和设置，升级及版本切换保留原有授权。
- **[授权]** {{edition:professional}} 更新弹窗会显示最新版本的更新内容。
- **[知识库]** 在“我的会话”中，Agent 可以建议把你发送的文件保存到知识库，你可以在消息旁将其保存到系统或项目知识库，或者拒绝。

### 🚀 优化

- **[任务]**
  - 支持按存储盘配置任务、评论和 Agent 对话的附件大小上限。
  - 待规划的任务打开时默认显示「说明」，其他任务显示「动态」，切换到另一个任务时重新决定。
- **[质量]** {{edition:enterprise}}
  - 项目质量测试在场景清单定稿后同时开始所有维度，每个维度完成时及时唤醒项目经理，把慢测试登记为每次测试一个耗时优化任务，并在功能维度显示各测试套件的耗时以及最慢的文件和用例。
  - 性能测试现在通过可配置登录实测选定页面，并按统一标准填写报告。
  - 质量设置的测试时间改为在输入框内直接修改，不再弹出浏览器时间面板；有未保存的修改时显示保存栏，离开前会提醒。
  - 质量页的跟进任务改用任务页的列表：按状态分组、未完成的在前，可按优先级、最近命中或命中次数排序并保留在地址中，手机上也能看到标题和状态。
- **[知识库]** 角色不再提供无用的“知识库索引”权限，Studio 也不再提供知识库索引设置接口。

### 🐛 修复

- **[Agent]** 向看不到任务的人隐藏私有项目任务的运行记录和对话。
- **[质量]** {{edition:enterprise}} 能查看项目但不能查看其任务的人，在质量页面不再看到测试、场景和跟进任务。
- **[我的会话]** Agent 仍在工作时发送的消息会进入队列，不再因会话忙碌而发送失败。
- **[成员和角色]** 成员首次打开 Studio 时保留管理员已设置的角色。
