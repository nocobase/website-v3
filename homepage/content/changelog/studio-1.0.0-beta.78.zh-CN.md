### 🎉 新特性

- **[质量]** {{edition:enterprise}} 性能测试现在会测量全部页面及其调用的接口，以指标和趋势显示页面体积、请求数、每次请求的 SQL 条数和响应时间，并把超出阈值的页面和接口登记为任务。

### 🚀 优化

- **[质量]** {{edition:enterprise}}
  - 质量页的跟进任务列表改为每次加载 50 条并通过「加载更多」继续显示，与任务列表一致，不再分页显示 20 条。
  - 在质量指标页点击某个维度的指标行或趋势点，会在当前页的抽屉中打开该维度详情，与概览一致。
  - 维度报告合并同因结果、去掉场景大表、只列本维度附件、按语言使用标点，附件可在页内预览。
  - 质量测试开测前检查执行机的浏览器和环境，环境问题改派重试，不再登记为跟进任务。
  - 性能测试现在会补充缺失数据、登记 seed 后续任务，并利用生成的实体清单解析页面和接口参数。
  - 安全测试支持密钥和登录态接口扫描及可复用测试数据，生产依赖存在严重或高危漏洞时正确显示失败。
  - 维度报告合成一份，短句分层：先写要处理的，再按缺少的条件分组列出没测的，最后写范围，明细默认折叠。
- **[任务]**
  - 任务运行记录在模型旁显示每次运行所在的运行环境。
  - 加快项目任务分组加载，保留可见父任务上下文、进度更新和分页。
- **[提醒]**
  - 缩短任务提醒和导航计数的刷新时间，保留全部待处理事项。
  - 任务提醒只推送给与改动相关的人，Studio 重启后也不会再漏掉提醒。
- **[知识库]** 加快多项目知识目录加载，保留可见空间和文档数量。
- **[Git]** 新关联仓库默认使用 Agent 自检，已有仓库保持原检查来源。
- **[发布]** 环境应用列表按页加载，并保持筛选、总数和访问范围一致。

### 🐛 修复

- **[质量]** {{edition:enterprise}}
  - 质量测试技能统一使用英文，性能报告按测试选定的语言输出。
  - 权限仅统计标记场景，审查问题与越权扫描单独计数，场景详情显示缺陷维度。
  - 质量指标显示测试套件的实际耗时，并标明缺少实测时间时的累计耗时。
  - 没有可测试的业务任务时，显示正确的质量测试提示。
  - 质量测试中断后可接续已提交的场景批次，性能检查无需等待功能维度完成。
  - 扫描结果采集失败时保留 ZAP 告警和认证复查结果。
  - 质量报告现在清楚标注各组计数、显示开发依赖公告，并统一测试摘要和维度标题的结论用语。
- **[登录]** 注册后会跳到登录页，并提示用户登录。
- **[我的会话]**
  - 在 Runner 回复中显示生成的文件，并使用统一的预览和下载操作。
  - Runner 对话中，有空闲执行机即将领取消息时不再闪现等待提示；只有 30 秒内仍无执行机领取时才显示中性提示。
  - 在 Runner 会话之间切换时始终停在最新消息处，任务卡片随对应的更早消息一起出现，关联任务很多的会话在流式输出时不再卡顿。
- **[Git]** 使用 GitHub App 连接的 Agent 可以在任务的每个仓库开 PR，不再只限第一个仓库。
- **[发布]** 预览 Host 默认使用 85% 堆准入阈值、320 MiB 启动预留和 70% 主动轮换线。
