### 🎉 New Features

- **[Issues]** Issues have a requester who confirms requirements and accepts delivery before the owner merges, with decisions available in the inbox.

### 🚀 Improvements

- **[Issues]**
  - A task now shows everything waiting on you in one "Needs you" block, each thing once, with its buttons in place; quota waits no longer offer Reply and are explained in the interface language.
  - Filter My issues and Issues by requester and remember the Requester column separately on each page.

### 🐛 Bug Fixes

- **[API keys]** Support API key names up to 100 characters when configuring repository CI and creating or rotating keys.
