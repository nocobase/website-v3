### 🎉 新特性

- **[任务]** 任务支持需求负责人确认需求并先行验收，确认、验收和问答可在收件箱处理，再由开发负责人合并。

### 🚀 优化

- **[任务]**
  - 任务页把所有需要你处理的事项合并到一个「需要你」区块，每件事只出现一次并可直接操作；额度挂起不再显示「回复」，并按界面语言说明。
  - 我的任务和所有任务支持按需求负责人筛选，并分别记住需求负责人列的显示选择。

### 🐛 修复

- **[API 密钥]** 配置仓库 CI、创建或轮换 API 密钥时支持最长 100 个字符的名称。
