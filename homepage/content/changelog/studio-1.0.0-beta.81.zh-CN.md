### 🎉 新特性

- **[Studio]**
  - 按配置的日期范围导出脱敏后的 Studio 和运行环境日志，查看实时进度并复制失败请求 ID。
  - 支持使用人大金仓 KingbaseES 作为 Studio 的应用数据库
- **[质量]** {{edition:enterprise}}
  - 维度报告新增场景、自动化测试和代码问题页签，首行显示场景覆盖率、通过率和自动化率。
  - 质量维度可提交 gitleaks、ZAP、Semgrep 等扫描工具的 SARIF 文件，并在新的「扫描发现」页签中列出发现。
  - 权限维度根据权限引擎的结果显示「越权检查」页签和越权卡片，并为每个越权登记缺陷。
- **[Agent]** 支持在已有 Runner 对话中选择执行机并二次确认，发送下一条消息时生效。

### 🚀 优化

- **[任务]** 我的任务待办数字按任务去重计算，包含等待处理的子任务与关注任务。
- **[质量]** {{edition:enterprise}}
  - 维度报告改为页签显示，性能报告列出全部已测页面和接口，显示页面标题并与上次测试对比。
  - 功能质量测试会针对默认值、边界和异常路径设计检查点，并把不明确的业务规则登记为待确认问题。
  - 质量测试按用户目标拆分核心场景，检查页面和写操作是否都有场景覆盖，并为每日测试和发布测试按优先级选取回归场景。
  - 质量卡片、维度报告和测试总结显示同一结论，卡片明细最多三行，测试进行中即可看到已完成维度的结果和各维度进度。
  - 安全报告新增「依赖漏洞」和「检查项」页签，生产和开发依赖分开列出，未取得结论的扫描在总览中直接标明。
  - 质量测试登记的缺陷和待确认按模板书写，任务里直接显示截图，标题带测试语言的类型前缀；测试不再为场景更新和补自动化单独建任务。
  - 质量测试不再在固定时间到达时停止准备测试数据或安全主动扫描，各维度说明记录每个阶段的耗时。
  - 权限测试对所有接口检查被拒绝的写入和应允许的身份，并把每项检查作为 JUnit 用例输出。
- **[发布]** 支持通过环境变量配置预览发布包的校验与解压超时时间。

### 🐛 修复

- **[任务]** 在任务评论框或回复框聚焦后立即输入 @，Lead Agent 和其他 Agent 加载完成后会立即出现在候选中，不再只有成员。
- **[登录]** 访客登录后返回原访问页面，并保留筛选条件和锚点。
- **[账户]** 修复账号设置中第一次点击「修改密码」没有反应的问题。
- **[我的会话]** 手机上悬浮的「我的会话」按钮不再遮挡任务评论、回复和退回输入框的发送按钮，并可上下拖动避开内容。
- **[技能]** 修复内置技能引导 Agent 使用无关 CI 仓库的问题，并保留自定义技能
- **[Git]** 允许外部 CI 仓库使用仓库 CI Key 通过 `nb-studio check report` 上报检查结果。
