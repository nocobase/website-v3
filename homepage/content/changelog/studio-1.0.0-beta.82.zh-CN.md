### 🎉 新特性

- **[Studio]** 新增 NocoBase Studio CE 镜像，无需 License Key，不含需求负责人和 Quality。

### 🚀 优化

- **[设置]** 日志导出会显示服务端日志的实时进度，同时收集执行机日志，执行机目录按名称命名，并去掉了按任务筛选。
- **[质量]** {{edition:enterprise}}
  - 权限卡片和权限概览统一按接口统计：显示通过的接口数和计划接口数，分段条区分越权、未验证、通过和未测接口，并列出受影响的模块。
  - 自动化用例失败按原因分析，只有产品缺陷登记缺陷任务；功能维度卡片和报告按原因显示失败。
  - 代码质量测试改用工具统计重复率、认知复杂度、未使用代码和依赖循环，只对新增结果判定达标，在卡片、指标页和新的「指标」页签显示指标和覆盖率，每个项目只保留一个代码质量清理任务。
  - 各维度报告和交付报告显示各阶段耗时，交付报告的维度结果与卡片口径一致，性能报告显示测试数据规模。
- **[技能]** 内置工作规范适用于各类项目，Agent 可直接完成任务范围内的数据改动，无需额外请示。
- **[任务]** 任务、Agent 回复、文件预览和质量报告中的链接统一在新标签页打开，页内标题锚点除外。

### 🐛 修复

- **[部署环境]** 匿名调用不能再发起部署；预览和流水线列表不再显示、也不能搜索查看者无权阅读的 PR 和任务标题。
- **[质量]** {{edition:enterprise}}
  - 维度详情的报告页签只出现一次、不再先显示占位页签，加载时不再显示其他维度的问题，报告加载也快了很多。
  - 权限测试只为越权登记缺陷；有权限的身份被拒时显示为未验证并按原因分组，不再登记缺陷。
  - 功能测试在整个项目的测试中更新过时场景，在按任务的测试中将其列为未验证，不为过时预期登记缺陷。
  - 质量测试的耗时在最后一个维度提交时固定，任务交付后改回进行中再交付不再让耗时变长。
- **[Agent]** 对话中的 Agent 在提问或创建任务后不再重复整段回复。
- **[发布]** 各版本更新日志按「质量」和「任务流程」展示适用的功能改动。
