### 🎉 新機能

- **[Git]** Git connections can fetch and push over SSH with a deploy key Studio generates, and switch between HTTPS and SSH at any time.

### 🚀 改善

- **[Agent]** Show OpenCode and Pi models with their provider, and show what the coding tool said when a run fails.
- **[スキル]** Project skill settings no longer say that online agents skip skill scripts.
- **[タスク]** The task detail's pull request line stays above "Needs you", keeps Account while the preview sleeps, and ends with the pull requests' mark, which opens Code and previews.

### 🐛 不具合修正

- **[ライセンス]** {{edition:professional}} The update badge no longer appears when the new versions bring no changes to this edition of Studio.
- **[プロジェクト]** On a phone, the selected project tab stays in view when tabs such as Releases or Quality appear after the page opens.
