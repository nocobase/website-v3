### 🚀 Improvements

- **[Quality]** {{edition:enterprise}} The quality overview opens faster: each block appears as soon as its own data arrives, and a running test refreshes only what changed.
- **[Agents]** The Lead Agent is no longer woken by self-check failures while a delegated agent is still working on the task; it reviews the result when the step ends.
