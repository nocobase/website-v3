### 🎉 新特性

- **[任务]**
  - 在自己负责的已完成或已取消任务下评论并 @ Lead Agent，任务会回到进行中，由 Lead Agent 处理这条评论。
  - 项目新增「工作流程」页，展示任务在人与智能体之间的流转；每个任务通过「流程」芯片选用一个流程，内置流程和质量技能不可修改；存在独立需求方时，需求方和负责人都不能单方面替换对方。
- **[质量]** {{edition:enterprise}} 质量配置可为每日、发布、项目测试设置负责人，新的后续任务归测试任务当前负责人，无需接手和确认需求。
- **[Git]** 多个 Git 连接现在可以共用一把 SSH 密钥：在编辑连接对话框里选择或新建，在 设置 › Git 新的「SSH 密钥」标签页管理；SSH 连接点「测试 SSH 连接」通过即可使用。

### 🚀 优化

- **[Agent]** Studio 保留原有的聊天、收件箱、设置页面和 Agent 页面访问权限，并默认关闭框架的存储管理、应用托管模型服务和系统密钥、成员密钥和密钥规则管理接口。
- **[质量]** {{edition:enterprise}}
  - 质量测试发现慢测试时，更新项目里未完成的测试耗时优化任务，不再重复新建；代码质量清理任务的标题日期也跟随最近一次测试。
  - 没有问题的质量维度打开详情时默认显示总览，问题页签为空时提示「本次没有发现问题」。
  - 质量维度详情的「问题」页签默认按严重程度从高到低排序。
  - 项目的「质量」页签直接显示该项目的质量内容（概览、测试任务、核心场景、跟进任务、指标、设置和运行测试），不再只是跳转到质量页的入口。
- **[发布]** 界面为日语时，更新对话框显示日语版发布说明；每次发布也会生成日语版发布说明和更新日志。
- **[任务]**
  - 执行记录中被重试过的运行显示各次尝试的合计时长和尝试次数，并逐次显示每次尝试的时长和结束原因。
  - 在任务列表或独立详情页打开任务时，可以更快看到当前进度。
- **[项目]** 项目详情页的「发布」标签移到「质量」之后。
- **[技能]** Agent 可以再次在唤醒它的人有权限时读取和修改技能库；内置技能在负责人未要求英文时接受其他语言的界面截图。

### 🐛 修复

- **[质量]** {{edition:enterprise}}
  - 质量页面加载时不再跳动，概览加载更快。
  - 修复先按任务编号登记跟进任务、后提交结果时，失败场景的问题记录没有关联任务的问题。
- **[运行环境]** 修复运行环境因工作区子模块残留正常 linked worktree 元数据而误报检出失败的问题，精简 Git 错误展示，并在运行临时目录权限轻微偏移时自动修复。
- **[Agent]** 恢复原来的 Agent、运行环境、技能和用量页面；页面中角色无权查看的部分改为显示无权查看提示，不再报错。
- **[Git]** 升级或切换到 HTTPS 后，连接会自动解除 SSH 密钥绑定，管理员可以删除闲置密钥
