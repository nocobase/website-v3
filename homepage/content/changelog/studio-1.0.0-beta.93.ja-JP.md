### 🚀 改善

- **[プロジェクト]** プロジェクトの既定の開発担当者を、設定ではなく「ワークフロー」タブの開発担当者ステップで表示・変更できるようにしました。すべてのメンバーが確認できます。
- **[タスク]** タスクのステージバーに担当者の引き継ぎ・開始と、依頼者が受け入れる場合の担当者によるマージを表示し、プロジェクトの「ワークフロー」タブと一致させます。依頼者が要件を確認する前は、タスクをレビュー待ちにできません。
- **[品質]** {{edition:enterprise}}
  - 品質概要のテスト実行記録に表示しきれないテストがあるとき、下部に件数を示し、テストタスクですべてを表示できるようにしました。
  - タスク単位の品質テストでは変更されたテストファイルだけを実行し、各評価項目の詳細に主な所要時間とその理由を記載します。
  - コアシナリオ一覧の「新規」タグをシナリオ名の後ろに表示し、「今回の結果」には結果のみを表示します。

### 🐛 不具合修正

- **[リリース]** 再デプロイ時にサンプルデータ設定の変更が反映され、未実行のサンプルデータを読み込めるようになりました。
- **[品質]** {{edition:enterprise}} 品質概要のメトリクスのテスト選択メニューで、最新テストの番号が折り返されず、日時も完全に表示されるようにしました。
- **[Agent]** オフラインやイントラネット環境での OpenCode の起動およびモデル検出の失敗を修正し、`opencode.json` / `opencode.jsonc` に設定された API キーを認識するようにしました。モデル検出に失敗した場合は、ランタイム詳細のツール状態の横に原因を確認できる警告を表示します。
