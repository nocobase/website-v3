### 🚀 优化

- **[项目]** 在项目「工作流程」页的开发负责人节点上显示并修改默认开发负责人，所有成员都能看到，不再放在设置里。
- **[任务]** 任务阶段条补齐开发负责人的接手/启动和合并环节，与项目「工作流程」页保持一致；需求负责人确认需求前，任务不能直接提交待验收。
- **[质量]** {{edition:enterprise}}
  - 质量概览的测试执行记录有未显示的测试时，底部提示还有多少个，并可跳转到测试任务查看全部。
  - 按任务测的质量测试只运行有改动的测试文件，各维度说明列出主要耗时及原因。
  - 核心场景列表的「新增」标签改为显示在场景标题之后，「本次结果」只显示测试结果。

### 🐛 修复

- **[发布]** 后续部署可加载尚未执行的示例数据，重新部署时会应用示例数据开关的变更。
- **[质量]** {{edition:enterprise}} 质量概览指标区块的测试下拉框中，最新一次测试的编号不再折行，日期完整显示。
- **[Agent]** 修复 OpenCode 在离线或内网环境下启动及模型检测失败的问题，支持识别 `opencode.json` / `opencode.jsonc` 中配置的 API Key，并在运行环境详情页的工具状态旁显示模型检测失败提醒与具体原因。
