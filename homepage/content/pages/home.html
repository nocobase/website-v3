FAQ

常见问题Questions & answers

NocoBase 和 Vibe Coding 有什么区别？How is NocoBase different from vibe coding?

Vibe Coding 让软件开发更加高效，但当项目涉及复杂业务、多人协作和长期迭代时，仅靠 AI 生成代码还不够，还需要可靠的应用底座、规范的开发流程和全自动的质量测试。NocoBase 并不是 Vibe Coding 的替代品，而是通过应用底座（Core）提供现成的基础能力和统一架构，通过工作台（Studio）按工作流程加载常驻技能、做好不同模型交叉评审和关键节点把关，并调用业界成熟测试工具从功能、冒烟、权限、安全、性能、代码质量和 UX 多维度实测、自动闭环修复，把 AI 写出的代码变成可靠的业务系统。Vibe coding speeds up writing code, but complex enterprise systems also need a reliable foundation, structured workflows, and automated quality testing. NocoBase doesn’t replace vibe coding—Core supplies ready-made building blocks and one consistent architecture, while Studio runs every issue through workflows with pinned skills, cross-model review, and human gates, plus parallel multi-dimensional testing with proven tools and closed-loop fixes to turn AI-written code into reliable business systems.

和低代码平台有什么区别？How is it different from low-code platforms?

两者在开发速度、能力上限和运行方式上有本质区别：低代码平台仍靠人逐页拖拽配置，遇到复杂规则或深度定制往往碰壁，且应用绑定平台运行；NocoBase 由 Agent 直接编写标准源码并可 24 小时并行推进，开发速度更快、几乎没有能力上限，代码保存在企业自己的 Git 仓库里且发布后独立运行，同时业务系统天然内置业务 Agent 主动分担日常事务。Low-code platforms still rely on manual drag-and-drop configuration, hit limits on complex rules or custom UIs, and tie apps to the platform. With NocoBase, agents write standard source code in parallel—delivering much faster with virtually no capability ceiling. Your code lives in your own Git repo, runs standalone, and comes with built-in business agents for daily operations.

已经在用 Claude Code、Codex、Cursor，还需要 NocoBase 吗？We already use Claude Code, Codex, or Cursor—why NocoBase?

需要。这些编码工具解决的是写代码的速度，NocoBase 解决的是如何持续交付可靠的业务系统。你可以先直接用你手头的编码工具从 Core 起步——权限、认证、流程、数据库等 30 多项基础能力开箱就绪，Agent 按统一规范只写业务，架构不会漂移；当项目变多、需要多人协作、业务参与验收和全自动质量把关时，再接入 Studio 把这些编码工具组建成受控的 Agent 团队。Yes. Coding tools solve how fast code gets written; NocoBase solves how to deliver reliable business systems continuously. Start directly with Core using your existing coding tools—30+ building blocks come ready out of the box so agents focus on business logic without architecture drift. When projects multiply and you need team collaboration, business sign-off, and automated quality gates, add Studio to coordinate them as one governed agent team.

不懂代码的业务人员能用吗？Can non-technical business users participate?

能。业务人员可以在电脑或手机上直接提需求、回答 Agent 的问题，在测试环境里用真实数据验收；环境、分支、测试和发布，由 Agent 和工作台承担。Yes. Business users describe requirements, answer agent questions, and verify results with real data in a test environment on desktop or mobile. Agents and Studio handle branches, environments, testing, and releases.

AI 写的系统可靠吗？Are systems built by AI reliable enough for production?

权限、审批等核心基础能力由应用底座提供，不由 AI 从零生成。每个改动都按工作流程经过自动检查和不同模型交叉评审才交给人验收；项目级质量测试用成熟工具覆盖功能、冒烟、权限、安全、性能、代码质量和 UX 并自动闭环修复；经人批准才发布到生产，出了问题可以回滚。Permissions, approvals, and other critical modules come from Core rather than being generated from scratch. Every change runs through a structured workflow with automated checks and cross-model review before human sign-off. Project-level quality testing uses proven tools across features, smoke checks, permissions, security, performance, code quality, and UX with closed-loop fixes, and releases require approval with instant rollback.

数据会不会传到外部？Does our data leave our infrastructure?

NocoBase 部署在企业自己的服务器上，支持纯内网。Agent 工作时，相关代码会发给企业选择的模型服务；需要时可以使用本地部署的模型。NocoBase runs on your own servers, including air-gapped networks. While agents work, relevant code is sent only to the model provider you choose, and you can use locally hosted models whenever required.
