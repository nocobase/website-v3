FAQ

常见问题Questions & answers

NocoBase 和 Vibe Coding 有什么区别？How is NocoBase different from vibe coding?

Vibe Coding 让软件开发更加高效，但当项目涉及复杂业务、多人协作和长期迭代时，仅靠 AI 生成代码还不够。NocoBase 并不是 Vibe Coding 的替代品，而是通过应用底座（Core）提供现成的基础能力和统一规范，通过工作台（Studio）完成多 Agent 调度、质量把关和经验沉淀，把 AI 写出的代码变成可靠的业务系统。Vibe coding speeds up writing code, but complex enterprise systems also need a reliable foundation, consistent architecture, and governance. NocoBase doesn’t replace vibe coding—Core supplies ready-made building blocks and standards, while Studio coordinates agent teams, quality checks, and team know-how to turn AI-written code into reliable business systems.

和低代码平台有什么区别？How is it different from low-code platforms?

低代码平台靠人拖拽配置，复杂需求要绕开平台限制，应用依附于平台。NocoBase 由 Agent 编写真正的源码，复杂规则、系统集成、定制界面都能做；代码在企业自己的仓库里，应用独立运行。Low-code platforms rely on manual drag-and-drop configuration, hit platform ceilings on complex requirements, and lock apps to the platform. With NocoBase, agents write real source code for complex rules, integrations, and custom UIs—stored in your own repo and running independently.

已经在用 Claude Code、Codex、Cursor，还需要 NocoBase 吗？We already use Claude Code, Codex, or Cursor—why NocoBase?

需要。这些编码工具解决的是一个人怎样用 AI 写代码，NocoBase 解决的是企业怎样用它们持续交付可靠的业务系统。工作台把这些编码工具组成一支 Agent 团队统一调度、按流程把关；应用底座提供现成的基础能力和统一规范，编码工具在上面只写业务，换人、换模型架构也不会漂移。Coding tools solve how one developer writes code with AI; NocoBase solves how a team delivers reliable business systems continuously. Studio orchestrates those tools as a governed agent team, and Core gives them ready-made building blocks and consistent standards so the architecture never drifts.

不懂代码的业务人员能用吗？Can non-technical business users participate?

能。业务人员可以在电脑或手机上直接提需求、回答 Agent 的问题，在测试环境里用真实数据验收；环境、分支、测试和发布，由 Agent 和工作台承担。Yes. Business users describe requirements, answer agent questions, and verify results with real data in a test environment on desktop or mobile. Agents and Studio handle branches, environments, testing, and releases.

AI 写的系统可靠吗？Are systems built by AI reliable enough for production?

权限、审批等核心基础能力由应用底座提供，不由 AI 从零生成。每个改动都经过自动测试和不同模型交叉评审，才交给人验收；经人批准才发布到生产，出了问题可以回滚。Permissions, approvals, and other critical modules come from Core rather than being generated from scratch. Every change passes automated tests and cross-model review before human verification, ships only after approval, and can be rolled back anytime.

数据会不会传到外部？Does our data leave our infrastructure?

NocoBase 部署在企业自己的服务器上，支持纯内网。Agent 工作时，相关代码会发给企业选择的模型服务；需要时可以使用本地部署的模型。NocoBase runs on your own servers, including air-gapped networks. While agents work, relevant code is sent only to the model provider you choose, and you can use locally hosted models whenever required.
