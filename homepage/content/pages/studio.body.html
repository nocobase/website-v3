NocoBase Studio

Agent 自主推进，团队掌控全局。Agents keep the work moving. Your team stays in control.

NocoBase Studio 是 NocoBase 的工作台。它把多台设备上的 Claude Code、Codex、OpenCode 等组建成一支 24 小时工作的 Agent 团队，按流程自主推进开发、测试和评审；人在电脑或手机上提需求、看进展、做决策。NocoBase Studio is the workbench for NocoBase. It brings Claude Code, Codex, and OpenCode across your devices into one 24/7 agent team that handles development, testing, and review by process, while people make requests, track progress, and decide from desktop or mobile.

把个人电脑和团队服务器上的编码工具统一接入工作台，由调度 Agent 自动分派任务，在独立环境里并行推进多个项目。Connect coding tools on laptops and team servers in one workbench. A coordinator assigns the work, and agents run in isolated environments across multiple projects around the clock.

多设备、多工具统一接入Many devices, any coding tool

统一接入个人电脑和服务器上的 Claude Code、Codex、OpenCode 等编码工具，不绑定单一模型或厂商，机器越多并发越高。Connect Claude Code, Codex, OpenCode, and others across laptops and servers with no vendor lock-in. Add machines to run more work in parallel.

调度 Agent 自动分派Automatic dispatch by specialty

调度 Agent 按每个 Agent 的专长分派设计、开发、测试和评审任务，不用人逐个盯着终端会话，验收始终由人把关。A coordinator assigns design, build, test, and review tasks by each agent’s strengths—no babysitting terminals, while people keep final sign-off.

独立环境并行推进Isolated parallel runs

每个任务在独立的分支、worktree 和测试环境里运行，互不干扰，24 小时同时推进多个项目和大量任务。Every issue runs in its own branch, worktree, and test environment so dozens of tasks move in parallel without colliding.

人机协作与决策Collaboration & decisions

随时随地，有理有据做决策。Clear decisions, anywhere.

业务人员在电脑或手机上直接提需求、看交付报告和可操作的测试环境并亲自验收；多人多项目的进展、周期和模型花费一目了然。Business teams submit requests and accept work from desktop or mobile with delivery reports and live test environments, while progress, cycle time, and model spend stay visible across every project.

进展、负荷与花费一目了然Progress, load, and spend in one place

流程与质量把关Process & quality

按流程推进，层层把关质量。Structured process, quality at every gate.

从需求、方案、开发、测试、评审到验收、上线，每一步由谁做、谁确认、交出什么都按流程执行，全程留痕。From request and design to build, test, review, acceptance, and release, every step has clear ownership, gates, and a complete audit trail.

  1. 1

    按项目选流程Right-sized workflow

    内置从简单到完整的多种流程，小改动走轻量流程，核心系统走严格流程，也可按企业制度自定义。Built-in workflows from lightweight to strict, or tailor your own to match your engineering standards.

  2. 2

    自动测试与交叉评审Tests & cross-model review

    每个改动先跑自动测试，再换另一家厂商的模型交叉评审；未通过自动返工重测，全过才交给人。Automated tests run first, followed by code review from a different model vendor; failures loop back automatically.

  3. 3

    业务与技术双重验收Dual sign-off

    业务人员在独立测试环境里做业务验收，技术负责人做技术验收，各把各的关。Business stakeholders verify behavior in a live preview while tech leads sign off on architecture and safety.

  4. 4

    质量计划与回归测试Quality plans & regression

    上线前按质量计划对系统做功能、权限、安全、性能和代码质量回归测试，每次发版心里有底。Run full regression across features, permissions, security, performance, and code quality before every release.

  5. 5

    审批上线与回滚Approved release & rollback

    经审批人批准才发布到生产环境，支持预发布验证与上线窗口；出了问题一键回滚到上一版本。Production deploys require approval, support release windows, and roll back cleanly to the last good release.
