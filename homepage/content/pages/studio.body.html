NocoBase Studio 是 NocoBase 的团队开发工作台。它把多台设备上的 Claude Code、Codex、OpenCode 等组建成一支 24 小时工作的 Agent 团队，按流程自主推进开发、测试和评审；人在电脑或手机上提需求、看进展、做决策。NocoBase Studio is the team development workbench for NocoBase. It brings Claude Code, Codex, and OpenCode across your devices into one 24/7 agent team that handles development, testing, and review by process, while people make requests, track progress, and decide from desktop or mobile.

Agent 团队Agent team

一支 24 小时工作的 Agent 团队。A 24/7 agent team.

把个人电脑和团队服务器上的编码工具统一接入工作台，由调度 Agent 自动分派任务，在独立环境里并行推进多个项目。Connect coding tools on laptops and team servers in one workbench. A coordinator assigns the work, and agents run in isolated environments across multiple projects around the clock.

多设备、多工具统一接入Many devices, any coding tool

统一接入个人电脑和服务器上的 Claude Code、Codex、OpenCode 等编码工具，不绑定单一模型或厂商，机器越多并发越高。Connect Claude Code, Codex, OpenCode, and others across laptops and servers with no vendor lock-in. Add machines to run more work in parallel.

调度 Agent 自动分派Automatic dispatch by specialty

调度 Agent 按每个 Agent 的专长分派设计、开发、测试和评审任务，不用人逐个盯着终端会话，验收始终由人把关。A coordinator assigns design, build, test, and review tasks by each agent’s strengths—no babysitting terminals, while people keep final sign-off.

独立环境并行推进Isolated parallel runs

每个任务在独立的分支、worktree 和测试环境里运行，互不干扰，24 小时同时推进多个项目和大量任务。Every issue runs in its own branch, worktree, and test environment so dozens of tasks move in parallel without colliding.

人机协作与决策Collaboration & decisions

随时随地，有理有据做决策。Clear decisions, anywhere.

业务人员在电脑或手机上直接提需求、看交付报告和可操作的测试环境并亲自验收；多人多项目的进展、周期和模型花费一目了然。Business teams submit requests and accept work from desktop or mobile with delivery reports and live test environments, while progress, cycle time, and model spend stay visible across every project.

进展、负荷与花费一目了然Progress, load, and spend in one place

工作流程Workflows

按流程推进，关键节点由人把关。Structured workflows, people at the gates.

同一项目可按任务选用精简流程、标准流程或自定义流程；常驻技能每次运行自动加载，每一步谁做、谁确认全程留痕。Match each issue to a simple, standard, or custom workflow with resident skills loaded on every run—keeping clear ownership, automatic rework loops, and a full audit trail.

多流程并存，支持自定义Built-in & custom workflows

社区版内置精简流程与标准流程，小改动快跑、核心改造走完整步骤；专业版支持多角色流程、自定义流程与权责规则。Community ships with simple and standard workflows; Professional adds multi-role workflows, custom steps, and configurable ownership rules.

清晰把关，退回自动闭环Clear gates & automatic rework

需求方确认、开发负责人启动，中间由 AI 完成方案、编码、换另一家模型只读评审并通过 CI 自动检查；验收退回自动回到 AI 执行阶段，各节点任务数一目了然。Requesters and tech leads own the start and finish while agents handle planning, coding, read-only review by another model, and automated CI checks in between—with rejections looping back automatically.

常驻技能自动生效，不可移除Pinned skills on every run

开发规范、评审分级标准与汇报格式作为常驻技能绑定到流程，按项目或仓库强制加载，搭配审批上线与一键回滚，确保规范落地不走样。Attach development, review-grading, and reporting rules as pinned skills that load automatically and cannot be dropped per issue, paired with approved releases and rollback.

角色分工Clear roles

业务人员提需求、做验收，技术负责人定规则、批准上线。Business teams own requirements and sign-off; tech leads own rules and releases.

业务人员不用懂代码，用业务语言说清规则、回答 Agent 追问，在测试环境里用真实数据验收；分支、测试、评审与部署由 Agent 和工作台承担。Business teams state rules in plain language and verify with real data in a test environment—branches, tests, reviews, and deploys are handled by agents and Studio.

质量管理Quality management

全自动质量测试，问题闭环修复。Automated quality testing, closed-loop fixes.

不靠 AI 读代码估算，而是调用业界成熟测试工具多机并行实测七个维度；测完自动生成报告，问题自动登记为跟进任务修复并复测。Proven testing tools run in parallel across seven dimensions instead of agents guessing from code—generating reports automatically and turning findings into follow-up issues that fix and retest in a closed loop.

成熟工具实测，标准可自定义Proven tools & custom standards

覆盖功能、冒烟、权限、安全、性能、代码质量和 UX，调用 Playwright、权限引擎、OWASP ZAP、gitleaks、Lighthouse、PostgreSQL 执行计划与 jscpd 等工具实测；内置业界标准并支持自定义阈值、技能和维度，缺条件标未验证不凑数。Covers features, smoke checks, permissions, security, performance, code quality, and UX with Playwright, a role-matrix engine, OWASP ZAP, gitleaks, Lighthouse, PostgreSQL EXPLAIN, and jscpd. Customize thresholds, skills, and dimensions; missing prerequisites stay clearly marked unverified.

四种触发、多机并行，无人值守Four triggers, parallel runners

每日测试、发布测试、项目测试和自定义测试共用一套引擎与标准；核心业务场景随项目演进沉淀在仓库中，由多台测试机按维度并行执行，全程无需值守。Daily, release, project, and custom runs share one engine and rule set. Core scenarios live in the repo and evolve with the product while multiple test machines execute dimensions in parallel.

自动出报告，问题闭环修复Auto reports & closed-loop fixes

维度报告自动汇总为交付报告；发现的缺陷、性能、安全漏洞和代码清理问题按原因合并登记为跟进任务，进入开发流程修复、评审并在下次测试复测，仅规则不明的交人拍板。Dimension reports roll up into one delivery report. Deduplicated defects, performance regressions, security findings, and cleanup items enter the dev workflow for agents to fix, review, and retest—leaving only ambiguous rules for people.
