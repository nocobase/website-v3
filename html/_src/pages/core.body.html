基础能力Building blocks

基础能力不用从头开发和验证。Proven building blocks, ready to use.

即使交给 AI，权限、工作流引擎、审批等底层模块从零开发，设计难度依然很高，边界情况多，维护工作量大。Core 提供现成的基础能力，由 NocoBase 持续维护和升级。Agent 只开发业务部分，需要开发和验证的代码大幅减少。Even with AI writing the code, permissions, workflow engines, and approvals are hard to design from scratch. They are full of edge cases and take a lot of work to maintain. Core provides ready-made building blocks, and NocoBase keeps maintaining and upgrading them. Agents build only the business logic, so there is far less code to write and verify.

架构和规范Architecture and standards

为 Agent 提供统一的架构和规范。One architecture, one set of standards.

换人、换模型甚至换会话，AI 都可能随机发挥，系统越来越难维护。Core 提供统一的项目结构和开发规范，系统在统一架构下长期稳定迭代。Switch developers, models, or even sessions, and the AI may improvise differently each time. The system gets harder and harder to maintain. Core provides one project structure and one set of development standards, so the system evolves steadily for years on a consistent architecture.

项目脚手架Project scaffolding

新建的应用自带统一的目录：页面、接口、表结构变更、测试各有固定位置，Core 的基础能力以包的形式引入。Every new app starts with the same layout. Pages, endpoints, schema changes, and tests each have a fixed place, and Core’s building blocks come in as packages.

架构规范Architecture standards

AGENTS.md 和技能写明业务代码放在哪里、哪些直接用现成能力、迁移和权限怎么写。AGENTS.md and the skills spell out where business code goes, what to take from Core, and how to write migrations and permission checks.

开发技能Development skills

技能随 Core 的包发布，安装依赖时同步到应用里。Claude Code、Codex 等编码工具读到的是同一套写法，换人、换模型也不变。Skills ship with Core’s packages and sync into the app on install. Claude Code, Codex, and other coding tools read the same playbook, so the approach holds as people and models change.
