有什么不一样What’s Different

不是在业务软件旁边加个聊天框，Not a chat box bolted onto business software. 而是给每个团队配一支有岗位的 Agent 团队。An agent team with real jobs, for every team.

很多业务软件都“加了 AI”：一个等你提问的助手。NocoBase Solutions 里的 Agent 是团队成员——有职责、有上岗时机、有权限边界、有绩效；而整个应用本身，也能交给 AI 继续改。Plenty of business software has “added AI”: an assistant that waits for your question. In NocoBase Solutions, agents are team members—with duties, triggers, permission boundaries, and a track record. And the app itself can be changed by AI, too.

先用起来，Use it first. 再按你的业务改。Then shape it to your business.

    部署即用Deploy and use

    改技能、规则与代码Change skills, rules, code

    方法变了就改技能；流程和字段变了，让 Agent 改代码。在 Studio 中安装、定制和发布，每次变更都经过检查。New method? Edit a skill. New process or fields? Have agents change the code. In Studio, install, customize, and release with every change checked.

    选择性跟进官方更新Take the updates you want
