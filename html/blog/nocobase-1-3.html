NocoBase 1.3：REST API 数据源、移动端 V2 和更多功能NocoBase 1.3: REST API data source, mobile v2, and more features

NocoBase 1.3 带来了 REST API 和 MSSQL 数据源、支持通过 URL 打开弹窗、动态配置字段组件、增强的移动端版本、企业微信认证、多对多数组、以及工作流中的日期计算节点等多项新功能。NocoBase 1.3 introduces REST API and MSSQL data sources, support for opening pop-ups via URL, dynamically configuring field components, enhanced mobile version, WeCom authentication, many-to-many arrays, and a new date calculation node in workflows.

发布日志Release Notes2024年8月29日Aug 29, 2024NocoBase teamNocoBase team

从 v1.3 开始，NocoBase 提供两个关键分支：main 和 next。

  • main 分支，beta 版本，专注于缺陷修复，确保为用户提供一个稳定的版本；
  • next 分支，alpha 版本，包含一些正式未发布的新特性，这个版本不稳定，适用于开发者或测试人员，用于提前体验新功能或进行兼容性测试。

重要变更

环境变量 DB_TIMEZONE 更改为 TZ

新增 TZ 环境变量，用于设置应用的时区，默认为操作系统时区。旧的 DB_TIMEZONE 仍保持兼容，但已废弃。

  • next branch (alpha version) contains some unreleased new features. This version is unstable and is intended for developers or testers to experience new features early or to conduct compatibility testing.

Important changes

Environment variable DB_TIMEZONE changed to TZ

The new TZ environment variable has been added to set the application's time zone, with the default being the operating system's time zone. The old DB_TIMEZONE remains compatible but is deprecated.
