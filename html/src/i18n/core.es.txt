074: Arquitectura y estándares
075: Una arquitectura, <span class="m">unos mismos estándares.</span>
076: Si cambian los desarrolladores, los modelos o incluso las sesiones, la IA puede improvisar de forma distinta cada vez, y el sistema se vuelve cada vez más difícil de mantener. Core ofrece una estructura de proyecto y unos estándares de desarrollo comunes, para que el sistema evolucione de forma estable durante años sobre una arquitectura coherente.
077: Estructura de proyecto
078: Cada app nueva empieza con la misma estructura. Páginas, endpoints, cambios de esquema y pruebas tienen un lugar fijo, y los componentes base de Core se incorporan como paquetes.
080: AGENTS.md y las skills indican dónde va el código de negocio, qué tomar de Core y cómo escribir las migraciones y las comprobaciones de permisos.
081: Skills de desarrollo
082: Las skills se publican con los paquetes de Core y se sincronizan en la app al instalar. Claude Code, Codex y otras herramientas de programación leen las mismas pautas, así que la forma de trabajar se mantiene aunque cambien las personas y los modelos.
