title: NocoBase 파트너 찾기 — 업무를 아는 파트너와 함께 시스템을 만들고 운영
description: NocoBase 파트너는 NocoBase 3, Studio, 각 업종의 업무를 잘 알고, 에이전트 팀을 이끌며 요구사항 정리, 개발, 검수, 오픈, 이후 유지보수까지 함께합니다. 납품한 코드는 귀사의 것입니다.
001: 업종을 아는 파트너를 찾아 <span class="m">시스템을 만들고 운영하세요.</span>
002: NocoBase 파트너는 NocoBase 3과 Studio를 잘 알고, 귀사의 업종에도 깊이 정통합니다. 에이전트 팀을 이끌고 요구사항 정리, 시스템 개발, 미리보기 검수, 오픈과 운영까지 함께합니다. 전 과정이 Studio에서 투명하게 보이며, 납품되는 소스 코드, 스킬, 지식 베이스는 100% 귀사의 것입니다.
003: 요구사항 제출
005: 파트너가 필요할 때
006: AI로 업무 시스템을 만들고 싶지만, 
007: 팀은 아직 준비되지 않았다.
008: 개발 인력 부족
009: 내부에 개발이나 납품 경험이 부족해, 전문 팀이 에이전트를 이끌고 안정적으로 완수해 주길 원할 때.
010: 빠른 오픈 필요
011: 업무는 기다려 주지 않으니, 기성 Solution이나 업종 템플릿에서 시작해 몇 주 안에 사용하고 싶을 때.
012: 복잡한 연동과 이전
013: ERP, OA, SSO, 기존 데이터베이스와 연동하거나, 기존 시스템·NocoBase 2에서 매끄럽게 이전해야 할 때.
014: 자체 팀 육성
015: 함께 만들며 배워, 내부 팀이 에이전트에게 요구사항을 주고 검수하고 배포하는 역량을 갖추게 하고 싶을 때.
016: 파트너가 하는 일
017: 첫 대화부터

019: 요구사항 정리와 아키텍처
020: 업무 프로세스를 정리하고, 기성 Solution과 Core 중 어디서 시작할지 정해 단계별로 오픈할 모듈로 나눕니다.
021: 맞춤 개발
022: Studio에서 에이전트 팀을 배정해 개발하고, 모든 변경은 테스트와 리뷰를 거쳐 미리보기 환경에서 귀사가 검수합니다.
023: 시스템 연동
024: ERP, CRM, OA, SSO, 업무용 메신저, 외부 데이터베이스와 연동하고, 권한은 서버 측에서 엄격히 통제합니다.
025: 데이터 이전
026: 스프레드시트, 기존 시스템, NocoBase 2에서 데이터를 이전하며, 이전 스크립트는 실제 데이터 미리보기 환경에서 먼저 검증합니다.
027: 현장 서비스
028: 귀사의 지역에서 방문 서비스: 배포, 문제 해결, 업무 부서와의 대면 요구사항 협의.
029: 운영과 지속적 개선
030: 셀프 호스팅 배포, 백업, 버전 업그레이드, 장애 대응을 맡아 지속적인 지원과 유지보수를 제공합니다.
031: 협업 방식

033: 업무 결정은 귀사가 내린다.
034: 프로젝트는 귀사의 Studio에서 바로 진행하거나, 파트너의 Studio에서 개발해 귀사의 저장소로 납품할 수 있습니다. 진행 상황, 막힌 지점, 오픈 시점이 모두 투명합니다.
035: 업무 설명
036: 귀사가 프로세스와 문제점을 설명하면, 파트너가 요구사항과 단계별 계획으로 정리합니다.
037: 방안 확정
038: 업무 규칙, 범위, 검수 기준은 귀사가 확정합니다.
039: 개발과 검사

041: 미리보기 검수
042: 미리보기 환경에서 직접 해 보고, 통과하면 오픈을 승인합니다.
043: 인수인계와 유지보수
044: 소스 코드, 스킬, 지식 베이스는 귀사의 저장소에 있으며, 이후 직접 수정하거나 계속 파트너에게 맡길 수 있습니다.

063: 파트너와 일하는 것과 NocoBase 본사와 직접 일하는 것은 무엇이 다른가요?
064: NocoBase 본사는 제품 기반, 상용 라이선스, 실전 검증을 제공하고, 파트너는 귀사의 지역과 업종에 깊이 들어가 맞춤 개발, 시스템 연동, 데이터 이전, 장기 유지보수를 일괄 제공합니다. 중점 프로젝트는 본사와 파트너가 공동으로 지원할 수도 있습니다.
065: 비용은 어떻게 되나요?
066: 구축과 유지보수 서비스는 파트너가 프로젝트, 모듈, 연간 유지보수 단위로 견적을 냅니다. NocoBase 상용 라이선스는 공식 사이트의 통일 가격이며, 파트너를 통해 함께 구매할 수 있습니다.
067: 납품된 코드는 누구의 것인가요?
068: 전적으로 귀사의 것입니다. 업무 로직은 모두 귀사 저장소의 깔끔한 소스 코드이며, 공통 기능은 NocoBase Core 플러그인이 제공합니다. 소스 코드, 스킬, 지식 베이스, 유지보수에 대한 권리와 책임은 계약에서 명확히 정합니다.
069: 나중에 파트너를 바꾸거나 내부 팀이 유지보수할 수 있나요?
070: 언제든 가능합니다. 시스템은 표준 NocoBase Core 위에 구축되고, 개발 규칙은 스킬에, 업무 맥락은 지식 베이스에 담겨 있어 어떤 팀이 맡아도 처음부터 헤맬 필요가 없습니다.
071: 요구사항 제출
072: 만들고 싶은 시스템을 알려 주시면 지역, 업종, 필요한 서비스에 맞는 파트너를 추천해 드립니다.
