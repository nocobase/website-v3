title: NocoBase Studio — Agent 自主推進，團隊掌控全局
description: NocoBase Studio 是人與 Agent 協同開發的治理平台。把 Claude Code、Codex、OpenCode 組成一支 Agent 團隊自主推進任務，進展一目了然，關鍵處由人做決策。
000: Agent 自主推進，<span class="m">團隊掌控全局。</span>
002: 線上體驗
004: 地端部署在企業自己的伺服器上
005: 支援 Claude Code、Codex 等數十種開發工具
006: 於商業版中提供
007: Agent 團隊
008: 一支持續推進的 <span class="m">Agent 團隊。</span>
009: Studio 接入多台機器上的 Agent 統一調度，24 小時同步推進多個專案和大量任務。
010: 接入多台機器上的 Agent
011: 個人電腦和團隊伺服器上的 Claude Code、Codex 等接入後，Studio 自動識別已登入的開發工具和模型。寫明每個 Agent 擅長什麼並啟用，它就加入 Agent 團隊。
012: 調度 Agent 分派工作
013: 調度 Agent 依每個 Agent 的專長分派設計、開發、測試、審查工作。它不寫程式碼、不合併程式碼，驗收始終由人來做。
014: 多個任務同時推進
015: 每個任務在自己的分支上開發，每次執行使用獨立的 worktree，多個任務同時推進、互不干擾。機器越多，能同時推進的任務越多。
016: 我的對話
017: 在 Studio 裡和自己電腦上的 Agent 對話，討論和釐清需求、記錄任務、追蹤進展。任務開始後，由調度 Agent 安排 Agent 團隊開發。
018: 進展
019: 各項進展<span class="m">一目了然。</span>
020: 專案進展、任務推進過程、Agent 工作負載和模型用量都清晰可見。每個任務做到哪裡、下一步做什麼，都一目了然。
021: 專案進展
022: 每個專案的進度，以及完成的任務、週期時間、Agent 完成占比和單一任務成本，都和上一週期對比。
023: 任務推進過程
024: 每個任務做到哪一步、哪個 Agent 在做、接下來做什麼，都顯示在任務的最上方。
025: Agent 工作負載和模型用量
026: 每台機器上的 Agent 在推進哪些任務，各個模型用了多少 token、花了多少錢，隨時可查。
027: 決策
028: 有憑有據<span class="m">做決策。</span>
030: 報告與清單
031: 交付時寫明做了什麼、怎樣驗證的，並附上逐條的驗收清單。
032: 截圖與預覽
033: 每個情境附上截圖；需要時開啟獨立的預覽環境，親自試一遍。
034: 通過或退回
035: 看完依據，通過或退回。退回時寫明原因，Agent 接著改。
036: 業務專家
037: 不懂程式的業務專家，也可以直接拍板。
038: 業務專家用業務語言提需求、回答 Agent 的提問，在預覽裡用真實資料驗收。環境、分支、測試和發布，由 Agent 和 Studio 承擔。
039: 技術負責人定規則、批准上線；業務專家定需求、負責驗收。
040: 交到人手上之前，Studio 組織檢查和審查。
041: 每次改動走同樣的流程：測試和程式碼審查都通過，才交給人驗收；經人批准，才發布到正式環境，出了問題可以回復。
042: 分支與 worktree
043: 每個任務有自己的分支，每次執行在獨立的 worktree 裡進行；分支上的 PR 自動關聯到任務。
044: 測試與審查
045: CI 跑檢查和測試，再換一個模型審查程式碼，優先用另一家廠商的模型。
046: 預覽驗收
047: 需要時為 PR 啟動獨立的預覽環境，供人試用驗收。
048: 合併發布
049: 驗收通過後合併，任務的 PR 全部合併後任務自動完成；發布到正式環境由人批准。
050: 回復
051: 出了問題，退回上一個版本。
053: 方法、經驗、知識<span class="m">累積在團隊裡。</span>
054: 需求背景、業務資料、專案經驗散落在不同電腦的不同對話裡，換人、換 Agent 就很難找到。Studio 用技能、知識庫和專案記憶累積方法與經驗，換人、換 Agent 都能順利交接。
055: 技能
056: 技能保存做事的方法。需求釐清、開發、審查、發布的做法寫成技能，分全域、專案、工作目錄三級，每次執行自動帶上。
057: 知識庫
058: 知識庫保存業務資料。需求文件、業務規則、合約範本等由人撰寫或上傳，Agent 工作時直接查閱。
059: 專案記憶
060: 專案記憶保存 Agent 自主學到的經驗，存在專案的儲存庫裡，隨任務的 PR 一起審查、合併，下次開工前先讀。
061: 開源與地端部署
062: 地端部署，<span class="m">程式碼和資料歸企業所有。</span>
070: Agent 寫的程式碼建在 NocoBase Core 上
