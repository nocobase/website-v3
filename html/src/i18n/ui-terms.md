# NocoCRM、NocoITAM 的界面用语

页面文案里提到产品界面上的菜单、页面、Agent 和功能时，用界面上的原名，读者对照产品能找到。产品界面只有简体中文和英文：

- **繁体中文**：用简体中文界面的说法，只换成繁体字（线索 → 線索、审批 → 審批、业务指导 → 業務指導），不换成别的台湾说法。这两页的界面示意图在繁体中文里也这样写（`crm.ui.zh-TW.json`、`itam.ui.zh-TW.json` 只换字形），和正文一致。
- **其他语言**：这些语言下产品显示英文界面，界面上的名称照英文原样写（首字母大小写照界面），一般描述照常翻译。

取自两个产品的界面文案：NocoCRM 的 `client/locales/crm/index.ts`，NocoITAM 的 `client/locales/en-US.ts` 与 `zh-CN.ts`。产品改了名称，这里跟着改。
