01

NocoBase

品牌表达21 字

AI + NocoBase，构建可靠的业务系统

定义66 字

NocoBase 是用 AI 持续开发和运行业务系统的开源平台。Agent 写代码、做执行，NocoBase 提供底座和治理能力，人来做决策。

标准介绍164 字

NocoBase 是用 AI 持续开发和运行业务系统的开源平台。Core 是应用底座，提供业务系统共用的基础能力和开发规范，Agent 在此基础上开发企业的业务需求；Studio 是人与 Agent 协同开发的治理平台，Agent 分工推进任务，人掌握进展，在关键处做决策。NocoBase 把 AI 的开发能力，转化为企业持续交付可靠业务系统的能力。

02

为什么需要 NocoBase

一句话理由24 字

AI 写代码很快，但构建可靠的业务系统依然不简单。

问题与方案

你的企业已经在用 AI 开发或者 Vibe Coding，代码写得很快，但新的问题随之出现。

  1. 01

    底层能力要从零建设

    问题

    即使交给 AI，权限、工作流引擎、审批等底层模块从零开发，设计难度依然很高，边界情况多，维护工作量大。

    方案Core

    Core 提供现成的基础能力，由 NocoBase 持续维护和升级。Agent 只开发业务部分，需要开发和验证的代码大幅减少。

  2. 02

    架构随机漂移，逐渐失控

    问题

    换人、换模型甚至换会话，AI 都可能随机发挥，系统越来越难维护。

    方案Core

    Core 提供统一的项目结构和开发规范，系统在统一架构下长期稳定迭代。

  3. 03

    并行任务很多，人确认不过来

    问题

    同时处理多个项目和任务，在多个终端和对话之间切换，Agent 交过来的改动也越来越多，人看不过来，又不敢放手。

    方案Studio

    Studio 统一调度 Agent 团队同时推进大量项目和任务，进展一目了然。需要人介入时，Agent 会附上报告、清单、截图，人可以有理有据做决策。

  4. 04

    知识和经验难以沉淀和共享

    问题

    需求背景、业务资料、项目经验散落在不同电脑的不同会话里，换人、换 Agent 就很难找到。

    方案Studio

    Studio 用技能、知识库和项目记忆沉淀方法和经验，换人、换 Agent 都能无障碍交接。

03

NocoBase Core

品牌表达19 字

让 Agent 专心写业务，底座已经就绪。

定义72 字

NocoBase Core 是 AI 开发和运行业务系统的开源应用底座。权限、流程、文件等基础能力现成可用，Agent 在统一架构上只开发企业自己的业务。

标准介绍143 字

NocoBase Core 是 AI 开发和运行业务系统的开源应用底座。它提供数据、权限、流程、文件、AI 接入等每个业务系统都需要的基础能力，以及统一的项目结构和开发规范。Agent 使用这些现成能力，只开发企业自己的业务部分。每个项目需要开发和验证的代码大幅减少，系统在统一架构下长期稳定迭代。

核心特色

  • 基础能力不用从头开发和验证

    Core 提供权限、流程、文件、通知等 20 多项基础能力，Agent 只专注于业务开发。

  • 为 Agent 提供统一的架构和规范

    Core 提供项目脚手架、架构规范和开发技能，换人、换模型，项目架构都能保持统一、受控。

  • 应用和数据归企业私有

    Core 开源免费，业务代码和数据都在企业自己的仓库和服务器上，模型和 Agent 也由企业自由选择。

04

NocoBase Studio

品牌表达17 字

Agent 自主推进，团队掌控全局。

定义92 字

NocoBase Studio 是人与 Agent 协同开发的治理平台。把 Claude Code、Codex、OpenCode 组成一支 Agent 团队自主推进任务，进展一目了然，关键处由人做决策。

标准介绍198 字

NocoBase Studio 是人与 Agent 协同开发的治理平台。个人电脑和团队服务器上的 Claude Code、Codex 等接入后，组成一支 Agent 团队，由调度 Agent 分派设计、开发、测试、评审工作，自主推进多个项目。每个任务做到哪里、下一步做什么，都一目了然。方法和经验沉淀在技能、知识库和项目记忆中，换人、换 Agent 都能无障碍交接。在每个关键处，Agent 会附上报告、截图，由人来做决策。

核心特色

  • 一支持续推进的 Agent 团队

    接入多台机器上的 Agent 统一调度，24 小时同步推进多个项目和大量任务。

  • 各项进展一目了然

    项目进展、任务推进过程、Agent 工作负荷和模型用量都清晰可见。

  • 有理有据做决策

    需要人做决策时，Agent 会附上详细的报告、清单、截图和建议，不懂代码的业务专家也可以直接拍板。

  • 方法、经验、知识沉淀在团队里

    技能保存做事的方法，知识库保存业务资料，项目记忆保存 Agent 自主学到的经验。换人、换 Agent 都能无障碍交接。

05

NocoBase Solution

品牌表达17 字

开源业务应用，AI 驱动，开箱即用。

定义68 字

NocoBase Solution 是由 Agent 驱动的、基于 Core 构建的一系列企业业务应用，Agent 做大部分执行工作，人只做关键决策。

标准介绍201 字

NocoBase Solution 是由 Agent 驱动的、基于 Core 构建的一系列企业业务应用。传统业务软件靠人来记录、流转和操作；在 Solution 里，大部分执行工作都由 Agent 完成，比如调研客户、起草邮件、核对资产台账、做内容增长、处理客户工单，遇到需要决策的事，Agent 附上详细依据交给负责人拍板。Solution 开源免费，可以直接安装使用，也可以让 Coding Agent 根据自己的业务需求定制。

核心特色

  • Agent 主动工作

    每个应用中内置很多业务 Agent，它们会按照规则主动承担大部分执行工作，比如核查退款、处理工单。

  • 人负责关键决策

    Agent 的工作成果会附上依据，关键决策必须由人来做。Agent 继承负责人的权限，保证数据安全。

  • 方便定制开发

    基于 NocoBase Core 开发，具备统一的架构和可靠的底座，可以让 Coding Agent 对它们进行定制开发。

  • 开源免费，开箱即用

    所有 Solution 均开源免费，部署在企业自己的服务器上，模型自由选择。

06

开源与私有部署

Core 和 Solution 开源免费；Studio 在商业版中提供。

  • 开源免费

    Core 和所有 Solution 开源免费，可以直接用于生产。

  • 私有部署

    Core、Solution 和 Studio 都部署在企业自己的服务器上，代码和数据归企业所有。

  • 模型与 Agent 自由选择

    不绑定厂商，支持 Claude Code、Codex 等编码工具和各类大模型。

  • 应用独立运行

    业务应用发布后独立运行，日常业务请求不经过 Studio。

FAQ

NocoBase 和 Vibe Coding 有什么区别？

Vibe Coding 让软件开发更加高效，但当项目涉及复杂业务、多人协作和长期迭代时，仅靠 AI 生成代码还不够，还需要可靠的应用底座、统一的开发规范和完善的治理。NocoBase 并不是 Vibe Coding 的替代品，而是在它之上补齐底座和治理能力。

基础能力

没有 NocoBase

权限、工作流、审批等底层模块，每个项目都由 AI 从零生成，成本高且很难保证可靠。

NocoBase

Core 提供现成的基础能力，Agent 只开发业务部分。

架构规范

没有 NocoBase

换人、换模型、换会话，AI 都可能随机发挥，架构逐渐漂移。

NocoBase

Core 提供统一的项目结构、开发规范和开发技能，系统在统一架构下长期稳定迭代。

开发治理

没有 NocoBase

Agent 交来的改动越来越多，人审不过来，往往直接接受，问题越积越多。

NocoBase

Studio 组织多个 Agent 协同完成设计、开发、测试和评审，关键决策交给人把关，并附上报告和截图作为依据。

知识沉淀

没有 NocoBase

需求背景、项目资料和经验散落在各自的会话里。

NocoBase

Studio 用技能、知识库和项目记忆沉淀方法和经验，换人、换 Agent 都能无障碍交接。
