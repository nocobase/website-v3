# AI + NocoBase · 品牌宣传片 · 规范与镜头表（v2 · 一个业务系统的一年）

141 秒，16:9，1920×1080，60 fps，中文版，无旁白（配乐 + 音效）。先出 HTML 审片版（`preview.html`），确认后再渲染。

## 1. 从第一性原理出发

**看片的人是谁**：中大型企业里负责业务系统的 CIO、IT 负责人、技术负责人，以及懂业务的负责人。他们在官网首页点「观看演示」，或在发布会、销售演示里看到这支片子。

**他们心里的问题**：AI 写代码已经很快了，我们能不能用 AI 建设和维护企业自己的业务系统？做出来的东西能不能放进核心业务、能不能长期用下去、团队能不能管得过来？

**看完要带走的四句话**（全部来自已确认的定位与官网文案）：

1. NocoBase 是用 AI 开发和运行业务系统的开源平台。Agent 写代码、做执行，NocoBase 提供底座和流程，人来做决策。
2. AI 写代码很快，但企业要的是长期可靠的系统。
3. Core：让 Agent 专心写业务，通用底座已经就绪。Studio：让团队专心做决策，执行交给 Agent 团队。
4. 第一天起点高，每一次迭代有章法，之后很多年走得远。

**为什么上一版乱**：它按产品结构排（Core 一章、Studio 一章），又用 7 条需求当账单逐条对账，开头立了"改坏"和"人成了瓶颈"两个问题，Agent 一会儿是写代码的、一会儿是业务里的，规模从一个系统跳到全公司再跳回来。

**这一版的主线**：**一个业务系统的一年。** 采购部的供应商管理系统，从第 1 天上线，之后每周上线一版，到第 52 周还在稳定迭代。时间就是主线，三幕正好对应三项核心价值，也对应系统生命周期的三个阶段：

| 幕 | 时间 | 核心价值 | 由谁提供 | 这一幕要证明的 |
|---|---|---|---|---|
| 第一幕 | 第 1 天 | 起点高 | NocoBase Core | 第一版就是企业级：Agent 只写业务，权限、审批等 20 多项能力直接用底座 |
| 第二幕 | 第 2 周 → 第 8 周 | 有章法 | NocoBase Studio | 每周一版，每次迭代走同一套流程：Agent 团队执行，人只在交代目标、做决定、验收与批准时出场；Agent 把学到的经验记进项目记忆，下次开工先读 |
| 第三幕 | 第 26 周 → 第 52 周 | 走得远 | Core + Studio + 开源 | Core 升级业务不用重写，换了负责人工作接着做，代码和数据始终在自己手里 |

借 CRM 片的骨架：一个承诺、一个系统、一条贯穿全片的进度条（三项价值）、一个版本徽标（版本号与第几天、第几周）。每一幕只有一句标题。

**画面规则**：Agent 做的事带 Agent 标识（CX、CC、调）；人只通过光标出场；NocoBase 提供的部分用蓝色。片中的 Agent 主要指写代码的 Agent，业务 Agent 只在第一幕的权限与审批里出现一次（供应商 Agent），说明它和员工用同一套规则。

**不讲**：Solutions、Launch、价格；不出现"改坏""瓶颈"这类恐惧说法；不出现产品里没有的能力（发布前自动备份、NocoBase 专属检查、运维 Agent、用量上限、操作审计）。

## 4. 配乐

沿用上一版的音色和 score-kit 的编排规则：120 BPM，调性中心 D，每个章节从前一小节引入、在强拍落下。

- **开场 0–11.5**：干声总线。窄的持续音、时钟和机械音型 D C A B♭；终端写代码时音型加密；时间轴上每落一个需求加一层织体；11.0 收住，宽的属和弦和引入接上品牌，中间不留空白。
- **品牌 12**：D 大调在强拍进来，钟声奏动机的大调版（D C# A B）；分工三个词各一声轻点。
- **第一幕 20–54**：Dadd9 · A/C# · Bm · G；Core 落下时加鼓组，业务代码落下一声；权限、审批两个证明用 Bm 色彩，标题出现时减薄，审批最后一小节在 V 级上推起来；能力看板：卡片亮起时走 IV、ii 级，琶音让位，每亮一张弹一个和弦内音，逐列升高，计数到 20+ 一声钟；拉远看到整屏时落在 I 级，最开阔，出字和 v1.0 时走到 IV 级，再一小节 V 级接进第二幕。
- **第二幕 54–108**：Studio 落下后进入中速律动 D · G · Bm · A；执行那一页织体加厚（并行），评审发现问题时琶音退出、修好后回来；批准上线一声钟；版本一行行往上长时，每行一个上行的钟声音符；项目记忆一页织体放轻，每张卡片一个轻弹音，下一个任务读到两条记忆时各一声钟。
- **第三幕 108–128**：半速感，铺底更宽，贝斯全音符；Core 3.1 落定一声；一年计数时逐渐抬升。
- **收束 128–134**：鼓组退出，三栏各一个钟声；贝斯走回主音。
- **落版 134**：Dmaj9，三声钟，长尾。
